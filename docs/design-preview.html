Creating variables

A variable is a name that refers to a value. You create one by assigning with =.

variables.py
age = 25
name = "Ada"
print(name)
print(age)

Output 

Click Run…

Variable names can use letters, numbers, and underscores. They cannot start with a number.

Naming rules

Use snake_case for multi-word names — it's the Python convention.

Updating values

You can change what a variable holds by assigning again: age = 26 replaces the old value.

Variables in print

Pass variables into print() or use an f-string: print(f"Hello, {name}").
