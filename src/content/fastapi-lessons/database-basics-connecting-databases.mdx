## Why this matters

Connecting correctly means one pool of connections shared across requests, sessions closed after each request, and no leaked connections under load. FastAPI's `Depends()` makes that pattern repeatable.

## Connection string

<CodeExample language="python" filename="main.py" runnable={true} code={`DATABASE_URL = "postgresql+psycopg2://user:pass@localhost/appdb"
# SQLite example:
# sqlite:///./app.db

engine = create_engine(DATABASE_URL)`} />

## Session per request

<CodeExample language="python" filename="main.py" runnable={false} code={`SessionLocal = sessionmaker(bind=engine, autoflush=False)

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return db.query(Item).all()`} />

<CodeExample language="bash" filename="terminal.sh" runnable={true} code={`# Test Postgres is reachable
psql "$DATABASE_URL" -c 'SELECT 1'`} />

## Recap

- Engine manages the connection pool
- `yield` in `get_db` closes sessions after each request
- Inject `db` with `Depends(get_db)` in routes
