When **`print`** is not enough, **pdb** (Python debugger) pauses your program so you can inspect variables step by step.

## One new idea: breakpoint()

```python
def divide(a, b):
    breakpoint()  # Python 3.7+
    return a / b

divide(10, 0)
```

At the prompt:

```text
(Pdb) p a
(Pdb) p b
(Pdb) n        # next line
(Pdb) c        # continue
```

## Common pdb commands

| Command | Action           |
| ------- | ---------------- |
| `n`     | next line        |
| `s`     | step into call   |
| `c`     | continue running |
| `l`     | list source      |
| `q`     | quit debugger    |
