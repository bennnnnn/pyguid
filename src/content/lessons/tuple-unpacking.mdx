You open a **labeled lunch box**: slot one is the sandwich, slot two is the apple. **Unpacking** does the same — one tuple on the right, **one variable per slot** on the left.

## One new idea: one line, many variables

<PythonExample
  filename="unpack.py"
  code={`point = (3, 4)
x, y = point
print(x)
print(y)`}
/>

**Line by line**

- `point = (3, 4)` — a tuple with two values
- `x, y = point` — first value → `x`, second → `y`
- Python matches **left to right**, position by position

| Tuple position | Variable | Value |
| -------------- | -------- | ----- |
| `0`            | `x`      | `3`   |
| `1`            | `y`      | `4`   |

## Real use case: swap two values

<PythonExample
  filename="swap.py"
  code={`a = 1
b = 2
a, b = b, a
print(a, b)`}
/>

No temporary variable needed — Python builds a tiny tuple `(2, 1)` and unpacks it into `a` and `b`.

## Unpack in a loop

<PythonExample
  filename="loop_unpack.py"
  code={`pairs = [(1, "one"), (2, "two"), (3, "three")]
for number, word in pairs:
    print(number, word)`}
/>

Each item in `pairs` is a tuple. The loop unpacks `(number, word)` every time.

## The `*` operator — collect “the rest”

<PythonExample
  filename="star.py"
  code={`numbers = (1, 2, 3, 4, 5)
first, *middle, last = numbers
print(first)
print(middle)
print(last)`}
/>

- `first` → `1`
- `*middle` → **list** `[2, 3, 4]` (everything in the middle)
- `last` → `5`

<Callout variant="danger" title="Oops — Python is yelling">
  The number of variables on the left must match the tuple size, **unless** you use `*` to
  collect extras. `(1, 2)` into `a, b, c` → **ValueError**.
</Callout>

<TryIt title="Try it yourself" answer="20">
  With `size = (10, 20)`, unpack into `width, height`. Print `height`.
</TryIt>

## Recap

- **`x, y = point`** assigns each tuple item to a variable
- **`a, b = b, a`** swaps two values cleanly
- **`*rest`** collects leftover items into a **list**
