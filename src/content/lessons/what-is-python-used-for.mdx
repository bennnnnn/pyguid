## Why this matters

“What can I build?” keeps motivation high. Python is not locked to one career path — but it **excels** in several areas you will hear about in jobs and side projects.

## Major areas

| Area | What people build | Why Python fits |
| ---- | ----------------- | --------------- |
| **Web backends** | APIs, server logic | Frameworks like Django and Flask |
| **Data & AI** | Analysis, models, notebooks | Libraries like pandas, PyTorch, scikit-learn |
| **Automation** | Rename files, reports, emails | Quick scripts, reads like English |
| **Education** | Courses, grading tools | Easy first language |
| **Scripting** | Glue between apps | Fast to write, runs on most OSes |

Companies such as Instagram, Dropbox, and Netflix have used Python in parts of their stack. Research labs and startups use it daily.

## What this course focuses on

PyGuide teaches **core Python** — variables, types, control flow, functions, files, classes. That core works in **every** area above.

Specialized topics (web frameworks, deep learning) come **after** fundamentals. You are not behind if you do not pick a specialty on day one.

## Recap

- Python is **versatile** — web, data, automation, education, hobbies
- **Core skills** transfer across all of those uses
- Pick a specialty later; master basics first
