## Why this matters

Lambda functions shows up throughout Advanced Functions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A sticky note with one quick formula — no full recipe card needed. A **lambda** is a **tiny function without a name**, useful for one-line jobs.

## One new idea: lambda arguments: expression

```python
lambda arguments: expression
```

<PythonExample
  filename="lambda_basic.py"
  code={`double = lambda x: x * 2
print(double(5))

add = lambda a, b: a + b
print(add(3, 7))`}
/>

**Line by line**

- `lambda x: x * 2` — take `x`, return `x * 2`
- Assign to a name if you will reuse it
- One **expression** only — no multi-line bodies

## Real use case: sorted with key=

<PythonExample
  filename="sorted_key.py"
  code={`names = ["charlie", "ada", "bob"]
print(sorted(names, key=lambda n: len(n)))
print(sorted(names, key=lambda n: n.lower()))`}
/>

`key=` tells `sorted` how to compare — lambdas shine here.

## map() and filter()

<PythonExample
  filename="map_filter.py"
  code={`nums = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
print(doubled)
print(evens)`}
/>

List comprehensions often replace these for simple cases.

<Callout variant="note">
  List comprehensions often replace `map` and `filter` for simple cases: `[x * 2 for x in
  nums]`.
</Callout>

<Callout variant="tip">
  Use `def` for anything longer than one expression. Lambdas shine for short `key=`
  functions in `sorted()`.
</Callout>

## Recap

- **`lambda x: expr`** — small anonymous function
- **`sorted(..., key=lambda ...)`** — common real use
- Prefer **`def`** when logic grows beyond one line
