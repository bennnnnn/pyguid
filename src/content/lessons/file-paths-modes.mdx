## Why this matters

File paths and modes shows up throughout Files and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A file has an **address** (path) and an **action** (read, write, or append). **`open(path, mode)`** needs both.

## One new idea: mode letters

| Mode  | Meaning                          |
| ----- | -------------------------------- |
| `"r"` | **read** (file must exist)       |
| `"w"` | **write** (creates or **wipes**) |
| `"a"` | **append** (add to end)          |

## Paths: relative vs absolute

```text
notes.txt           # same folder as script
data/notes.txt      # folder data next to script
/Users/you/notes.txt  # absolute (Mac/Linux)
```

<Callout variant="danger" title="Oops — Python is yelling">
  **`open("x.txt", "w")`** **deletes** old content. Double-check before writing.
</Callout>

<Callout variant="note">
  Browser **Run code** cannot touch your real disk. Practice paths on your machine in a

</Callout>

## Recap

- **`"r"`** read · **`"w"`** overwrite write · **`"a"`** append
- Paths can be **relative** or **absolute**
