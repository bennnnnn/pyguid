Gift wrap goes around a box without changing the gift inside. A **decorator** wraps a **function** — same call signature outside, extra behavior before or after inside.

## One new idea: function that returns function

<PythonExample
  filename="decorator.py"
  code={`def log_calls(func):
    def wrapper(*args, **kwargs):
        print("Calling", func.__name__)
        result = func(*args, **kwargs)
        print("Done", func.__name__)
        return result
    return wrapper

@log_calls
def add(a, b):
return a + b

print(add(2, 3))`}
/>

`@log_calls` above `add` means `add = log_calls(add)`.

- **`wrapper`** calls the original function
