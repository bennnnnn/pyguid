## Why this matters

'if __name__ == shows up throughout Modules and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.


A file can be **imported** as a module or **run** as the main program. **`if __name__ == "__main__":`** wraps code that should run **only** when you execute the file directly.

## One new idea: two ways to use a file

<PythonExample
  filename="main_demo.py"
  code={`def add(a, b):
    return a + b

print("Module loaded, name is:", **name**)

if **name** == "**main**":
print("Running as main script")
print(add(2, 3))`}
/>

When **Run** here, `__name__` is `"__main__"` — the block runs.

When another file **`import`s** this module, `__name__` is the module name — the block is **skipped**.

## Real pattern

```python
def main():
    print("Start here")

if __name__ == "__main__":
    main()
```

Keeps **reusable functions** at the top and **script steps** at the bottom.

## Recap

- **`import`** — `__name__` is module name
- **Run file directly** — `__name__` is `"__main__"`
- Put script-only code inside the **`if`** block
