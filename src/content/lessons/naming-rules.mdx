You cannot label a box **`2socks`** — names that start with a number confuse everyone. Python has similar rules for variable names: they must be **readable labels** the computer can parse.

## One new idea: legal names

A variable name may use:

- Letters (`a`–`z`, `A`–`Z`)
- Digits (`0`–`9`) — but **not** as the first character
- Underscores (`_`)

No spaces. No hyphens (Python reads `-` as minus).

<PythonExample
  filename="valid.py"
  code={`user_name = "Sam"
score2 = 100
_private = True
print(user_name)`}
/>

**Line by line**

- `user_name` — two words joined with `_` (good style)
- `score2` — digit at the **end** is fine
- `_private` — leading underscore is allowed (often means “internal use”)
- `print(user_name)` — shows `Sam`

## Several words: snake_case

When a name has more than one word, Python style uses **snake_case**: lowercase words separated by `_`.

<PythonExample
  filename="snake.py"
  code={`first_name = "Alex"
last_name = "Lee"
full_name = first_name + " " + last_name
print(full_name)`}
/>

Read `first_name` as “first name,” not `firstname` mashed together.

## Case matters

`name` and `Name` are **two different** variables. Pick one style and stick to it.

<PythonExample
  filename="case.py"
  code={`name = "ada"
Name = "Ada"
print(name)
print(Name)`}
/>

## Common mistakes: illegal names

| You write | Problem                          |
| --------- | -------------------------------- |
| `2score`  | starts with a digit              |
| `my-var`  | `-` is subtraction, not a letter |
| `my var`  | space splits into two tokens     |

<Callout variant="danger" title="Oops — Python is yelling">
  Do not use **keywords** as variable names: `if`, `for`, `print`, `True`, `class`, and
  others already mean something special. `print = 5` would break `print()` later.
</Callout>

<TryIt title="Try it yourself" answer="Ada Lovelace">
  Create `first_name` with `"Ada"`, `last_name` with `"Lovelace"`, then `full_name` as
  `first_name + " " + last_name`. Print `full_name`.
</TryIt>

## Recap

- Names use letters, digits, `_` — **not** starting with a digit
- Use **snake_case** for multi-word names
- **`=`** assigns; keywords are off-limits
