## Menu loop pattern (local Python)

```python
cart = []
while True:
    cmd = input("add / show / quit: ").strip().lower()
    if cmd == "quit":
        break
    if cmd == "add":
        cart.append(input("Item: "))
    elif cmd == "show":
        for item in cart:
            print("-", item)
```

## Recap

- **`append`** adds one item
- **`for`** prints every item
- A **`while`** menu ties commands together
