A **shopping list** is the classic list exercise: add items, show everything, maybe remove one. You have **`append`**, loops, and **`remove`** ready.

## Start with a fixed demo

<PythonExample
  filename="shop.py"

print("Shopping list:")

## Menu loop pattern (local Python)

```python
cart = []
while True:
    cmd = input("add / show / quit: ").strip().lower()
    if cmd == "quit":
        break
    if cmd == "add":
        cart.append(input("Item: "))
    elif cmd == "show":
        for item in cart:
            print("-", item)
```

## Stretch goals

- Remove an item with **`remove()`** (handle `ValueError` if missing)
- Sort before printing with **`sorted(cart)`**
- Save the list to a text file (preview of the **Files** chapter)

## Recap

- **`append`** adds one item
- **`for`** prints every item
- A **`while`** menu ties commands together
