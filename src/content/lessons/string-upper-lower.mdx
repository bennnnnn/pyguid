## Why this matters

upper() and lower shows up throughout Strings and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

You shout in ALL CAPS and whisper in lowercase. String methods like **`upper()`** and **`lower()`** do that for text — and they return a **new** string; the original stays unchanged.

## One new idea: upper()

<PythonExample
  filename="upper.py"
  code={`msg = "Hello, Python"
loud = msg.upper()
print(loud)
print(msg)`}
/>

**Before → after**

| Variable | Value                         |
| -------- | ----------------------------- |
| `msg`    | `"Hello, Python"` (unchanged) |
| `loud`   | `"HELLO, PYTHON"`             |

## lower() for comparisons

<PythonExample
  filename="compare.py"
  code={`answer = "YES"
if answer.lower() == "yes":
    print("Confirmed")`}
/>

Users type `YES`, `yes`, `Yes` — compare with **`.lower()`** so you do not miss a match.

## title() and capitalize()

<PythonExample
  filename="title.py"
  code={`name = "ada lovelace"
print(name.title())
print(name.capitalize())`}
/>

| Method          | `"ada lovelace"` → |
| --------------- | ------------------ |
| `.title()`      | `"Ada Lovelace"`   |
| `.capitalize()` | `"Ada lovelace"`   |

## Common mistake: forgetting to save the result

<Callout variant="warning" title="Oops — Python is yelling">
  **`msg.upper()`** alone does not change **`msg`**. Assign it: **`msg = msg.lower()`** if
  you need to keep the new version.
</Callout>

## Recap

- Methods return **new** strings — originals stay the same
- **`lower()`** helps compare user input fairly
- Assign the result if you need to keep it
