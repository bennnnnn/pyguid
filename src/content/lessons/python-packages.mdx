## Why this matters

Packages and pip shows up throughout Packages and Imports and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A single tool hangs on the wall; a **tool chest** holds many drawers. A **package** is a folder of related modules — the chest for bigger libraries like `requests` or `pandas`.

## One new idea: standard library vs packages

Python ships with many modules — no install needed:

| Module     | What it does    |
| ---------- | --------------- |
| `math`     | Math functions  |
| `random`   | Random numbers  |
| `datetime` | Dates and times |
| `json`     | JSON data       |

You already used `import math` in the first lesson of this chapter.

## pip — install from the internet

On your own computer (not in this browser course), you install extra packages with **pip**:

```text
pip install requests
```

Then in code:

```python
import requests
```

## Real use case: split your own code into files

Small projects grow into multiple files:

- `helpers.py` — functions you wrote
- `main.py` — `import helpers`

## Recap

- **Package** — folder of modules for a larger library
- **Standard library** — built in, just `import`
- **pip** — installs extra packages on your computer
