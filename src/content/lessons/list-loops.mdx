A **`for`** loop visits each item in a list:

<PythonExample
  filename="for_list.py"
  code={`fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)`}
/>

## Loop with index using range()

<PythonExample
  filename="index_loop.py"
  code={`fruits = ["apple", "banana", "cherry"]
for i in range(len(fruits)):
    print(i, fruits[i])`}
/>

## enumerate()

Gets **index and value** together — preferred when you need both:

<PythonExample
  filename="enumerate.py"
  code={`fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)

for index, fruit in enumerate(fruits, start=1):
    print(f"{index}. {fruit}")`}
/>

## Build a new list in a loop

<PythonExample
  filename="build.py"
  code={`numbers = [1, 2, 3, 4]
doubled = []
for n in numbers:
    doubled.append(n * 2)
print(doubled)`}
/>

## Loop with a condition

<PythonExample
  filename="filter_loop.py"
  code={`scores = [88, 42, 95, 64, 72]
passing = []
for s in scores:
    if s >= 60:
        passing.append(s)
print(passing)`}
/>

## Nested lists

<PythonExample
  filename="nested_loop.py"
  code={`grid = [[1, 2], [3, 4], [5, 6]]
for row in grid:
    for value in row:
        print(value, end=" ")
    print()`}
/>

<Callout variant="tip">
  Prefer `for item in my_list:` when you only need values. Use `enumerate` when you need the index too.
</Callout>

<Callout variant="note">
  **List comprehensions** (later chapter) shorten many “build a new list” loops.
</Callout>
