A teacher reads names from a class list, one at a time. A **`for`** loop does that with a Python list — no need to count indexes unless you want them.

## One new idea: for item in my_list

<PythonExample
  filename="for_list.py"
  code={`fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)`}
/>

**Line by line**

- `for fruit in fruits` — each time through, **`fruit`** is the **next** item
- `print(fruit)` — runs once per item (three lines of output)

## When you need the index too: enumerate()

<PythonExample
  filename="enumerate.py"
  code={`fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)

print("---")
for index, fruit in enumerate(fruits, start=1):
print(f"{index}. {fruit}")`}
/>

| Tool         | Gives you                        |
| ------------ | -------------------------------- |
| `for x in L` | each **value**                   |
| `enumerate`  | **index** and **value** together |

## Loop with range() (classic style)

<PythonExample
  filename="index_loop.py"
  code={`fruits = ["apple", "banana", "cherry"]
for i in range(len(fruits)):
    print(i, fruits[i])`}
/>

Works, but **`for fruit in fruits`** is simpler when you only need values.

## Real use case: build a new list

<PythonExample
  filename="build.py"
  code={`numbers = [1, 2, 3, 4]
doubled = []
for n in numbers:
    doubled.append(n * 2)
print(doubled)`}
/>

Pattern: empty list → loop → **`append`** → finished list.

## Filter with a condition

<PythonExample
  filename="filter_loop.py"
  code={`scores = [88, 42, 95, 64, 72]
passing = []
for s in scores:
    if s >= 60:
        passing.append(s)
print(passing)`}
/>

## Nested lists: loop inside loop

<PythonExample
  filename="nested_loop.py"
  code={`grid = [[1, 2], [3, 4], [5, 6]]
for row in grid:
    for value in row:
        print(value, end=" ")
    print()`}
/>

<Callout variant="tip">
  Prefer **`for item in my_list:`** when you only need values. Use **`enumerate`** when
  you need position numbers for display or logic.
</Callout>

## Recap

- **`for x in list:`** — visit each value
- **`enumerate(list)`** — index + value
- Loops often **build** new lists with **`append`**
