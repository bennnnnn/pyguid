## Why this matters

Numbers drive scores, prices, counters, and scientific code. / always gives float in Python 3 while // floors division—mixing them causes off-by-one bugs. Knowing int vs float helps you pick the right input parsing and display format.

You count whole apples with **1, 2, 3** and weigh flour as **2.5** kg. Python uses two number types the same way: **integers** for whole counts, **floats** for decimals.

## One new idea: int vs float

| Type        | Name    | Example | When to use         |
| ----------- | ------- | ------- | ------------------- |
| **Integer** | `int`   | `42`    | counts, scores      |
| **Float**   | `float` | `3.14`  | money, measurements |

## Basic math

<PythonExample
  filename="math.py"
  code={`a = 10
b = 4
print(a + b)
print(a - b)
print(a * b)
print(a / b)`}
/>

| Operator | Meaning                   |
| -------- | ------------------------- |
| `+`      | add                       |
| `-`      | subtract                  |
| `*`      | multiply                  |
| `/`      | divide (always **float**) |

`10 / 4` → `2.5`, not `2`.

## Whole-number division and remainder

<PythonExample
  filename="floor_mod.py"
  code={`print(17 // 5)
print(17 % 5)`}
/>

| Expression | Result | Meaning              |
| ---------- | ------ | -------------------- |
| `17 // 5`  | `3`    | how many full 5s fit |
| `17 % 5`   | `2`    | what is left over    |

Think: `17 = 3 × 5 + 2`.

## Common mistake: quotes turn numbers into text

<Callout variant="warning" title="Oops — Python is yelling">
  **`"5" + "5"`** → **`"55"`** (text glued together). **`5 + 5`** → **`10`**. Quotes mean
  string, not math — until you learn `int("5")` later.
</Callout>

<Callout variant="note">
  **`0.1 + 0.2`** might show **`0.30000000000000004`** — tiny float rounding. Normal for
  beginners; special tools handle money later.
</Callout>

## Recap

- **`int`** — whole numbers; **`float`** — decimals
- **`/``** always gives a float
- **`//`** and **`%`** — divide and remainder
