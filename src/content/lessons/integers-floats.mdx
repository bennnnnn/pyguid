## Why this matters

Numbers drive scores, prices, counters, and scientific code. Knowing **`int`**, **`float`**, and **`complex`** helps you pick the right type for the job.

You count whole apples with **1, 2, 3**, weigh flour as **2.5** kg, and engineers describe AC current with numbers like **2 + 3j**. Python has one built-in type for each: **integers**, **floats**, and **complex** numbers.

## The three number types

| Type        | Name      | Example   | When to use                          |
| ----------- | --------- | --------- | ------------------------------------ |
| **Integer** | `int`     | `42`      | counts, scores, ages                 |
| **Float**   | `float`   | `3.14`    | money, measurements, decimals        |
| **Complex** | `complex` | `2 + 3j`  | engineering, signals, advanced math  |

**Line by line**

- Numbers have **no quotes** (quotes mean text)
- `type(...)` shows `int`, `float`, or `complex`
- Complex numbers use **`j`** (not `i`) for the imaginary part — `2 + 3j`, never `2 + 3i`

## Common mistake: quotes turn numbers into text

<Callout variant="warning" title="Oops — Python is yelling">
  **`"5" + "5"`** → **`"55"`** (text glued together). **`5 + 5`** → **`10`**. Quotes mean
  string, not math — until you learn `int("5")` later.
</Callout>

<Callout variant="note">
  **`0.1 + 0.2`** might show **`0.30000000000000004`** — tiny float rounding. Normal for
  beginners; special tools handle money later.
</Callout>

## Recap

- **`int`** — whole numbers; **`float`** — decimals; **`complex`** — numbers with `j`
- Numbers have **no quotes** — `5` is a number, `"5"` is text
- Most everyday code uses `int` and `float`; `complex` shows up in engineering and science
- Math operators (**`+`**, **`/`**, **`//`**, **`%`**, **`**`**) live in the **Operators** chapter
