High scores on a leaderboard should go **low → high** (or the other way). **`sort()`** rearranges the **same list** so items are in order — like sorting cards in your hand without getting a second deck.

## One new idea: sort in place

<PythonExample
  filename="sort.py"
  code={`scores = [88, 72, 95, 64, 85]
scores.sort()
print(scores)`}
/>

**Before → after**

| Before                 | After `sort()`         |
| ---------------------- | ---------------------- |
| `[88, 72, 95, 64, 85]` | `[64, 72, 85, 88, 95]` |

Default: **smallest → largest**.

## Biggest first

<PythonExample
  filename="sort_reverse.py"
  code={`nums = [3, 1, 4, 1, 5]
nums.sort(reverse=True)
print(nums)`}
/>

## Sort words (case matters)

<PythonExample
  filename="sort_strings.py"
  code={`names = ["Charlie", "ada", "Ben"]
names.sort()
print(names)`}
/>

Capital letters sort **before** lowercase in ASCII order (`"Ben"` before `"ada"`). For friendlier order:

<PythonExample
  filename="sort_key.py"
  code={`names = ["Charlie", "ada", "Ben"]
names.sort(key=str.lower)
print(names)`}
/>

## sorted() — keep the original order too

<PythonExample
  filename="sorted.py"
  code={`original = [3, 1, 2]
ordered = sorted(original)
print("original:", original)
print("ordered:", ordered)`}
/>

| Tool       | Changes original? | Returns      |
| ---------- | ----------------- | ------------ |
| `.sort()`  | Yes               | `None`       |
| `sorted()` | No                | **new** list |

## Common mistake: expecting a return from sort()

<Callout variant="warning" title="Oops — Python is yelling">
  **`result = scores.sort()`** sets **`result`** to **`None`**. The sorted data is in
  **`scores`**, not in `result`.
</Callout>

<Callout variant="danger">
  **`[1, "two"].sort()`** → **TypeError**. Python cannot compare number and text to order
  them.
</Callout>

<TryIt title="Try it yourself" answer="[1, 2, 3]">
  With `nums = [3, 1, 2]`, call `sort()`, then print `nums`.
</TryIt>

## Recap

- **`list.sort()`** — reorder **this** list; returns **`None`**
- **`sorted(list)`** — new sorted list; original unchanged
- **`reverse=True`** — largest first

Next: **`reverse()`** — flip order without sorting.
