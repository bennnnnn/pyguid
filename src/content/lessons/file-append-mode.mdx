## Why this matters

Append mode (a) shows up throughout Files and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

**Write mode** (`"w"`) wipes the slate clean. **Append mode** (`"a"`) adds new lines at the **end** — perfect for logs, journals, and growing todo files.

## One new idea: open with a

On your computer:

```python
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("New entry\\n")
```

Each call adds text; previous content stays.

## w vs a

| Mode  | Creates file? | If file exists                   |
| ----- | ------------- | -------------------------------- |
| `"w"` | yes           | **truncates** (empty)            |
| `"a"` | yes           | **keeps** content, writes at end |
| `"r"` | no (error)    | read only                        |

## Pathlib append

```python
from pathlib import Path

path = Path("notes.txt")
with path.open("a", encoding="utf-8") as f:
    f.write("Another note\\n")
```

<Callout variant="warning">
  Forgetting `"a"` and using `"w"` **deletes** old notes. Double-check the mode string.
</Callout>

## Recap

- **`"a"`** — append without erase
- Pair with **`encoding="utf-8"`**
- Logs and **JSON todo** files grow this way
