## Why this matters

+= and friends appear in every counter, accumulator, and loop. For lists, += behaves like extend, which surprises people expecting append. Clear assignment shorthand makes loops readable and matches how C-style languages express updates.

You already know **`score = score + 10`**. **`+=`** is the shorthand: “add to what is already in the box.”

## One new idea: += and friends

<PythonExample
  filename="plus_eq.py"
  code={`points = 10
points += 5
print(points)`}
/>

| Long form             | Shortcut      |
| --------------------- | ------------- |
| `points = points + 5` | `points += 5` |
| `x = x - 1`           | `x -= 1`      |
| `n = n * 2`           | `n *= 2`      |
| `n = n / 2`           | `n /= 2`      |

<Callout variant="danger" title="Oops — Python is yelling">
  **`+=`** is **not** the same as **`==`**. **`+=`** updates a variable; **`==`** compares
  two values.
</Callout>

## Recap

- **`+=` `-=` `*=` `/=`** update in place
- Same meaning as the long `x = x + ...` form
