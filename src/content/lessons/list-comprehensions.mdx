## Why this matters

Comprehensions are idiomatic Python—you will see them in tutorials, libraries, and interview snippets. They teach you to think in transformations: start with data, filter, map, collect. They are optional early on, but recognizing them prevents copy-paste confusion later.

An assembly line: each item enters, gets transformed, and lands in a finished box. A **list comprehension** does that in **one line** — loop, transform, and collect.

## One new idea: [expression for item in iterable]

<PythonExample
  filename="basic.py"
  code={`numbers = [1, 2, 3, 4, 5]
doubled = [n * 2 for n in numbers]
print(doubled)`}
/>

**Line by line**

- `for n in numbers` — same loop you already know
- `n * 2` — expression applied to each item
- Whole thing inside `[ ]` — builds a **new list**

## With a condition

<PythonExample
  filename="filter.py"
  code={`numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)`}
/>

Only items where the `if` is true are included.

## Real use case: transform strings

<PythonExample
  filename="strings.py"
  code={`words = ["hello", "world"]
upper = [w.upper() for w in words]
print(upper)`}
/>

Replaces: empty list → loop → append.

## Nested comprehension (careful)

<PythonExample
  filename="nested.py"
  code={`matrix = [[1, 2], [3, 4]]
flat = [num for row in matrix for num in row]
print(flat)`}
/>

<Callout variant="warning">
  If a comprehension gets long or has many `if`/`for` clauses, a regular `for` loop is
  clearer.
</Callout>

<Callout variant="tip">
  Comprehensions often replace: create empty list → loop → append. They are idiomatic
  Python for simple transforms.
</Callout>

## Chapter 17 mini project: score report

Filter, transform, and summarize in comprehensions:

<PythonExample
  filename="scores.py"
  code={
    'names = ["Ada", "Ben", "Cara", "Dan"]\nscores = [95, 42, 88, 76]\n\npassing = [name for name, score in zip(names, scores) if score >= 60]\ndoubled_bonus = [score * 2 for score in scores if score >= 80]\nlabels = [f"{n}: {s}" for n, s in zip(names, scores)]\n\nprint("Passing:", passing)\nprint("Double bonus (80+):", doubled_bonus)\nprint("Report:")\nfor line in labels:\n    print(" ", line)'
  }
/>

Change scores or add names. Try a threshold other than `60`.

## Recap

- **`[expr for x in items]`** — build a list in one line
- **`if` at the end** — filter while building
- Use a plain **`for` loop** when the logic gets long
