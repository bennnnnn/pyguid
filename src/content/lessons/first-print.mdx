A **`print()`** is like a megaphone for your program: whatever you put inside gets shown on the screen. It is the fastest way to see if your code is doing what you expect.

## One new idea: show text with quotes

<PythonExample filename="hello.py" code={`print("Hello, Python!")`} />

**Line by line**

- `print` — the function name
- `("Hello, Python!")` — the **argument**: what to display
- Double `"` or single `'` quotes mean **text** (a string)

<PythonExample filename="quotes.py" code={`print('Single quotes work too')`} />

## Show numbers (no quotes)

<PythonExample
  filename="numbers.py"
  code={`print(42)
print(3.14)
print(10 + 5)`}
/>

| You write     | Python treats it as |
| ------------- | ------------------- |
| `print(42)`   | number **42**       |
| `print("42")` | text **"42"**       |

Numbers can do math **before** printing: `10 + 5` becomes `15`.

## Several values: commas add spaces

<PythonExample
  filename="multiple.py"
  code={`print("The answer is", 42)
print(2, "+", 2, "=", 2 + 2)`}
/>

**Output**

```text
The answer is 42
2 + 2 = 4
```

## Blank line

<PythonExample
  filename="blank.py"
  code={`print("Line 1")
print()
print("Line 3")`}
/>

`print()` with nothing inside prints an empty line.

## Control spacing: `sep` and `end`

<PythonExample
  filename="sep_end.py"
  code={`print("apple", "banana", "cherry", sep=", ")
print("Loading", end="...")
print(" done")`}
/>

| Option | Default  | Example effect          |
| ------ | -------- | ----------------------- |
| `sep`  | space    | `sep=", "` → commas     |
| `end`  | new line | `end="..."` → same line |

## Special characters inside text

| Code | Meaning          |
| ---- | ---------------- |
| `\n` | new line         |
| `\t` | tab              |
| `\"` | quote in `"..."` |

<PythonExample
  filename="escape.py"
  code={`print("Line one\\nLine two")
print("She said \\"Hello\\"")`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  **`print(hello)`** without quotes looks for a variable named `hello`. You have not
  created one yet → **NameError**. For now, put words in **quotes**.
</Callout>

<TryIt title="Try it yourself" answer="Hello, Sam">
  Print a greeting with your name: `print("Hello, Sam")` (change `Sam` to your name).
</TryIt>

## Recap

- **`print("text")`** — show strings
- **`print(42)`** — show numbers
- **Commas** — several items with spaces between
- **Quotes** = text; **no quotes** = number
