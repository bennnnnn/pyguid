Your list-based **todo** and **JSON todo** projects stored data in memory or text. SQLite keeps todos in **`todos.db`** — one file, real queries, ready for a menu CLI.

## Schema

```sql
CREATE TABLE IF NOT EXISTS todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    text TEXT NOT NULL,
    done INTEGER NOT NULL DEFAULT 0
);
```

## Core functions (local Python)

```python
import sqlite3

def add_todo(conn, text):
    conn.execute("INSERT INTO todos (text, done) VALUES (?, ?)", (text, 0))
    conn.commit()

def list_todos(conn):
    return conn.execute(
        "SELECT id, text, done FROM todos ORDER BY id"
    ).fetchall()

def mark_done(conn, todo_id):
    conn.execute("UPDATE todos SET done = 1 WHERE id = ?", (todo_id,))
    conn.commit()
```
