## Why this matters

input() turns static scripts into small tools—quizzes, calculators, CLI games. Everything from input is text, so conversion lessons come next. Handling input politely (clear prompts, validation) is the start of user-facing Python.

A form asks your name; you type and press Enter. **`input()`** is Python’s way to wait for that line of text and store it in a variable.

## One new idea: input() returns a string

On your computer (not in the browser runner):

```python
name = input("What is your name? ")
print(name)
```

**Line by line**

- `input("...")` — show prompt text, wait for Enter
- Whatever the user typed becomes a **string**
- Assign it to `name` like any other value
