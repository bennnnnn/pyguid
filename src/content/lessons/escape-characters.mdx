## Why this matters

Messages are not always one line. **Escape sequences** let you format text inside a normal quoted string.

## New line: `\n`

<PythonExample filename="newline.py" code={`print("Hello\\nPython")`} />

**Output**

```text
Hello
Python
```

## Tab: `\t`

<PythonExample filename="tab.py" code={`print("Name:\\tBini")`} />

Tabs align columns in simple output (fixed-width in the terminal).

## Quotes inside quotes

<PythonExample
  filename="quotes.py"
  code={`print("She said, \\"Hi!\\"")
print('It\\'s fine')`}
/>

Without the backslash, Python would think the string ended too early → **SyntaxError**.

## Quick reference

| You write | Meaning |
| --------- | ------- |
| `\n` | new line |
| `\t` | tab |
| `\"` | double quote inside `"..."` |
| `\'` | single quote inside `'...'` |
| `\\` | one backslash `\` |

<PythonExample
  filename="combo.py"
  code={`print("Line one\\nLine two")
print("A\\tB\\tC")`}
/>

## Recap

- **`\n`** — line break in output
- **`\t`** — tab
- **`\"`** / **`\'`** — quotes inside strings
- Backslash = “the next character is special”
