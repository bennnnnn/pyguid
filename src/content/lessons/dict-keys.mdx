## Why this matters

keys shows up throughout Dictionaries and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A filing cabinet has **drawer labels** — `"taxes"`, `"receipts"`, `"notes"`. **`keys()`** gives you every label in a dictionary, without opening each drawer.

## One new idea: `keys()` returns a view

<PythonExample
  filename="keys.py"
  code={`person = {"name": "Ada", "age": 36, "city": "London"}
print(person.keys())
print(list(person.keys()))`}
/>

**Line by line**

- `person.keys()` — a **view** of all keys (updates if the dict changes)
- `list(person.keys())` — snapshot as a plain list: `["name", "age", "city"]`
- Order follows insertion order (Python 3.7+)

| Method      | Returns                          |
| ----------- | -------------------------------- |
| `.keys()`   | view of **keys**                 |
| `.values()` | view of **values** (next lesson) |
| `.items()`  | view of **(key, value)** pairs   |

## Loop over keys

<PythonExample
  filename="loop_keys.py"
  code={`scores = {"math": 90, "english": 85, "science": 92}
for subject in scores.keys():
    print(subject)`}
/>

Shorthand: **`for subject in scores:`** loops over keys by default — same result, less typing.

## Real use case: list available settings

<PythonExample
  filename="settings.py"
  code={`config = {"theme": "dark", "lang": "en", "notifications": True}

print("Available settings:")
for key in config:
print("-", key)`}
/>

## Check if a key exists

<PythonExample
  filename="in_key.py"
  code={`user = {"name": "Sam", "role": "admin"}
print("name" in user)
print("email" in user)`}
/>

`in` checks **keys**, not values. `"Sam" in user` looks for a **key** named `"Sam"`, not the value.

<Callout variant="note" title="Oops — changing while looping">
  Adding or removing keys while looping over `.keys()` can surprise you. Use
  **`list(d.keys())`** when you need a fixed snapshot to loop safely.
</Callout>

## Recap

- **`d.keys()`** — all keys as a view
- **`for k in d:`** — same as looping keys
- **`"key" in d`** — test whether a key exists
