## Why this matters

count shows up throughout Strings and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

How many times does the letter **a** appear in a word? **`count()`** on a string answers that — like **`count()`** on a list, but for text inside text.

## One new idea: str.count(substring)

<PythonExample
  filename="count.py"
  code={`word = "banana"
print(word.count("a"))
print(word.count("na"))
print(word.count("z"))`}
/>

| Call          | Result | Meaning              |
| ------------- | ------ | -------------------- |
| `count("a")`  | `3`    | three a's            |
| `count("na")` | `2`    | overlapping allowed  |
| `count("z")`  | `0`    | not found — no error |

## count() vs find()

| Goal            | Use           |
| --------------- | ------------- |
| How many times? | **`count()`** |
| First position? | **`find()`**  |

<PythonExample
  filename="email.py"
  code={`email = "user@example.com"
print("@" in email)
print(email.count("@"))`}
/>

## Recap

- **`text.count(sub)`** — number of non-overlapping occurrences (default)
- Returns **`0`** if missing
- Pairs with **`find()`** and **`in`**
