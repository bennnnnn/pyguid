## Why this matters

So far your programs have used values you typed into the code. But real programs ask the **user** for information: a name, a password, a search term. **Input** is how your program listens.

## The program asks, you answer

Think of a program like a form. The program asks a question, waits for the user to type, and stores the answer:

```
Question: What is your name?
User types: Bini
Program stores: "Bini"
```

Without input, every program would show the same result every time. Input makes programs **interactive**.

## Input vs hardcoded values

**Hardcoded** (no input):

<PythonExample
  filename="hardcoded.py"
  code={`name = "Bini"
print("Hello,", name)`}
/>

**With input** (the user decides):

<PythonExample
  filename="with_input.py"
  code={`# On your PC: name = input("What is your name? ")
name = "Bini"
print("Hello,", name)`}
/>

## The pattern

Every interactive program follows the same pattern:

1. Ask a question
2. Wait for the answer
3. Store the answer
4. Use the answer

This chapter teaches each step.

## Recap

- **Input** is information the user gives the program while it runs
- Input makes programs **interactive** instead of showing the same result every time
- The pattern: ask → wait → store → use
