## Why this matters

Good **study habits** matter as much as picking Python. This page is your map for using PyGuide so the first chapter sticks.

## The PyGuide loop

1. **Read** one lesson top to bottom — one idea per page
2. **Run** every `<PythonExample />` — output proves you understand
3. **Change** a value or word and run again — prediction → check
4. **Back / Next** — follow sidebar order; it builds concepts step by step
5. **Quiz** — after a chapter, test recall at `/python/quiz/`
6. **Reference** — quick syntax lookup at `/python/reference/` while coding

## Use the sidebar as your path

Under **What Is Python?** you see a **flat list** of lessons — no extra menu layers. Click the next title when you are ready. You always know what comes next.

## When you are stuck

| Problem | Try this |
| ------- | -------- |
| Output surprise | Re-read **line by line** from the top |
| Red error text | Read the **last line** of the message; fix quotes or spelling |
| Concept fuzzy | Re-run yesterday’s example, then return |
| Syntax lookup | Open **Reference** for `print`, strings, etc. |

<Callout variant="warning" title="Oops — Python is yelling">
  Errors are not failure. They are the computer saying the file does not match Python’s rules yet. Fix one thing, run again.
</Callout>

## What to skip for now

- Comparing yourself to developers with years of experience
