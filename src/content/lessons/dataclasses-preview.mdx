## Why this matters

Dataclasses preview shows up throughout Python Standard Library and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Writing **`__init__`** for classes that only hold data gets repetitive. **`@dataclass`** (Python 3.7+) generates boilerplate for you.

## One new idea: @dataclass

On your computer:

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(3, 4)
print(p)
print(p.x)
```

## What you get for free

- **`__init__`** from the fields you list
- Nice **`__repr__`** for printing
- Less code than manual classes

## Compare to manual class

<PythonExample
