Writing **`__init__`** for classes that only hold data gets repetitive. **`@dataclass`** (Python 3.7+) generates boilerplate for you.

## One new idea: @dataclass

On your computer:

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(3, 4)
print(p)
print(p.x)
```

## What you get for free

- **`__init__`** from the fields you list
- Nice **`__repr__`** for printing
- Less code than manual classes

## Compare to manual class

<PythonExample
  filename="manual.py"
  code={`class PointManual:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = PointManual(3, 4)
print(p)`}

Same idea — dataclass saves typing when you have **many fields**.
