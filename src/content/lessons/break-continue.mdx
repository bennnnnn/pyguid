## Why this matters

break and continue let you stop searching once you find a match or skip bad rows without nested if pyramids. They appear in input validation, parsing, and game loops. Used wisely they simplify logic; overused they can hide confusing flow.

Searching a playlist, you stop as soon as you find the song — no need to keep scrolling. **`break`** exits a loop early; **`continue`** skips to the next round.

## One new idea: `break` and `continue`

<PythonExample
  filename="break.py"
  code={`for n in range(1, 10):
    if n == 5:
        break
    print(n)`}
/>

<PythonExample
  filename="continue.py"
  code={`for n in range(1, 8):
    if n % 2 == 0:
        continue
    print(n)`}
/>

**Line by line**

- **`break`** — stop the loop immediately (prints 1–4, then stops)
- **`continue`** — skip the rest of this round and jump to the next (only odd numbers print)

| Keyword    | Effect                     |
| ---------- | -------------------------- |
| `break`    | Exit the loop entirely     |
| `continue` | Skip to the next iteration |

## Real use case: search a list

<PythonExample
  filename="search.py"
  code={`names = ["Ana", "Ben", "Cara", "Dan"]
target = "Cara"
found = False

for name in names:
if name == target:
found = True
break

print(found)`}
/>

`break` works in **`while`** loops too — useful for retry limits:

<PythonExample
  filename="while_break.py"
  code={`password = "secret"
attempts = 0

while attempts < 3:
guess = "wrong"
attempts += 1
if guess == password:
print("Unlocked")
break
else:
print("Locked")`}
/>

A `while` loop's **`else`** runs only if the loop finishes **without** `break`.

## Chapter mini project: guess checker

Put **`while`**, **`for`**, **`range()`**, **`break`**, and **`continue`** together — check guesses against a secret number:

<PythonExample
  filename="guess_checker.py"
  code={`secret = 7
guesses = [3, 7, 9, 7]
attempts = 0
max_attempts = 5

while attempts < max_attempts:
for guess in guesses:
attempts += 1
if guess < 0:
continue
if guess == secret:
print("Found it on attempt", attempts)
break
else:
print("Not found this round")
break
else:
print("Out of attempts")`}
/>

<Callout variant="warning">
  Do not overuse `break` and `continue`. Sometimes a clearer `if` inside the loop is
  easier to read.
</Callout>

## Recap

- **`break`** exits the loop immediately
- **`continue`** skips to the next iteration
- Both work in **`for`** and **`while`** loops
- You now have **`while`**, **`for`**, **`range()`**, **`break`**, and **`continue`**
