## break — exit the loop

`break` stops the loop immediately:

<PythonExample
  filename="break.py"
  code={`for n in range(1, 10):
    if n == 5:
        break
    print(n)`}
/>

## continue — skip to next iteration

`continue` jumps to the next loop cycle:

<PythonExample
  filename="continue.py"
  code={`for n in range(1, 8):
    if n % 2 == 0:
        continue
    print(n)`}
/>

Only odd numbers print.

## Search with break

<PythonExample
  filename="search.py"
  code={`names = ["Ana", "Ben", "Cara", "Dan"]
target = "Cara"
found = False
for name in names:
    if name == target:
        found = True
        break
print(found)`}
/>

## while with break

<PythonExample
  filename="while_break.py"
  code={`password = "secret"
attempts = 0
while attempts < 3:
    guess = "wrong"
    attempts += 1
    if guess == password:
        print("Unlocked")
        break
else:
    print("Locked")`}
/>

<Callout variant="note">
  A `while` loop can have an `else` block that runs if the loop ends **without** `break`. It is uncommon but useful for “not found” cases.
</Callout>

<Callout variant="tip">
  Do not overuse `break` and `continue`. Sometimes a clearer `if` inside the loop is easier to read.
</Callout>
