## Why this matters

startswith() and endswith shows up throughout Strings and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Filenames like `report_2024.pdf` tell you a story: starts with **report**, ends with **.pdf**. **`startswith()`** and **`endswith()`** ask those questions and return **`True`** or **`False`**.

## One new idea: startswith()

<PythonExample
  filename="startswith.py"
  code={`filename = "report_2024.pdf"
print(filename.startswith("report"))
print(filename.startswith("invoice"))`}
/>

| Question                 | Answer  |
| ------------------------ | ------- |
| Starts with `"report"`?  | `True`  |
| Starts with `"invoice"`? | `False` |

## endswith() for file types

<PythonExample
  filename="endswith.py"
  code={`filename = "report_2024.pdf"

if filename.endswith(".pdf"):
print("PDF file")`}
/>

## Check several options with a tuple

<PythonExample
  filename="tuple.py"
  code={`url = "https://example.com"
if url.startswith(("http://", "https://")):
    print("Web URL")`}
/>

Pass a **tuple** of prefixes or suffixes — **any** match counts.

## Real use case: image files

<PythonExample
  filename="images.py"
  code={`name = "photo.PNG"
if name.lower().endswith((".png", ".jpg", ".gif")):
    print("Image file")`}
/>

<Callout variant="tip">
  Use **`.lower()`** on the filename when extensions might be uppercase (`PNG` vs `png`).
</Callout>

## Recap

- **`startswith(...)`** — beginning match
- **`endswith(...)`** — ending match
- Tuple argument = “any of these”
