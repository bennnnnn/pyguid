A price menu lists **item and price together**: apple $1.20, banana $0.80. **`items()`** gives you those **pairs** so you never look up the same key twice in a loop.

## One new idea: `(key, value)` pairs

<PythonExample
  filename="items.py"
  code={`person = {"name": "Ada", "age": 36}
print(person.items())
print(list(person.items()))`}
/>

**Line by line**

- `person.items()` — view of tuples like `("name", "Ada")`, `("age", 36)`
- Each pair is a **tuple** of `(key, value)`
- `list(...)` → `[("name", "Ada"), ("age", 36)]`

| What you need | Use                        |
| ------------- | -------------------------- |
| Keys only     | `for k in d:` or `.keys()` |
| Values only   | `.values()`                |
| **Both**      | **`.items()`**             |

## Loop with `items()`

<PythonExample
  filename="loop_items.py"
  code={
    'prices = {"apple": 1.2, "banana": 0.8}\nfor fruit, price in prices.items():\n    print(f"{fruit}: ${price:.2f}")'
  }
/>

Each loop unpacks **`fruit, price`** from one `(key, value)` tuple.

## Real use case: print a receipt

<PythonExample
  filename="receipt.py"
  code={
    'cart = {"notebook": 4.50, "pen": 1.25, "sticker": 0.75}\n\nprint("=== Receipt ===")\nfor item, cost in cart.items():\n    print(f"  {item}: ${cost:.2f}")\n\nprint("Total: $", sum(cart.values()))'
  }
/>

## Build a new dictionary

<PythonExample
  filename="build.py"
  code={`scores = {"math": 40, "english": 85, "art": 92}
passed = {}

for subject, score in scores.items():
if score >= 60:
passed[subject] = score

print(passed)`}
/>

<Callout variant="tip" title="Oops — slower pattern">
  Avoid **`for k in d: v = d[k]`** when **`.items()`** says the same thing in one line —
  clearer and slightly faster.
</Callout>

## Recap

- **`d.items()`** — `(key, value)` tuples
- **`for k, v in d.items():`** — best loop when you need both
- Prefer **`.items()`** over keys + bracket lookup
