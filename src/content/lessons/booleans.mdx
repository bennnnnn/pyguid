## Why this matters

Booleans shows up throughout Booleans and Conditions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A light switch is only **on** or **off**. A **boolean** (`bool`) is Python’s switch: **`True`** or **`False`** — no third option.

## One new idea: True and False

<PythonExample
  filename="bools.py"
  code={`is_active = True
is_admin = False
print(is_active)
print(is_admin)
print(type(is_active))`}
/>

**Line by line**

- `True` / `False` — capital **T** and **F** required
- `type(...)` shows `<class 'bool'>`

## Booleans from comparisons

Programs ask questions: “Is age at least 18?” The answer is a boolean:

<PythonExample
  filename="why.py"
  code={`age = 20
is_adult = age >= 18
print(is_adult)
print(type(is_adult))`}
/>

`age >= 18` is an expression that becomes **`True`** or **`False`** — not a number or string.

## Real use case: is it hot?

<PythonExample
  filename="hot.py"
  code={`temperature = 30
is_hot = temperature > 25
print("Hot day?", is_hot)`}
/>

You will learn every comparison operator (`==`, `!=`, `<`, …) in **Comparisons**, then **`and` / `or` / `not`**, then **`if`**.

## Common mistake: true vs True

<Callout variant="danger" title="Oops — Python is yelling">
  **`true`** and **`false`** are **invalid**. Only **`True`** and **`False`** work.
</Callout>

<Callout variant="tip">
  Name boolean variables like questions: **`is_valid`**, **`has_permission`**,
  **`can_edit`**. Then **`if can_edit:`** reads like English.
</Callout>

## Recap

- **`bool`** — only **`True`** or **`False`**
- Comparisons produce booleans
- Capital letters matter
