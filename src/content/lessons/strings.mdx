## Why this matters

Strings hold names, messages, file paths, and API text—almost every program uses them. Indexing and slicing on strings preview list behavior. Basic methods like strip and lower appear in input cleaning and data work immediately.

A **string** (`str`) is text in quotes — names, messages, passwords, emojis. If you can type it as words, it is probably a string.

## What you will learn in this section

1. **Strings** — create and combine text (this page)
2. **Case** — `upper()`, `lower()`, `title()`
3. **Whitespace** — `strip()`
4. **Split / join** — break apart and glue back
5. **Search** — `find()`, `replace()`, `in`
6. **Start/end checks** — `startswith()`, `endswith()`
7. **Formatting** — f-strings
8. **Slicing** — pieces of text

## Combine with `+` and repeat with `*`

<PythonExample
  filename="join_plus.py"
  code={`first = "Hello"
second = "World"
print(first + " " + second)
print("-" * 20)`}
/>

| Code       | Result        |
| ---------- | ------------- |
| `"Ha" * 3` | `"HaHaHa"`    |
| `"-" * 20` | twenty dashes |

## Length and first/last character

<PythonExample
  filename="len_index.py"
  code={`word = "Python"
print(len(word))
print(word[0])
print(word[-1])`}
/>

| Expression  | Meaning      |
| ----------- | ------------ |
| `len(word)` | 6 characters |
| `word[0]`   | `"P"`        |
| `word[-1]`  | `"n"`        |

<Callout variant="danger" title="Oops — Python is yelling">
  Strings are **immutable** — you cannot do `word[0] = "p"`. Build a **new** string
  instead (slicing and methods coming up).
</Callout>

## Recap

- **`str`** — text in quotes
- **`+`** joins strings; **`*`** repeats
- **`"5"`** is text; **`5`** is a number
