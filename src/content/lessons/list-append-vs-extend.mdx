**Short answer:** `append()` adds **one** item (any type). `extend()` adds **many** items by copying elements from another iterable.

## append() — one item at the end

<PythonExample
  filename="append_one.py"
  code={`items = ["a", "b"]
items.append("c")
print(items)`}
/>

## extend() — merge another iterable

<PythonExample
  filename="extend_many.py"
  code={`items = ["a", "b"]
items.extend(["c", "d"])
print(items)`}
/>

## Side-by-side

|                     | `append(x)`                     | `extend(iterable)`             |
| ------------------- | ------------------------------- | ------------------------------ |
| Adds                | **one** object `x`              | **each element** from iterable |
| `append(["x","y"])` | list becomes `[..., ["x","y"]]` | —                              |
| `extend(["x","y"])` | —                               | list becomes `[..., "x", "y"]` |
| Returns             | `None`                          | `None`                         |
| Changes original    | yes                             | yes                            |

## Common mistake: nested list with append

<PythonExample
  filename="nested.py"
  code={`row = [1, 2]
grid = []
grid.append(row)
row.append(3)
print(grid)`}
/>

`append(row)` stores **one** list object — aliasing bites later. Use `extend` or `copy` when building grids.

## FAQ

**Does append create a new list?**  
No. It mutates the same list in place.

**Why does append return None?**  
So you do not confuse the return value with the updated list. Use the variable: `items.append(x)` then `items`.

**Can I append multiple items at once?**  
Not in one `append` call. Use `extend`, a loop, or `+=` on lists.
