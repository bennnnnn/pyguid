## Why this matters

**`print()`** is your feedback loop: write a line, run it, see output. That loop stays useful for debugging long after you learn more advanced tools.

## One new idea: show something on the screen

<PythonExample filename="hello.py" code={`print("Hello, Python!")`} />

**Line by line**

- `print` — the function name (always lowercase)
- `(` … `)` — parentheses wrap what you want to show
- `"Hello, Python!"` — the **argument**: text in quotes

Whatever you pass to `print()` appears in the **output** panel when you press **Run**.

## Your first complete program

Many courses start with exactly this pattern — often called **Hello, World**:

<PythonExample filename="hello_world.py" code={`print("Hello, World!")`} />

If you see that text in output, your runner works and you wrote real Python.

## print is a function

A **function** is a named action. You **call** it with parentheses:

```python
print("something")
```

Other functions come later (`input`, `len`, and many more). For now, **`print()`** is how you **see** what your code does.

## Recap

- **`print(...)`** shows values on the screen
- Use **quotes** for text in this chapter
- **`print` is lowercase** — `Print` is wrong (you will see this again in Common beginner mistakes)
