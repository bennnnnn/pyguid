Someone hands you a sticky note with spaces smeared around the words. **`strip()`** trims that junk from the **start and end** — not from the middle of the sentence.

## One new idea: strip() both ends

<PythonExample
  filename="strip.py"
  code={`text = "   Hello, Python!   "
clean = text.strip()
print(repr(clean))`}
/>

**Before → after**

| `text` (with spaces) | `clean` after `strip()` |
| -------------------- | ----------------------- |
| `"   Hello...   "`   | `"Hello, Python!"`      |

`repr()` shows quotes so you can **see** spaces are gone.

## One side only: lstrip() and rstrip()

<PythonExample
  filename="sides.py"
  code={`line = ">>> prompt "
print(line.lstrip("> "))
print(line.rstrip())`}
/>

| Method     | Removes from   |
| ---------- | -------------- |
| `lstrip()` | **left** start |
| `rstrip()` | **right** end  |

## Real use case: clean form input

<PythonExample
  filename="input_clean.py"
  code={`raw = "  yes  "
cleaned = raw.strip().lower()
print(cleaned)`}
/>

Pattern: **`strip()`** then **`lower()`** before comparing answers.

<Callout variant="tip">
  Always **`strip()`** text from forms, files, or copy-paste before **`==`** comparisons.
</Callout>

## Recap

- **`strip()`** — both ends
- **`lstrip()` / `rstrip()`** — one side
- Middle spaces stay unless you use other tools
