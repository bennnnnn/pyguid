An empty slot on a form — not zero, not false, just **blank**. **`None`** is Python’s way to say “no value here” or “not found.”

## One new idea: None

<PythonExample
  filename="none.py"
  code={`result = None
print(result)
print(type(result))`}
/>

**Line by line**

- `None` — a single shared object meaning “nothing”
- `type(result)` — `<class 'NoneType'>`
- Different from `0`, `False`, or `""`

## Functions without return give None

<PythonExample
  filename="no_return.py"
  code={`def log(msg):
    print(msg)

x = log("Hi")
print(x)`}
/>

No `return` → caller gets **`None`**.

## Real use case: check with is None

<PythonExample
  filename="is_none.py"
  code={`value = None

if value is None:
print("No value set")

def find_user(id): # pretend not found
return None

user = find_user(99)
if user is None:
print("User not found")`}
/>

Use **`is None`** — not `==` — when testing for missing values.

## .get() returns None for missing keys

<PythonExample
  filename="get_none.py"
  code={`data = {"name": "Ada"}
email = data.get("email")
print(email)
print(email is None)`}
/>

<Callout variant="warning">
  Do not confuse `None` with `0`, `False`, or `""`. They are all “falsy” in `if` tests,
  but they mean different things.
</Callout>

<Callout variant="tip">
  Use `None` as a default in functions: `def f(x=None):` then set `x = []` inside if
  needed — never use `def f(x=[]):`.
</Callout>

<TryIt title="Try it yourself" answer="True">
  With `data = {"a": 1}`, set `v = data.get("b")` and print `v is None`.
</TryIt>

## Recap

- **`None`** — missing or empty value
- **No return** → function result is `None`
- **`is None`** — preferred check; `.get()` uses `None` for missing keys
