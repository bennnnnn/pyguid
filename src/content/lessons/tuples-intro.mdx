## Why this matters

Python tuples shows up throughout Tuples and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A **list** is like a whiteboard — you can erase and rewrite. A **tuple** is like a **printed ticket**: the seat number and row are **fixed** once it is printed. Same order, **no edits**.

## One new idea: a tuple in parentheses

<PythonExample
  filename="tuple.py"
  code={`point = (10, 20)
colors = ("red", "green", "blue")
print(point[0])
print(len(colors))`}
/>

**Line by line**

- `(10, 20)` — two numbers in `( )`, separated by a comma
- `point[0]` — first item, just like a list (index starts at **`0`**)
- `len(colors)` — how many items? Here, **`3`**

Tuples are:

- **Ordered** — first item stays first
- **Immutable** — you **cannot** change, add, or remove items after creation
- **Indexed** — use `[0]`, `[1]`, slicing, and negative indexes like lists

## What is in this chapter?

You will learn tuples in this order:

1. **What a tuple is** (this page)
2. **Unpacking** — assign each item to its own variable

## One item? Keep the comma

<PythonExample
  filename="one_item.py"
  code={`single = (42,)
print(single)
print(type(single))`}
/>

| Expression | What Python makes                                |
| ---------- | ------------------------------------------------ |
| `(42,)`    | a **tuple**                                      |
| `(42)`     | just the **int** `42` (parentheses for grouping) |

The trailing comma tells Python “this is a one-item tuple.”

## Real use case: fixed coordinates

<PythonExample
  filename="coords.py"
  code={`office = (40.7128, -74.0060)
lat, lon = office
print("Latitude:", lat)
print("Longitude:", lon)`}
/>

Use a tuple when the data should **not** change — map points, RGB colors `(255, 0, 0)`, or dates returned from a function.

<Callout variant="warning" title="Oops — Python is yelling">
  `coords[0] = 99` causes a **TypeError**. Tuples cannot be modified. If you need to
  change items, use a **list** instead.
</Callout>

## Recap

- **`(a, b, c)`** creates an ordered, **unchangeable** collection
- **`(42,)`** — one-item tuple needs a **trailing comma**
- Indexing and slicing work like lists
