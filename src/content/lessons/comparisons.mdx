## Why this matters

Comparisons drive if statements, while loops, and sorting—every branch needs them. Confusing = with == is a frequent bug. Chained comparisons like 0 < x < 10 are readable Python idioms worth knowing early.

A bouncer at a club checks your ID: old enough or not? Comparison operators let Python answer the same kind of yes/no questions about your data.

## One new idea: ask questions with `==`, `!=`, `<`, `>`, `<=`, `>=`

Each comparison returns **`True`** or **`False`**. Type operators exactly as shown — **`>=`** is two characters: `>` and `=`.

<PythonExample
  filename="compare.py"
  code={`x = 5
print(x == 5)
print(x != 3)
print(x < 10)
print(x > 2)
print(x <= 5)
print(x >= 5)`}
/>

**Line by line**

- `x == 5` — is `x` equal to 5? → `True`
- `x != 3` — is `x` not equal to 3? → `True`
- `x < 10`, `x > 2`, `x <= 5`, `x >= 5` — each returns a boolean

| Symbol | What it does in Python                          |
| ------ | ----------------------------------------------- |
| `=`    | **Assignment** — stores a value in a variable   |
| `==`   | **Comparison** — checks if two values are equal |

## Real use case: minimum age check

<PythonExample
  filename="minimum.py"
  code={`age = 20
can_enter = age >= 18
print("Can enter?", can_enter)

score = 72
passed = score >= 60
print("Passed?", passed)`}
/>

Use **`>=`** for a minimum (“at least 18”) and **`<=`** for a maximum (“at most 5 items”).

<PythonExample
  filename="strings.py"
  code={`name_a = "Amy"
name_b = "Ben"
print(name_a < name_b)
print(name_a == "Amy")`}
/>

Every comparison result is a **`bool`** you can store: `is_adult = age >= 18`.

<Callout variant="danger" title="Oops — Python is yelling">
  `if x = 5:` is invalid — `=` assigns, it does not compare. Use `if x == 5:` instead.
</Callout>

<Callout variant="warning">
  `==` on strings is case-sensitive: `"a"` and `"A"` are not equal.
</Callout>

## Recap

- Comparisons return **`True`** or **`False`**
- **`=`** stores a value; **`==`** checks equality
- **`>=`** and **`<=`** include the boundary value
- Store results in variables like `passed = score >= 60`
