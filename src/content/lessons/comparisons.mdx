Programs **compare** values to answer yes/no questions (is the score high enough? is the password correct?). Each comparison returns **`True`** or **`False`**. Type operators exactly as shown (for example **`>=`** is two characters: `>` and `=`).

<OperatorTable
  rows={[

    { operator: "!=", meaning: "not equal to", example: "x != 5" },
    { operator: "<", meaning: "less than", example: "x < 5" },
    { operator: ">", meaning: "greater than", example: "x > 5" },
    { operator: "<=", meaning: "less than or equal to", example: "x <= 5" },
    { operator: ">=", meaning: "greater than or equal to", example: "x >= 5" },
  ]}
/>

<PythonExample
  filename="compare.py"
  code={`x = 5
print(x == 5)
print(x != 3)
print(x < 10)
print(x > 2)
print(x <= 5)
print(x >= 5)`}
/>

## Greater or equal: `>=`

**`>=`** means “greater than **or** equal to.” Type both characters. Use it for a **minimum** (must be at least…):

<PythonExample
  filename="minimum.py"
  code={`age = 20
print(age >= 18)

score = 72
passed = score >= 60
print(passed)`}
/>

## Less or equal: `<=`

**`<=`** means “less than **or** equal to.” Type both characters. Use it for a **maximum** (must be at most…):

<PythonExample
  filename="maximum.py"
  code={`temperature = 18
print(temperature <= 20)

items = 3
print(items <= 5)`}
/>

## Equal and not equal: `==` and `!=`

<PythonExample
  filename="equal.py"
  code={`password = "secret123"
print(password == "secret123")
print(password != "wrong")`}
/>

## Assignment `=` is not a comparison

| Symbol | What it does in Python                          |
| ------ | ----------------------------------------------- |
| `=`    | **Assignment** — stores a value in a variable   |
| `==`   | **Comparison** — checks if two values are equal |

<Callout variant="danger" title="Common beginner mistake">
  `if x = 5:` is invalid. Use `if x == 5:` to compare.
</Callout>

## Comparing numbers

<PythonExample
  filename="numbers.py"
  code={`price = 49.99
on_sale = price < 50
print(on_sale)

level = 10
print(level >= 10)`}
/>

## Comparing strings

Use **`==`** for exact text. Use **`<`** and **`>`** for alphabetical order:

<PythonExample
  filename="strings.py"
  code={`name_a = "Amy"
name_b = "Ben"
print(name_a < name_b)
print(name_a == "Amy")`}
/>

<Callout variant="warning">
  `==` on strings is case-sensitive: `"a"` and `"A"` are not equal.
</Callout>

## Store the result

Every comparison returns **`bool`**:

<PythonExample
  filename="stored.py"
  code={`age = 16
is_adult = age >= 18
print(is_adult)
print(type(is_adult))`}
/>

## Chaining comparisons

<PythonExample
  filename="chain.py"
  code={`age = 25
print(18 <= age < 65)`}
/>

<Callout variant="tip">
  `18 <= age < 65` means: age is at least 18 and less than 65.
</Callout>
