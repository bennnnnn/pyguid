## Why this matters

Multiple assignment shows up throughout Input and Type Conversion and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

You label three boxes in one go: `x`, `y`, and `z` each get a value. Python can assign **multiple names** in a single line — clean and common in real code.

## One new idea: several names, one line

<PythonExample
  filename="multi.py"
  code={`x, y, z = 1, 2, 3
print(x, y, z)`}
/>

**Line by line**

- Left side: three names
- Right side: three values
- Python pairs them **left to right**

## Swap without a temp variable

<PythonExample
  filename="swap.py"
  code={`a = 10
b = 20
print("before:", a, b)

a, b = b, a
print("after:", a, b)`}
/>

| Before       | After swap   |
| ------------ | ------------ |
| `a=10, b=20` | `a=20, b=10` |

## Real use case: coordinates

<PythonExample
  filename="coords.py"
  code={`width, height = 800, 600
print(f"Screen: {width} x {height}")`}
/>

<Callout variant="warning" title="Oops — Python is yelling">
  **`x, y = 1`** — not enough values on the right. Counts on both sides must **match**.
</Callout>

## Recap

- **`a, b = 1, 2`** — multiple assignment
- **`a, b = b, a`** — swap values
- Left and right must have the **same number** of items
