## Why this matters

Real scripts often unpack several related values at once—coordinates, RGB colors, or form fields. Multiple assignment keeps that **compact** and **readable**.

## Several names, several values

Python can assign **multiple variables** in **one line**. Counts on the left and right must **match**.

<PythonExample
  filename="triple.py"
  code={`name, age, city = "Bini", 25, "San Francisco"
print(name)
print(age)
print(city)`}
/>

Python pairs them **left to right**:

- **`name`** ← **`"Bini"`**
- **`age`** ← **`25`**
- **`city`** ← **`"San Francisco"`**

## Same value for several names

<PythonExample filename="zeros.py" code={`x = y = z = 0
print(x, y, z)`} />

All three names point to **`0`**.

<Callout variant="warning" title="Oops — count mismatch">
  **`a, b = 1`** raises an error—two names on the left need **two** values on the right.
</Callout>

## Recap

- **`name, age, city = "Bini", 25, "San Francisco"`** — one line, three assignments
- **`x = y = z = 0`** — same value for every name
- Left and right sides must have the **same number** of items
