## Why this matters

append() is how you grow lists one step at a time in real scripts—shopping carts, log lines, and collected results all start here. Confusing append with extend or += is a top beginner bug that creates nested lists. Learning append cleanly makes loops and data collection much easier.

You have a shopping list on paper. You remember one more thing and write it **at the bottom**. Python lists work the same way with **`append()`**.

## One new idea: add one item to the end

<PythonExample
  filename="append.py"
  code={`items = ["milk", "bread"]
items.append("eggs")
print(items)`}
/>

**Before → action → after**

| Step             | List                        |
| ---------------- | --------------------------- |
| Start            | `["milk", "bread"]`         |
| `append("eggs")` | adds `"eggs"` at the end    |
| After            | `["milk", "bread", "eggs"]` |

**Line by line**

- `items = [...]` — create the list
- `items.append("eggs")` — tell **that same list** to grow by one item
- `print(items)` — show the updated list

## Real use case: building a cart

<PythonExample
  filename="cart.py"
  code={`cart = []

cart.append("laptop")
cart.append("mouse")
cart.append("keyboard")

print("Cart:", cart)
print("Total items:", len(cart))`}
/>

You start empty, then add items as the user “clicks buy.”

## Common mistake: `append` returns `None`

`append()` changes the list **in place**. It does **not** return the new list.

<PythonExample
  filename="append_none.py"
  code={`items = ["milk"]
result = items.append("eggs")

print(result)
print(items)`}
/>

| Expression | What you get                       |
| ---------- | ---------------------------------- |
| `result`   | `None`                             |
| `items`    | `["milk", "eggs"]` — the real data |

<Callout variant="danger" title="Oops — Python is yelling">
  `items.append("a", "b")` fails — **one** item per `append()`. Use two calls or use
  **`extend()`** for several items.
</Callout>

## Recap

- **`append(x)`** adds **one** item to the **end**
- The list **changes in place**
- Return value is **`None`** — use the list variable, not the result of `append`
