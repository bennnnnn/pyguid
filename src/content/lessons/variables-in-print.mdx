## Why this matters

Printing variables shows up throughout Variables and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

You filled out a form: **Name: \_\_\_**, **Age: \_\_\_**. Printing with variables is the same idea — you have labels (`name`, `age`) and you drop them into a sentence.

## One new idea: print a variable

<PythonExample
  filename="print_var.py"
  code={`name = "Ada"
print(name)`}
/>

`print(name)` does **not** print the word `name` — it looks up the **value** stored in `name` and shows `Ada`.

## Mix labels and values with commas

`print()` can take **several** items. It puts a **space** between them.

<PythonExample
  filename="comma.py"
  code={`name = "Ada"
age = 36
print("Name:", name)
print("Age:", age)`}
/>

**Output**

```text
Name: Ada
Age: 36
```

## f-strings: fill in the blanks (recommended)

Put **`f`** before the quotes. Inside **`{curly braces}`**, write a variable or expression:

<PythonExample
  filename="fstring.py"
  code={`name = "Ada"
age = 36
print(f"Name: {name}")
print(f"Age: {age}")
print(f"Next year: {age + 1}")`}
/>

Read `f"Next year: {age + 1}"` as: build this sentence and **compute** whatever is inside `{}`.

## Join strings with `+`

<PythonExample
  filename="concat.py"
  code={`greeting = "Hello, "
name = "Ada"
print(greeting + name)`}
/>

Every piece joined with `+` must be a **string**.

## Common mistake: number + text

If you tried `print("Age: " + age)` with `age = 36`, Python would raise **TypeError** — you cannot add a string and a number with `+`.

Use one of these instead:

<PythonExample
  filename="safe_print.py"
  code={`age = 36
print("Age:", age)
print(f"Age: {age}")`}
/>

<Callout variant="warning" title="Oops — Python is yelling">
  `"Age: " + age` fails when `age` is a number — you cannot add text and int with `+`. Use
  **`f"Age: {age}"`** or **`print("Age:", age)`**.
</Callout>

## Chapter 2 mini project: player card

Put the chapter together — create variables, update one, print a card:

<PythonExample
  filename="player_card.py"
  code={`player = "Sam"
level = 1
xp = 0

xp += 25
xp += 10
level = 2

print("--- Player card ---")
print(f"Name: {player}")
print(f"Level: {level}")
print(f"XP: {xp}")`}
/>

Run it. Change the name and XP gains. That is how small games track state with variables.

## Recap

- **`print(variable)`** shows the stored value
- **Commas** and **f-strings** mix text and data safely
- Prefer **f-strings** for readable messages
