A set of unique stickers: you **add** new ones, **remove** one you know is there, or **discard** without crashing if it is missing.

## One new idea: add()

<PythonExample
  filename="add.py"
  code={`tags = {"python", "web"}
tags.add("data")
tags.add("python")
print(tags)`}
/>

**`add("python")` twice** — still one `"python"` (sets ignore duplicates).

## remove() vs discard()

<PythonExample
  filename="remove_discard.py"
  code={`colors = {"red", "green", "blue"}

colors.discard("yellow")
print(colors)

colors.remove("red")
print(colors)`}
/>

| Method       | If item missing |
| ------------ | --------------- |
| `discard(x)` | no error        |
| `remove(x)`  | **KeyError**    |

## Recap

- **`add()`** — insert one item
- **`remove()`** — delete (errors if missing)
- **`discard()`** — delete safely
