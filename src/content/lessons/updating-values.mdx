## Why this matters

Updating values shows up throughout Variables and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A sticky note on your monitor can say **“score: 10”** today and **“score: 20”** tomorrow. The label **score** stays the same; you **replace** what is written on it.

Variables work the same way: the **name** stays, the **value** can change.

## One new idea: assign again with `=`

<PythonExample
  filename="update.py"
  code={`score = 10
print(score)
score = 20
print(score)`}
/>

**Before → action → after**

| Step           | What `score` means |
| -------------- | ------------------ |
| `score = 10`   | `10`               |
| `print(score)` | shows `10`         |
| `score = 20`   | old `10` is gone   |
| `print(score)` | shows `20`         |

The second `=` does **not** add — it **replaces** whatever was there.

## Use the current value when updating

<PythonExample
  filename="increment.py"
  code={`count = 1
count = count + 1
print(count)`}
/>

**Line by line**

- `count = 1` — start at 1
- `count = count + 1` — read current `count` (1), add 1, store 2
- `print(count)` — shows `2`

## Shorthand: `+=`

<PythonExample
  filename="shorthand.py"
  code={`points = 5
points += 3
print(points)`}
/>

`points += 3` means the same as `points = points + 3`. You will see `+=`, `-=`, `*=` often in real code.

## Real use case: game score

<PythonExample
  filename="game.py"
  code={`score = 0
print("Start:", score)

score += 10
print("Coin:", score)

score += 50
print("Boss:", score)`}
/>

## Common mistake: `=` vs `==`

<Callout variant="warning" title="Oops — Python is yelling">
  **`=`** stores a value. **`==`** checks if two values are equal (you will use that in
  comparison lessons). Writing `if score = 10` is invalid — use `if score == 10`.
</Callout>

## You can change the type (careful)

<PythonExample
  filename="reassign.py"
  code={`x = 10
print(x)
x = "ten"
print(x)`}
/>

`x` first held a number, then text. Python allows it, but flipping types in one variable can confuse **you** when reading code. Prefer a new name when the meaning changes.

<Callout variant="note">
  Updating `score` does not change other variables. If two names pointed at the same list
  (later chapter), that is a different story — for simple numbers and strings, each name
  is independent.
</Callout>

## Recap

- Assign again with **`=`** to replace a value
- **`count = count + 1`** and **`count += 1`** do the same thing
- Do not confuse **`=`** with **`==`**
