A variable can point to a **new value** at any time. Use `=` again to update it:

<PythonExample
  filename="update.py"
  code={`score = 10
print(score)
score = 20
print(score)`}
/>

The first `print` shows `10`. After `score = 20`, the old value is gone — `score` now means 20.

## Update using the current value

You can use the variable on the right side when assigning:

<PythonExample
  filename="increment.py"
  code={`count = 1
count = count + 1
print(count)`}
/>

<PythonExample
  filename="shorthand.py"
  code={`points = 5
points += 3
print(points)`}
/>

`points += 3` means the same as `points = points + 3`.

## Change type

A variable can hold a different **type** of value after an update:

<PythonExample
  filename="reassign.py"
  code={`x = 10
print(x)
x = "ten"
print(x)`}
/>

<Callout variant="note">
  Updating a variable does not change other variables. If you copy a value into two names,
  each name can be updated separately.
</Callout>

<Callout variant="warning">
  Be careful not to confuse `=` (assignment) with `==` (comparison). You will use `==`
  when checking if two values are equal in later lessons.
</Callout>
