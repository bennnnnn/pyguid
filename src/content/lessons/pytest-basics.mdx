**assert** checks one idea at a time. **pytest** runs **many** checks from files named `test_*.py` and reports pass/fail clearly — how most Python teams test code.

## One new idea: test functions

```python
# test_slugify.py
from myapp import slugify

def test_lowercase():
    assert slugify("Hello") == "hello"

def test_spaces():
    assert slugify("a b") == "a-b"
```

Rules pytest expects:

- File name starts with **`test_`**
- Function name starts with **`test_`**
- Body uses plain **`assert`**

## Run locally

```bash
pip install pytest
pytest
```

Pytest discovers tests automatically and shows green/red output.
