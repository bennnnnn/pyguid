## Why this matters

Command-line arguments (sys.argv) shows up throughout Modules and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

When you run `python greet.py Ada`, the name **Ada** travels with the script. **`sys.argv`** is the list of command-line words Python received.

## One new idea: argv is a list of strings

<PythonExample
  filename="argv_demo.py"
  code={`import sys

# Simulated argv (on your PC, Python fills this automatically)

sys.argv = ["greet.py", "Ada", "Bob"]

print("Script:", sys.argv[0])
print("Args:", sys.argv[1:])

for name in sys.argv[1:]:
print("Hello,", name)`}
/>

**Line by line**

- `sys.argv[0]` — script name (`greet.py`)
- `sys.argv[1:]` — everything **after** the script name
- All pieces are **strings** — convert with `int()` when needed

## Typical local script

```python
import sys

if len(sys.argv) < 2:
    print("Usage: python greet.py NAME")
else:
    print("Hello,", sys.argv[1])
```

## Recap

- **`import sys`** then **`sys.argv`**
- Index `0` = script, `1+` = arguments
- Foundation for **argparse**
