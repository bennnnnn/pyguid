**requests** blocks while waiting. **aiohttp** fits **async/await** — fetch several URLs without waiting for each to finish serially.

## Install

```bash
pip install aiohttp
```

## Fetch two URLs (local)

```python
import asyncio
import aiohttp

async def fetch(session, url):
    async with session.get(url) as response:
        return response.status, url

async def main():
    async with aiohttp.ClientSession() as session:
        tasks = [
            fetch(session, "https://example.com"),
            fetch(session, "https://httpbin.org/get"),
        ]
        for status, url in await asyncio.gather(*tasks):
            print(status, url)

asyncio.run(main())
```
