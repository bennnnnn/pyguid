## Why this matters

popitem shows up throughout Dictionaries and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

When you do not care **which** entry leaves first (often the last inserted in modern Python), **`popitem()`** removes **one** pair and gives it back as a tuple.

## One new idea: popitem()

<PythonExample
  filename="popitem.py"
  code={`cache = {"a": 1, "b": 2, "c": 3}
pair = cache.popitem()
print("Removed:", pair)
print("Left:", cache)`}
/>

**Line by line**

- `popitem()` — remove one item, return **`(key, value)`**
- Handy for processing dicts until empty

## Empty dict error

<PythonExample
  filename="empty.py"
  code={`data = {}
if data:
    data.popitem()
else:
    print("Nothing to pop")`}
/>

<Callout variant="note">
  **`pop(key)`** — you choose the key. **`popitem()`** — Python picks one (LIFO in 3.7+).
</Callout>

## Recap

- **`popitem()`** → `(key, value)` and shrinks dict
- Errors on **empty** dict
- Different from **`pop("key")`**
