## Why this matters

Import modules shows up throughout Modules and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A toolbox drawer holds wrenches you did not build — you **open the drawer** and use them. A **module** is Python’s drawer: reusable code you **import** instead of rewriting.

## One new idea: import a module

<PythonExample
  filename="import_math.py"
  code={`import math

print(math.sqrt(16))
print(math.pi)`}
/>

**Line by line**

- `import math` — load the **math** module
- `math.sqrt(16)` — call a function **inside** that module
- The module name acts like a prefix

## Import specific names

<PythonExample
  filename="from_import.py"
  code={`from math import sqrt, floor

print(sqrt(25))
print(floor(3.9))`}
/>

## Alias with as

<PythonExample
  filename="alias.py"
  code={`import math as m

print(m.pow(2, 3))`}
/>

## Real use case: random choices

<PythonExample
  filename="random.py"
  code={`import random

print(random.randint(1, 6))
items = ["apple", "banana", "cherry"]
print(random.choice(items))`}
/>

Roll a die or pick from a list — `random` ships with Python.

<Callout variant="note">
  Skulpt includes many standard modules like `math` and `random`. Some advanced modules
  are not available in the browser runner.
</Callout>

<Callout variant="tip">
  Prefer `import math` over `from math import *` — star imports dump many names into your
  file and can cause name clashes.
</Callout>

## Recap

- **`import module`** — load built-in or your own code
- **`from module import name`** — pull in one function
- **Standard library** — `math`, `random`, and more, no install needed
