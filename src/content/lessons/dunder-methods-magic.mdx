## Why this matters

Dunder methods shows up throughout Object-Oriented Python and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Methods with **double underscores** (`__len__`, `__eq__`) let your objects behave like built-ins — `len(box)`, `box == other`, `for item in box`.

## One new idea: **len** and **repr**

<PythonExample
  filename="dunder.py"
  code={`class Playlist:
    def __init__(self, songs):
        self.songs = list(songs)

    def __len__(self):
        return len(self.songs)

    def __repr__(self):
        return f"Playlist({self.songs!r})"

    def __getitem__(self, index):
        return self.songs[index]

pl = Playlist(["Intro", "Verse", "Chorus"])
print(len(pl))
print(pl[1])
for track in pl:
print(track)`}
/>

`__getitem__` enables **indexing** and **for** loops.

## **eq** for equality

<PythonExample
  filename="eq.py"
  code={`class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return self.x == other.x and self.y == other.y

print(Point(1, 2) == Point(1, 2))
print(Point(1, 2) == Point(0, 0))`}
/>

Return **`NotImplemented`** when the other type is not comparable.

| Method        | Enables         |
| ------------- | --------------- |
| `__len__`     | `len(obj)`      |
| `__repr__`    | debug display   |
| `__eq__`      | `==`            |
| `__getitem__` | `obj[i]`, loops |

## Recap

- **Dunder** = double underscore hooks
