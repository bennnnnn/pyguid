JSON files are great for small data. **SQLite** is a real **database in one file** — SQL queries, multiple tables, no separate server install.

## One new idea: connect and execute

```python
import sqlite3

conn = sqlite3.connect("app.db")
conn.execute(
    "CREATE TABLE IF NOT EXISTS todos (id INTEGER PRIMARY KEY, text TEXT, done INTEGER)"
)
conn.execute("INSERT INTO todos (text, done) VALUES (?, ?)", ("Learn SQL", 0))
conn.commit()

rows = conn.execute("SELECT id, text, done FROM todos").fetchall()
for row in rows:
    print(row)

conn.close()
```

`?` placeholders pass values safely — never f-string SQL with user input.

On your PC, `:memory:` creates a temporary database for practice.

| SQL snippet    | Purpose        |
| -------------- | -------------- |
| `CREATE TABLE` | define columns |
| `INSERT`       | add rows       |
| `SELECT`       | read rows      |

<Callout variant="warning">
  Always **`commit()`** after changes. Use **`with sqlite3.connect(...) as conn:`** for
  auto-close.
