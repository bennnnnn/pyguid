A clock has an **hour hand** loop and a **minute hand** loop inside each hour. **Nested loops** visit every combination: each outer step, run the whole inner loop.

## One new idea: loop inside loop

<PythonExample
  filename="grid.py"
  code={`for row in range(3):
    for col in range(3):
        print(row, col, end="  ")
    print()`}
/>

Outer `row` changes slowly; inner `col` runs completely each time.

## Real use case: multiplication table row

<PythonExample
  filename="table.py"
  code={`n = 3
for i in range(1, 4):
    print(n, "x", i, "=", n * i)`}
/>

## Grid of stars

<PythonExample
  filename="stars.py"
  code={`for i in range(3):
    for j in range(3):
        print("*", end="")
    print()`}
/>

<Callout variant="warning" title="Oops — infinite loops">
  If the inner loop never finishes (wrong `while` condition), the outer loop never
  advances. Check conditions when nesting **`while`** loops.
</Callout>

<TryIt title="Try it yourself" answer="(9 pairs printed)">
  Use two `for` loops `range(2)` each and print `i, j` for every pair.
</TryIt>

## Recap

- **Outer** loop runs once per row (or category)
- **Inner** loop runs fully each time
- Useful for tables, grids, all pairs
