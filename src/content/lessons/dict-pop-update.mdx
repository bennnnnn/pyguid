## Why this matters

pop(), update(), and del shows up throughout Dictionaries and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A desk drawer holds sticky notes. **`pop()`** pulls one off and reads it. **`update()`** slides in a whole stack of new notes. **`del`** throws a note away without reading it.

## One new idea: `pop(key)` removes and returns

<PythonExample
  filename="pop.py"
  code={`user = {"name": "Sam", "temp": True, "role": "admin"}
removed = user.pop("temp")
print("Removed:", removed)
print("Left:", user)`}
/>

**Line by line**

- `user.pop("temp")` — delete key `"temp"` and **return** its value (`True`)
- `removed` stores what was taken out
- `user` no longer has `"temp"`

| Method                | Returns                | If key missing    |
| --------------------- | ---------------------- | ----------------- |
| `pop("key")`          | the value              | **KeyError**      |
| `pop("key", default)` | the value or `default` | returns `default` |
| `del d["key"]`        | nothing                | **KeyError**      |

## `pop()` with a default

<PythonExample
  filename="pop_default.py"
  code={`data = {"a": 1}
print(data.pop("z", "missing"))
print(data)`}
/>

Safe when you are not sure the key exists.

## `update()` — merge dictionaries

<PythonExample
  filename="update.py"
  code={`defaults = {"theme": "light", "lang": "en"}
user_prefs = {"lang": "fr", "notifications": True}

defaults.update(user_prefs)
print(defaults)`}
/>

- Existing keys in `defaults` get **overwritten** (`"lang"` → `"fr"`)
- New keys from `user_prefs` are **added** (`"notifications"`)

## `del` and `clear()`

<PythonExample
  filename="del_clear.py"
  code={`person = {"name": "Ada", "age": 36}
del person["age"]
print(person)

cache = {"a": 1, "b": 2}
cache.clear()
print(cache)`}
/>

- **`del person["age"]`** — remove one key (no return value)
- **`cache.clear()`** — empty the entire dictionary → `{}`

## Chapter 11 mini project: contact book

Put it together — create, update, look up, and remove contacts:

<PythonExample
  filename="contacts.py"
  code={`contacts = {}

contacts["ada"] = {"name": "Ada Lovelace", "email": "ada@example.com"}
contacts["ben"] = {"name": "Ben Turing", "email": "ben@example.com"}

print("=== Contacts ===")
for user_id, info in contacts.items():
print(user_id, "→", info["name"], "|", info.get("email", "no email"))

print("Ada email:", contacts["ada"].get("email", "unknown"))

removed = contacts.pop("ben")
print("Removed:", removed["name"])
print("Remaining IDs:", list(contacts.keys()))`}
/>

Change the names. Add a third contact with **`update()`** or bracket assignment. Try **`pop()`** on a missing ID with a default.

<Callout variant="warning" title="Oops — Python is yelling">
  **`pop("missing")`** without a default → **KeyError**. Use **`pop("key", None)`** when
  you are not sure the key exists.
</Callout>

## Recap

- **`pop(key)`** — remove and return a value
- **`update(other)`** — merge another dict in place
- **`del d[key]`** — delete one entry; **`clear()`** — delete all
