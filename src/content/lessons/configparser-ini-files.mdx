## Why this matters

INI config files shows up throughout Files and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Games store graphics settings in a config file. **INI** files group **sections** (`[database]`) and **key = value** lines. **`configparser`** reads them without writing your own parser.

## One new idea: read_string

<PythonExample
  filename="ini.py"
  code={`import configparser

text = """
[app]
name = PyGuide
debug = true

[database]
path = data/app.db
"""

config = configparser.ConfigParser()
config.read_string(text)

print(config["app"]["name"])
print(config.getboolean("app", "debug"))
print(config["database"]["path"])`}
/>

**Line by line**

- `ConfigParser()` — empty config object
- `read_string` — load from text (use `read("settings.ini")` on disk)
- `config["section"]["key"]` — access values

## get with types

| Method       | Returns    |
| ------------ | ---------- |
| `get`        | string     |
| `getint`     | integer    |
| `getboolean` | True/False |

<Callout variant="note">

</Callout>

## Recap

- **`configparser.ConfigParser`**
- Sections in **`[brackets]`**
- Pair with **os.environ** for secrets (not in INI)
