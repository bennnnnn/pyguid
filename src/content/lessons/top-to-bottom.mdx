A recipe says: preheat oven, mix flour, bake. If you bake before mixing, disaster. Python reads your file like a recipe — **top to bottom**, one step at a time.

## One new idea: lines run in order

<PythonExample
  filename="order.py"
  code={`print("First")
print("Second")
print("Third")`}
/>

**Always this output**

```text
First
Second
Third
```

Python does not skip lines or reorder them on its own (later you will add `if` and loops that change flow).

## Later lines use earlier work

<PythonExample
  filename="steps.py"
  code={`greeting = "Hello"
print(greeting)
print("Done")`}
/>

**Line by line**

- Line 1 creates `greeting` — must run **first**
- Line 2 uses `greeting` — only works after line 1
- Line 3 runs last

You will learn variables properly in the **Variables** chapter; for now, remember: **define before use**.

## Math on one line happens before print

<PythonExample
  filename="math_first.py"
  code={`print(3 + 4)
print("3 + 4 =", 3 + 4)`}
/>

| Code                      | Output      |
| ------------------------- | ----------- |
| `print(3 + 4)`            | `7`         |
| `print("3 + 4 =", 3 + 4)` | `3 + 4 = 7` |

## Blank lines are for humans only

<PythonExample
  filename="spacing.py"
  code={`print("Start")

print("End")`}
/>

Empty lines are ignored — they help **you** read the file.

## Common mistake: use before create

<PythonExample
  filename="error_order.py"
  code={`print(score)
score = 100`}
/>

Run it — **NameError**: `score` does not exist yet when `print(score)` runs.

<Callout variant="tip">
  Fix: put **`score = 100`** **above** **`print(score)`**, then run again.
</Callout>

<Callout variant="warning">
  Later, **`if`** and loops need **indented** blocks (extra spaces). For now, keep every
  statement at the **left edge**.
</Callout>

## Recap

- Python runs from the **top** down
- Create values **before** you use them
- Blank lines do not affect execution
