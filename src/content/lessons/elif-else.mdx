Often you need more than two outcomes. Python provides:

- **`elif`** — “else if” — another condition to test
- **`else`** — runs when **no** previous condition was true

## elif

Python checks conditions **from top to bottom** and runs the **first** block that matches:

<PythonExample
  filename="grade.py"
  code={`score = 85

if score >= 90:
print("Grade: A")
elif score >= 80:
print("Grade: B")
elif score >= 70:
print("Grade: C")
else:
print("Grade: F")`}
/>

With `score = 85`, only “Grade: B” prints. The `elif score >= 70` block is **not** run, even though 85 is also ≥ 70.

<Callout variant="note">
  Order matters. Put **more specific** or **stricter** tests before looser ones when
  ranges overlap.
</Callout>

## else

`else` has **no** condition. It is the fallback:

<PythonExample
  filename="else_basic.py"
  code={`temperature = 15

if temperature > 25:
print("Hot")
elif temperature > 15:
print("Warm")
else:
print("Cool or cold")`}
/>

## if without elif

You can use `if` / `else` only:

<PythonExample
  filename="if_else.py"
  code={`password_correct = True

if password_correct:
print("Access granted")
else:
print("Access denied")`}
/>

## elif chain for categories

<PythonExample
  filename="traffic.py"
  code={`light = "yellow"

if light == "green":
print("Go")
elif light == "yellow":
print("Slow down")
elif light == "red":
print("Stop")
else:
print("Unknown signal")`}
/>

## Combining with and / or

Conditions in `if` and `elif` can use everything you learned:

<PythonExample
  filename="combined.py"
  code={`age = 22
country = "US"

if age < 18:
print("Too young")
elif age >= 18 and country == "US":
print("Eligible in US")
else:
print("Check local rules")`}
/>

## Common mistakes

<Callout variant="danger" title="elif after else">
  `else` must be **last**. You cannot write `elif` after `else`.
</Callout>

<Callout variant="warning" title="Separate if vs elif">
  Two separate `if` statements can both run. One `if` / `elif` chain runs **at most one**
  block. See the example below — both lines print because there are two independent `if`
  statements.
</Callout>

<PythonExample
  filename="two_if.py"
  code={`x = 10

if x > 5:
print("Greater than 5")

if x > 8:
print("Greater than 8")`}
/>

<Callout variant="tip">
  Draw a flowchart on paper for tricky logic — it helps you see whether you need `elif` or
  separate `if` statements.
</Callout>
