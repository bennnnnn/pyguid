## Why this matters

Most real decisions have more than two outcomes—grades, shipping tiers, command menus. elif keeps logic flat compared to nested ifs. else captures the default case so nothing falls through silently.

A traffic light is not just green or not-green — it can be yellow or red too. **`elif`** and **`else`** let Python pick exactly one branch from several options.

## One new idea: test conditions top to bottom

- **`elif`** — “else if” — another condition to test
- **`else`** — runs when **no** previous condition was true

Python checks from top to bottom and runs the **first** block that matches:

<PythonExample
  filename="grade.py"
  code={`score = 85

if score >= 90:
print("Grade: A")
elif score >= 80:
print("Grade: B")
elif score >= 70:
print("Grade: C")
else:
print("Grade: F")`}
/>

**Line by line**

- `score = 85` — only the `elif score >= 80` branch runs
- The `elif score >= 70` block is **not** run, even though 85 is also ≥ 70
- **`else`** has no condition — it is the fallback

| Structure                    | What runs             |
| ---------------------------- | --------------------- |
| `if` / `elif` chain          | **At most one** block |
| Two separate `if` statements | **Both** can run      |

## Real use case: traffic light

<PythonExample
  filename="traffic.py"
  code={`light = "yellow"

if light == "green":
print("Go")
elif light == "yellow":
print("Slow down")
elif light == "red":
print("Stop")
else:
print("Unknown signal")`}
/>

Conditions can use **`and`** / **`or`** from the previous chapter:

<PythonExample
  filename="combined.py"
  code={`age = 22
country = "US"

if age < 18:
print("Too young")
elif age >= 18 and country == "US":
print("Eligible in US")
else:
print("Check local rules")`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  `else` must be **last** — you cannot write `elif` after `else`.
</Callout>

<Callout variant="warning">
  Order matters. Put **stricter** tests before looser ones when ranges overlap — check `>= 90` before `>= 70`.
</Callout>

## Recap

- **`elif`** adds another condition to test
- **`else`** is the fallback with no condition
- Only **one** block in an `if` / `elif` / `else` chain runs
- Put more specific conditions **first**
