## Why this matters

Useful built-in functions shows up throughout Useful Built-in Functions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Python ships with a **toolbox** of ready-made functions — no `import` needed. These appear in almost every real script.

## One new idea: call them on your data

<PythonExample
  filename="builtins.py"
  code={`nums = [3, 1, 4, 1, 5]

print(len(nums))
print(sum(nums))
print(min(nums))
print(max(nums))
print(sorted(nums))
print(list(enumerate(["a", "b"])))`}
/>

| Function      | Job                 |
| ------------- | ------------------- |
| `len(x)`      | how many items      |
| `sum(list)`   | add numbers in list |
| `min` / `max` | smallest / largest  |
| `sorted(x)`   | new sorted list     |
| `enumerate`   | index + value pairs |

## zip, any, all

<PythonExample
  filename="more.py"
  code={`names = ["Ada", "Ben"]
scores = [90, 85]
for name, score in zip(names, scores):
    print(name, score)

print(any([False, True, False]))
print(all([True, True, False]))`}
/>

| Function | Meaning                    |
| -------- | -------------------------- |
| `zip`    | pair up two sequences      |
| `any`    | True if **one** is truthy  |
| `all`    | True if **all** are truthy |
