You mastered reading and writing one file. **`shutil`** (shell utilities) copies whole files, moves them, or duplicates folders — like drag-and-drop in the file manager, but in code.

## One new idea: copy and move

```python
import shutil
from pathlib import Path

src = Path("notes.txt")
dst = Path("backup/notes.txt")

dst.parent.mkdir(parents=True, exist_ok=True)
shutil.copy(src, dst)
shutil.move("old_name.txt", "new_name.txt")
```

| Function              | What it does             |
| --------------------- | ------------------------ |
| `shutil.copy(a, b)`   | copy file content        |
| `shutil.move(a, b)`   | move or rename           |
| `shutil.rmtree(path)` | delete folder + contents |

## Recap

- **`import shutil`** for file operations beyond read/write
- **`mkdir(parents=True, exist_ok=True)`** before copying into new folders
- Always test on **copies** first
