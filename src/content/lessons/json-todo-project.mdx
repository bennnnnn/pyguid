## Why this matters

Capstone: JSON todo list shows up throughout Python Standard Library and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Your **todo list** lived in memory. Your **notes app** used text files. This mini program stores todos as **JSON** — one file you can read, edit, and share.

## Data shape

```python
todos = [
    {"text": "Learn JSON", "done": False},
    {"text": "Build project", "done": False},
]
```

A **list of dicts** — JSON-friendly.

## Save and load (browser demo)

todos = [

**Line by line**

- `json.dumps` — Python → JSON string (`indent=2` pretty-prints)
- `json.loads` — JSON string → Python again
- Loop shows checkbox style output

## File version (local)

```python
import json
from pathlib import Path

PATH = Path("todos.json")

def load_todos():
    if not PATH.exists():
        return []
    return json.loads(PATH.read_text(encoding="utf-8"))

def save_todos(items):
    PATH.write_text(json.dumps(items, indent=2), encoding="utf-8")
```

Use **`"a"`** mode only for line logs; JSON files are usually **rewritten** whole with `write_text`.
