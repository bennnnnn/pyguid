## Why this matters

range() is the standard way to repeat a fixed number of times or index by position—printing times tables, numbering output, or pairing with len(). Confusing range with list indices causes off-by-one errors. Mastering start, stop, and step prevents many loop bugs.

A elevator display counts floors 1, 2, 3 without you typing each number. **`range()`** generates a sequence of numbers for loops the same way.

## One new idea: `range(stop)`, `range(start, stop)`, `range(start, stop, step)`

<PythonExample
  filename="range_stop.py"
  code={`for i in range(5):
    print(i)

for i in range(2, 6):
print(i)`}
/>

**Before → after**

| Call              | Numbers produced (stop is excluded) |
| ----------------- | ----------------------------------- |
| `range(5)`        | 0, 1, 2, 3, 4                       |
| `range(2, 6)`     | 2, 3, 4, 5                          |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8                       |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1                       |

<PythonExample
  filename="range_step.py"
  code={`for i in range(0, 10, 2):
    print(i)

for i in range(5, 0, -1):
print(i)`}
/>

## Real use case: repeat an action N times

<PythonExample
  filename="patterns.py"
  code={`for _ in range(3):
    print("Hello")

items = ["a", "b", "c"]
for i in range(len(items)):
print(i, items[i])`}
/>

Use **`_`** as the variable name when you do not need the loop value — common in `for _ in range(n):`.

You can turn a range into a list: `list(range(1, 6))` → `[1, 2, 3, 4, 5]`.

<Callout variant="warning">
  Prefer `for item in items:` over `for i in range(len(items)):` unless you specifically
  need the index.
</Callout>

## Recap

- **`range(stop)`** starts at 0 and stops **before** `stop`
- **`range(start, stop)`** and **`range(start, stop, step)`** control start and step
- The stop value is **never included**
- **`_`** means “I do not need this value”
