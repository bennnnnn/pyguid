You have learned the **tools** — `keys()`, `values()`, and `items()`. Now string them together like a **checklist**: what do you need from each entry — the label, the contents, or both?

## One new idea: three loop styles

<PythonExample
  filename="three_loops.py"
  code={`inventory = {"apple": 50, "banana": 30, "cherry": 10}

print("--- keys ---")
for item in inventory:
print(item)

print("--- values ---")
for count in inventory.values():
print(count)

print("--- items ---")
for item, count in inventory.items():
print(item, ":", count)`}
/>

**Line by line**

- `for item in inventory:` — keys only (default)
- `.values()` — counts only, no names
- `.items()` — **both** — usually the most useful

| Goal              | Loop                     |
| ----------------- | ------------------------ |
| Key names         | `for k in d:`            |
| Values only       | `for v in d.values():`   |
| Key **and** value | `for k, v in d.items():` |

## Real use case: filter into a new dict

<PythonExample
  filename="build.py"
  code={`scores = {"math": 40, "english": 85, "art": 92}
passed = {}

for subject, score in scores.items():
if score >= 60:
passed[subject] = score

print("Passed:", passed)`}
/>

Loop, decide, and **build** a new dictionary — a pattern you will use often.

## Nested dictionaries

<PythonExample
  filename="nested.py"
  code={`users = {
    "u1": {"name": "Ada", "active": True},
    "u2": {"name": "Ben", "active": False}
}

for user_id, info in users.items():
status = "online" if info["active"] else "offline"
print(user_id, info["name"], "→", status)`}
/>

Outer loop: user IDs. Inner dict: fields for each user.

<Callout variant="note" title="Oops — modifying while looping">
  Do not add or remove keys while looping over **`d.keys()`** directly. Loop over
  **`list(d.keys())`** if you must change the dict inside the loop.
</Callout>

## Recap

- **`for k in d:`** — keys; **`.values()`** — values; **`.items()`** — pairs
- Build new dicts by looping and assigning
- Nested dicts: outer **`.items()`**, then inner bracket access
