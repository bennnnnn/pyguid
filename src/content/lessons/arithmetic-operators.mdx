## Why this matters

Arithmetic is the language of counters, averages, game scores, and science scripts. / always giving float in Python 3 surprises newcomers who expect integer division. Knowing // and % upfront fixes loop and indexing mistakes.

Math class symbols meet Python: **`+` `-` `*` `/`** plus **`//` `%` `**`\*\* for whole division, remainders, and powers.

## One new idea: the seven arithmetic operators

<PythonExample
  filename="arith.py"
  code={`a = 17
b = 5
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** 2)`}
/>

| Operator | Name           | Example   | Result |
| -------- | -------------- | --------- | ------ |
| `+`      | add            | `17 + 5`  | `22`   |
| `-`      | subtract       | `17 - 5`  | `12`   |
| `*`      | multiply       | `17 * 5`  | `85`   |
| `/`      | divide (float) | `17 / 5`  | `3.4`  |
| `//`     | floor divide   | `17 // 5` | `3`    |
| `%`      | remainder      | `17 % 5`  | `2`    |
| `**`     | power          | `5 ** 2`  | `25`   |
