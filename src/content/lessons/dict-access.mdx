## Why this matters

Dicts map labels to values—JSON configs, user profiles, word counts. Wrong key access crashes programs with KeyError unless you use get() or in checks. items() unlocks clean loops over pairs without hunting keys twice.

Your locker has **labels on the doors**, not numbers on the rows. **`user["name"]`** is opening the door marked `"name"` — you get exactly what is stored inside.

## One new idea: bracket lookup

<PythonExample
  filename="brackets.py"
  code={`user = {"name": "Sam", "role": "admin"}
print(user["name"])
print(user["role"])`}
/>

**Line by line**

- `user["name"]` — key in quotes inside `[ ]`
- Returns the **value** tied to that key
- Keys must **match exactly** — `"Name"` and `"name"` are different keys

| Expression     | Result    |
| -------------- | --------- |
| `user["name"]` | `"Sam"`   |
| `user["role"]` | `"admin"` |

## Change a value or add a new key

<PythonExample
  filename="change.py"
  code={`user = {"name": "Sam", "age": 30}
user["age"] = 31
user["email"] = "sam@example.com"
print(user)`}
/>

- Existing key → **updates** the value
- New key → **adds** a new entry

## Real use case: update a game score

<PythonExample
  filename="score.py"
  code={`player = {"name": "Lin", "score": 0, "level": 1}

player["score"] = player["score"] + 100
player["level"] = 2

print(player["name"], "→ score:", player["score"], "level:", player["level"])`}
/>

## Check if a key exists

<PythonExample
  filename="in_dict.py"
  code={`user = {"name": "Sam"}
print("name" in user)
print("id" in user)

if "email" in user:
print(user["email"])
else:
print("No email on file")`}
/>

Use **`"key" in d`** before bracket access when the key might be missing.

<Callout variant="warning" title="Oops — Python is yelling">
  **`d["missing"]`** → **KeyError**. Either check with **`in`** first, or use **`.get()`**
  (next lessons) for a safe default.
</Callout>

<TryIt title="Try it yourself" answer="31">
  Start with `user = {"age": 30}`. Set `user["age"] = 31`. Print `user["age"]`.
</TryIt>

## Recap

- **`d["key"]`** reads or writes a value
- **New key** on the left of `=` **adds** an entry
- **`"key" in d`** checks membership before lookup
