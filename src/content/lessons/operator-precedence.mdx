In math class, multiplication happens before addition. Python follows similar **precedence** rules — unless **parentheses** change the order.

## One new idea: \* before +

<PythonExample
  filename="order.py"
  code={`print(2 + 3 * 4)
print((2 + 3) * 4)`}
/>

| Expression  | Result | Why               |
| ----------- | ------ | ----------------- |
| `2 + 3 * 4` | `14`   | `3*4` first → 12  |
| `(2+3) * 4` | `20`   | parentheses first |

## Quick reference (beginner)

| Higher priority (first) | Examples   |
| ----------------------- | ---------- |
| Parentheses             | `( )`      |
| Power                   | `**`       |
| Multiply / divide       | `* / // %` |
| Add / subtract          | `+ -`      |
| Comparisons             | `== < >=`  |
| `not`                   | `not x`    |
| `and`                   | `a and b`  |
| `or`                    | `a or b`   |

## Recap

- **`*` `/`** before **`+` `-`**
- **`()`** overrides everything
- When unsure, add parentheses — clarity beats guessing
