## Why this matters

enum — named constants shows up throughout Python Standard Library and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Magic strings like `"pending"` and `"done"` are easy to mistype. **Enums** give each choice a **name** and a **value** — autocomplete-friendly and readable.

## One new idea: Enum class

<PythonExample
  filename="enum_demo.py"
  code={`from enum import Enum

class Status(Enum):
PENDING = "pending"
DONE = "done"
FAILED = "failed"

task = Status.PENDING
print(task)
print(task.name)
print(task.value)

if task is Status.PENDING:
print("Still waiting")`}
/>

Compare with **`is`** or **`==`** to other enum members — not random strings.

## Why not plain strings?

| Approach         | Typos? | IDE help? |
| ---------------- | ------ | --------- |
| `"pendng"` typo  | yes    | no        |
| `Status.PENDING` | harder | yes       |

<Callout variant="tip">
  Use enums for **fixed sets**: order status, user roles, compass directions.
</Callout>

## Recap

- **`from enum import Enum`**
- Members are **`Name = value`**
- Safer than scattered string constants
