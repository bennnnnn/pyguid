## Why this matters

Mini project: Login checker shows up throughout Booleans and Conditions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A door checks **username** and **password** before you enter. You will code that decision tree with **`if`**, **`elif`**, **`else`**, and **`and`**.

## Simulated login (browser-safe)

<PythonExample
  filename="login.py"
  code={`# Simulated input
username = "ada"
password = "secret123"

correct_user = "ada"
correct_pass = "secret123"

if username == correct_user and password == correct_pass:
print("Welcome back!")
elif username != correct_user:
print("Unknown user")
else:
print("Wrong password")`}
/>

**Line by line**

- **`and`** — both must be true for success
- **`elif`** — wrong username path
- **`else`** — username OK but password wrong

## Stretch goals

- Count failed attempts with a counter
- Use **`in`** to block empty username `""`
- Add **`not`** for locked accounts

## Recap

- Real apps are **nested decisions**
- **`and`** combines conditions
- Order **`if` / `elif` / `else`** matters
