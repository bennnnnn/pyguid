A **.py** file runs top to bottom once. A **Jupyter notebook** runs **cells** in any order — great for experiments, charts, and teaching.

## Install and launch

```bash
pip install jupyterlab
jupyter lab
```

Creates a browser UI with code cells and markdown cells.

## Notebook mental model

| Cell type | Use for                 |
| --------- | ----------------------- |
| Code      | Python snippets, plots  |
| Markdown  | notes, headings, images |

Run one cell with **Shift+Enter**. Variables stay in memory until you restart the kernel.

## When to use notebooks

| Notebooks shine  | Use plain `.py` instead |
| ---------------- | ----------------------- |
| data exploration | production web apps     |
| classroom demos  | CLI tools with argparse |
| quick charts     | packages you publish    |

<Callout variant="tip">
  Export finished experiments into **modules** and **tests** — notebooks are scratchpads,
  not always the final app.
</Callout>
