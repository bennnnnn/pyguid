## Why this matters

Most first-week **`SyntaxError`** messages trace back to two families: **`"`** imbalance and **`(` `)`** imbalance. Drill the pattern visually and fixes take seconds instead of guessing.

## Missing closing quote

<PythonExample filename="open_string.py" code={`print("Hello)`} />

Run — Python wandered inside a **string forever** hunting the closing **`"`**.

**Fixed:**

<PythonExample filename="closed_string.py" code={`print("Hello")`} />

## Missing closing parenthesis

<PythonExample filename="open_paren.py" code={`print("Hello"`} />

Python hits end of line still “inside” **`print(...`**.

**Fixed:**

<PythonExample filename="closed_paren.py" code={`print("Hello")`} />

## Both layers at once — correct pattern

<PythonExample
  filename="balanced.py"
  code={`phrase = "Hi"
print(phrase)`}
/>

Quotes wrap **text**; parentheses wrap **`print`'s contents** — each layer closes cleanly.

## Recap

- **Every opening `"`** needs a closing **`"`**
- **Every opening `(` for a call like `print`** needs a matching **`)`**
- If lost, bracket-match from inside out—or paste the traceback line number and work backward
