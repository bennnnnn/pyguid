Getting into a concert takes two things: you must be old enough **and** have a ticket. Logical operators let Python combine several yes/no checks into one.

## One new idea: `and`, `or`, and `not`

| Operator | Meaning                        |
| -------- | ------------------------------ |
| `and`    | both parts must be true        |
| `or`     | at least one part must be true |
| `not`    | flip true to false (and back)  |

<PythonExample
  filename="and_example.py"
  code={`age = 25
has_id = True

result = age >= 18 and has_id
print(result)

age = 16
result = age >= 18 and has_id
print(result)`}
/>

**Line by line**

- `age >= 18 and has_id` — both must be true → `True`
- When `age` is 16, the first part is false → whole expression is `False`

<PythonExample
  filename="or_not.py"
  code={`day = "Saturday"
is_holiday = False

result = day == "Saturday" or day == "Sunday" or is_holiday
print(result)

is_closed = False
print(not is_closed)`}
/>

Use **parentheses** when mixing `and` and `or` so the meaning is clear:

<PythonExample
  filename="parens.py"
  code={`age = 20
has_ticket = True
is_vip = False

result = (age >= 18 and has_ticket) or is_vip
print(result)`}
/>

## Real use case: entry gate

<PythonExample
  filename="gate.py"
  code={`age = 25
has_id = True

if age >= 18 and has_id:
print("Entry allowed")
else:
print("Entry denied")`}
/>

You will use these operators heavily inside **`if`** in the next chapter.

<Callout variant="danger" title="Oops — Python is yelling">
  `if x > 0 and < 10` is invalid — each side must be a complete expression. Write `if x > 0 and x < 10:` instead.
</Callout>

<Callout variant="warning">
  If a condition feels long, split it into boolean variables: `can_edit = is_owner and
  is_logged_in`.
</Callout>

<TryIt title="Try it yourself" answer="True">
  Set `score = 85` and `bonus = True`. Print `score >= 60 and bonus`.
</TryIt>

## Recap

- **`and`** — both must be true
- **`or`** — at least one must be true
- **`not`** — reverses a boolean
- Use parentheses when mixing `and` and `or`
