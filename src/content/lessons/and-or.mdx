Use **`and`**, **`or`**, and **`not`** to combine boolean tests — for example, “old enough **and** has a ticket.” Comparisons give you one true/false answer; logical operators join several.

| Operator | Meaning                        |
| -------- | ------------------------------ |
| `and`    | both parts must be true        |
| `or`     | at least one part must be true |
| `not`    | flip true to false (and back)  |

## and

Both conditions must be true:

<PythonExample
  filename="and_example.py"
  code={`age = 25
has_id = True

result = age >= 18 and has_id
print(result)`}
/>

<PythonExample
  filename="and_false.py"
  code={`age = 16
has_id = True

result = age >= 18 and has_id
print(result)`}
/>

## or

At least one condition must be true:

<PythonExample
  filename="or_example.py"
  code={`day = "Saturday"
is_holiday = False

result = day == "Saturday" or day == "Sunday" or is_holiday
print(result)`}
/>

## Mixing and and or

Use **parentheses** when mixing operators so Python (and humans) know what you mean:

<PythonExample
  filename="parens.py"
  code={`age = 20
has_ticket = True
is_vip = False

result = (age >= 18 and has_ticket) or is_vip
print(result)`}
/>

## not

`not` reverses a boolean:

<PythonExample
  filename="not_example.py"
  code={`is_closed = False

result = not is_closed
print(result)`}
/>

## Using logical operators with if

You will use these operators heavily inside **`if`** in the next chapter. Preview:

<PythonExample
  filename="with_if.py"
  code={`age = 25
has_id = True

if age >= 18 and has_id:
print("Entry allowed")
else:
print("Entry denied")`}
/>

## Truth tables (quick reference)

**and** — only true when both are true:

- `True and True` → `True`
- `True and False` → `False`

**or** — true when at least one is true:

- `False or True` → `True`
- `False or False` → `False`

<Callout variant="tip">
  If a condition feels long, store parts in boolean variables: `can_edit = is_owner and
  is_logged_in`.
</Callout>

<Callout variant="warning" title="Each side must be complete">
  `age >= 18 and has_ticket` is valid — both sides are full expressions. `if x > 0 and < 10` is invalid.
</Callout>
