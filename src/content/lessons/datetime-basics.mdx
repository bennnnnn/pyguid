A wall calendar shows today’s date; a clock shows the exact moment. Python’s **`datetime`** module handles both — dates, times, and math between them.

## One new idea: date and datetime

<PythonExample
  filename="datetime.py"
  code={`from datetime import date, datetime

today = date.today()
print(today)
print(today.year, today.month, today.day)

now = datetime.now()
print(now)
print(now.hour, now.minute)`}
/>

**Line by line**

- `date.today()` — today’s date only
- `.year`, `.month`, `.day` — parts of a date
- `datetime.now()` — date **and** time right now

## Create a specific date

<PythonExample
  filename="create.py"
  code={`from datetime import date

birthday = date(2000, 5, 15)
print(birthday)
print(birthday.strftime("%B %d, %Y"))`}
/>

`strftime` formats a date as readable text.

## Real use case: date math with timedelta

<PythonExample
  filename="delta.py"
  code={`from datetime import date, timedelta

today = date.today()
in_one_week = today + timedelta(days=7)
print(today)
print(in_one_week)`}
/>

Add or subtract days for deadlines and reminders.

## Compare dates

<PythonExample
  filename="compare.py"
  code={`from datetime import date

a = date(2024, 1, 1)
b = date(2024, 6, 1)
print(a < b)`}
/>

Dates compare like numbers — earlier is “less than.”

<Callout variant="note">
  For time zones, use `datetime.timezone` or the third-party `zoneinfo` module (Python
  3.9+). Start with naive `date`/`datetime` first.
</Callout>

<Callout variant="tip">
  Store dates in ISO format strings (`"2024-05-23"`) in databases and JSON when you do not
  need time-of-day.
</Callout>

</TryIt>

## Recap

- **`date.today()`** / **`datetime.now()`** — current date or datetime
- **`timedelta(days=n)`** — add or subtract days
- **`strftime`** — format for display
