Two people share **one** notebook. If one person scribbles on page 3, the other sees it too. **`b = a`** for lists means **one notebook, two names** — not a photocopy.

## One new idea: assignment is not a copy

<PythonExample
  filename="reference.py"
  code={`a = [1, 2, 3]
b = a
b.append(4)
print("a:", a)
print("b:", b)`}
/>

**What happened**

| Step          | Reality                         |
| ------------- | ------------------------------- |
| `b = a`       | `b` points at the **same** list |
| `b.append(4)` | that list is now `[1, 2, 3, 4]` |
| `print(a)`    | **`a`** sees the change too     |

## Make a real copy: copy() or [:]

<PythonExample
  filename="copy.py"
  code={`a = [1, 2, 3]
b = a.copy()
b.append(4)
print("a:", a)
print("b:", b)`}
/>

**Before → after `b.append(4)`**

| Variable | List           |
| -------- | -------------- |
| `a`      | `[1, 2, 3]`    |
| `b`      | `[1, 2, 3, 4]` |

Another way: **`clone = original[:]`** (slice the whole list).

<PythonExample
  filename="slice_copy.py"
  code={`original = ["x", "y", "z"]
clone = original[:]
clone[0] = "changed"
print("original:", original)
print("clone:", clone)`}
/>

## Real use case: safe backup before editing

<PythonExample
  filename="backup.py"
  code={`scores = [88, 72, 95]
backup = scores.copy()

scores.sort()
print("Sorted:", scores)
print("Backup:", backup)`}
/>

## Shallow copy warning (nested lists)

<PythonExample
  filename="shallow.py"
  code={`a = [[1, 2], [3, 4]]
b = a.copy()
b[0].append(99)
print("a:", a)`}
/>

Both **`a`** and **`b`** still share the **inner** lists. For deep nesting, advanced code uses `copy.deepcopy()` — not required yet.

<Callout variant="danger" title="Oops — Python is yelling">
  **`b = a`** is **not** a copy. Use **`b = a.copy()`** or **`b = a[:]`** when edits to
  **`b`** must not touch **`a`**.
</Callout>

<TryIt title="Try it yourself" answer="[1, 2]">
  With `a = [1, 2]`, set `b = a.copy()`, `append(3)` to **`b` only**, print **`a`**.
</TryIt>

## Recap

- **`b = a`** — shared list
- **`b = a.copy()`** or **`b = a[:]`** — separate top-level list
- Shallow copy: inner lists may still be shared
