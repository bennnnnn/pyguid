A recipe card says “mix eggs and flour” once — you follow it every time you bake. A **function** is that card for code: write the steps **once**, **call** the name whenever you need them.

## One new idea: def and call

<PythonExample
  filename="hello_func.py"
  code={`def greet():
    print("Hello from a function")

greet()
greet()`}
/>

**Line by line**

- `def greet():` — define a function named `greet`
- Indented lines under `def` — the body runs only when you **call** it
- `greet()` — run the function (twice here)

Defining a function does **not** run its body. Only the **call** does.

## Pass data in with parameters

<PythonExample
  filename="params.py"
  code={`def greet(name):
    print(f"Hello, {name}")

greet("Ada")
greet("Lin")`}
/>

`name` is a **parameter** — a placeholder filled in when you call `greet("Ada")`.

## Multiple parameters

<PythonExample
  filename="multi.py"
  code={`def add(a, b):
    print(a + b)

add(3, 5)
add(10, 20)`}
/>

## Real use case: one place to change

<PythonExample
  filename="tax.py"
  code={`def price_with_tax(amount):
    tax = amount * 0.08
    return amount + tax

print(price_with_tax(10))
print(price_with_tax(25))`}
/>

If the tax rate changes, you edit **one function** — not every calculation in your program.

<Callout variant="note">
  Code inside a function runs only when you **call** it. Defining a function does not run
  its body.
</Callout>

<Callout variant="tip">
  If a block of code appears twice, turn it into a function. Change it in one place later.
</Callout>
