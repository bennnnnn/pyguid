## Why this matters

split() is the first tool for parsing user input, file lines, and URLs into workable pieces. Wrong delimiter assumptions create silent data corruption. Combining split with strip and join covers most beginner text-processing tasks.

A CSV row looks like one long string: `apple,banana,cherry`. **`split()`** is the knife that cuts it into separate pieces — a **list** of strings.

## One new idea: split on whitespace

With **no argument**, `split()` breaks on spaces, tabs, and newlines:

<PythonExample
  filename="split.py"
  code={`sentence = "Python is fun"
words = sentence.split()
print(words)`}
/>

**Before → after**

| `sentence`        | `words`                   |
| ----------------- | ------------------------- |
| `"Python is fun"` | `["Python", "is", "fun"]` |

## Split on a specific character

<PythonExample
  filename="split_comma.py"
  code={`csv = "apple,banana,cherry"
fruits = csv.split(",")
print(fruits)`}
/>

## Limit how many cuts

<PythonExample
  filename="maxsplit.py"
  code={`data = "one-two-three-four"
parts = data.split("-", 2)
print(parts)`}
/>

Only **2** splits → `["one", "two", "three-four"]` — the rest stays in the last piece.

## Real use case: read a data line

<PythonExample
  filename="user_row.py"
  code={`row = "ada,36,london"
parts = row.split(",")
name = parts[0]
age = parts[1]
city = parts[2]
print(name, "is", age, "from", city)`}
/>

<Callout variant="note">
  **`split()`** returns a **list**. Use **`join()`** (next lesson) to glue pieces back.
</Callout>

## Recap

- **`split()`** — default: whitespace
- **`split(",")`** — cut on commas
- Second argument limits number of splits
