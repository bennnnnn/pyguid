## Why this matters

What are data types? shows up throughout Data Types and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.


A toolbox has wrenches, tape, and glue — you do not use glue to tighten a bolt. **Data types** tell Python which “tool” fits each value: number math, text joining, or yes/no logic.

## One new idea: type decides behavior

<PythonExample
  filename="types_demo.py"
  code={`print("5" + "5")
print(5 + 5)
print(type("5"))
print(type(5))`}
/>

**Output**

```text
55
10
<class 'str'>
<class 'int'>
```

| Value | Type  | `+` means        |
| ----- | ----- | ---------------- |
| `"5"` | `str` | glue text → `55` |
| `5`   | `int` | add → `10`       |

## Core types in this chapter

| Type    | Example | Use for        |
| ------- | ------- | -------------- |
| `int`   | `42`    | whole counts   |
| `float` | `3.14`  | decimals       |
| `str`   | `"hi"`  | text           |
| `bool`  | `True`  | yes/no         |
| `None`  | `None`  | “no value yet” |

Later chapters add **list**, **tuple**, **set**, and **dict** — containers for many values.

## Recap

- Every value has a **type**
- The type controls what **operators** and **methods** work
- **`type(x)`** shows which type you have
