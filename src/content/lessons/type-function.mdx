Four kinds of luggage tags: **number**, **decimal**, **text**, **yes/no**. **`type()`** reads the tag when you are not sure what you are holding.

## The four core types — recap

| Type  | Example   | `type()` shows    |
| ----- | --------- | ----------------- |
| int   | `42`      | `<class 'int'>`   |
| float | `3.14`    | `<class 'float'>` |
| str   | `"hello"` | `<class 'str'>`   |
| bool  | `True`    | `<class 'bool'>`  |

<PythonExample
  filename="recap.py"
  code={`values = [42, 3.14, "hello", True]
for v in values:
    print(v, "->", type(v))`}
/>

## Division always makes float

<PythonExample
  filename="after_math.py"
  code={`result = 8 / 2
print(result)
print(type(result))`}
/>

Looks like `4` — but type is **`float`** (`4.0`).

## Convert types when you must

### str() — number to text for `+`

<PythonExample
  filename="str_convert.py"
  code={`age = 25
message = "You are " + str(age)
print(message)`}
/>

Without **`str(age)`**, **`"You are " + age`** → **TypeError**.

### int() and float() — text to numbers

<PythonExample
  filename="int_convert.py"
  code={`text = "42"
number = int(text)
print(number + 8)

price_text = "9.99"
price = float(price_text)
print(price + 1)`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  **`int("hello")`** → **ValueError**. The text must look like a real number.
</Callout>

## Same look, different type

<PythonExample
  filename="look_alike.py"
  code={`print(42, type(42))

/>

| ------ | ----- |

## Recap

- **`type(x)`** — what kind of value
- **`str` / `int` / `float`** — convert when mixing types
- **`+`** on strings needs **`str()`** for numbers
