## Why this matters

while loops fit input validation, game loops, and retry logic where repetition depends on state, not a fixed list. They also teach careful updates so the condition eventually becomes false. Understanding while prevents accidental infinite loops in real programs.

A microwave keeps heating **while** the timer is above zero. A **`while`** loop keeps running a block **as long as** its condition is `True`.

## One new idea: repeat while the condition is true

<PythonExample
  filename="while_basic.py"
  code={`count = 1
while count <= 5:
    print(count)
    count += 1`}
/>

**Line by line**

- `while count <= 5:` — check the condition before each round
- Indented lines run, then Python checks again
- `count += 1` changes the variable so the condition can eventually become false

<PythonExample
  filename="countdown.py"
  code={`n = 3
while n > 0:
    print(n)
    n -= 1
print("Go!")`}
/>

Lines at the normal indent (like `print("Go!")`) run **after** the loop finishes.

## Real use case: sum numbers 1 through 4

<PythonExample
  filename="total.py"
  code={`total = 0
number = 1
while number <= 4:
    total += number
    number += 1
print(total)`}
/>

Use **`while`** when you do not know how many repetitions you need in advance.

<Callout variant="danger" title="Oops — Python is yelling">
  If the condition never becomes false, you get an **infinite loop**. Always update a
  variable inside the loop (like `count += 1`) so the condition can eventually fail.
</Callout>

<Callout variant="warning">
  In the browser runner, an infinite loop may freeze the tab. If Run hangs, refresh and
  fix the loop logic.
</Callout>

## Recap

- **`while condition:`** repeats the indented block while the condition is `True`
- Update something inside the loop so it can end
- Code after the loop runs once the condition is false
