## Why this matters

zip() — pair lists together shows up throughout Lists and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Two columns on a spreadsheet — names and scores. **`zip()`** walks both lists **side by side**, one pair per step.

## One new idea: zip two lists

<PythonExample
  filename="zip_demo.py"
  code={`names = ["Ada", "Bob", "Chen"]
scores = [95, 88, 91]

for name, score in zip(names, scores):
print(name, "scored", score)`}
/>

**Line by line**

- `zip(names, scores)` — pairs `(Ada, 95)`, `(Bob, 88)`, …
- `for name, score in ...` — unpack each pair

## Turn zip into a list of tuples

<PythonExample
  filename="zip_list.py"
  code={`pairs = list(zip(["a", "b"], [1, 2]))
print(pairs)`}
/>

## Stops at the shorter list

<PythonExample
  filename="zip_short.py"
  code={`a = [1, 2, 3]
b = [10, 20]
print(list(zip(a, b)))`}
/>

Only **two** pairs — zip does not pad missing values.

<Callout variant="warning">
  Lists must be the **same idea** per position: index 0 of each list belongs together.
</Callout>

## Recap

- **`zip(a, b)`** — iterate pairs
- **`list(zip(...))`** — see all pairs at once
- Length = **shorter** list
