Websites speak **HTTP**. Python can **GET** a URL and read the response — weather APIs, JSON feeds, or HTML pages.

## Standard library: urllib

```python
from urllib.request import urlopen

with urlopen("https://example.com") as response:
    html = response.read().decode("utf-8")
    print(html[:200])
```

Runs with **no pip install**. Always use HTTPS URLs you trust.

## requests (third-party, popular)

```bash
pip install requests
```

```python
import requests

response = requests.get("https://api.github.com")
print(response.status_code)
print(response.json().keys())
```

| Tool     | Install  | API style   |
| -------- | -------- | ----------- |
| urllib   | built-in | lower-level |
| requests | pip      | friendly    |
