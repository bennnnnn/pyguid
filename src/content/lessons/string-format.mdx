## Why this matters

Formatted strings turn data into human-readable logs, receipts, and UI text. f-strings are fast to write and read compared to concatenation or old percent formatting. Format specs such as `:.2f` after a variable solve rounding display without manual string math.

Mad Libs: you fill blanks in a sentence. An **f-string** is the same — write a template with **`{holes}`** and Python drops variables in.

## One new idea: f-strings

Put **`f`** before the quotes. Inside **`{ }`**, put variables or math:

<PythonExample
  filename="fstring.py"
  code={`name = "Ada"
age = 36
print(f"My name is {name} and I am {age} years old.")
print(f"Next year: {age + 1}")`}
/>

**Line by line**

- `f"..."` — “format this string”
- `{name}` — value of `name`
- `{age + 1}` — expression computed first

## Format money-style numbers

<PythonExample
  filename="expr.py"
  code={'price = 19.99\nqty = 3\ntotal = price * qty\nprint(f"Total: {total:.2f}")'}
/>

`{total:.2f}` inside an f-string means “show as a float with 2 decimal places.”

## Real use case: scoreboard line

## Older styles (you may see in old code)

<PythonExample

/>

<Callout variant="tip">
  For new code, prefer **f-strings**. You already used them in the **Variables** chapter.
</Callout>

<Callout variant="warning" title="Oops — Python is yelling">
  **`"Age: " + age`** fails when `age` is a number. Use **`f"Age: {age}"`** instead.
</Callout>

## Recap

- **`f"{var}"`** — readable, modern default
- **`{expr}`** — any expression inside braces
- Avoid **`+`** between text and numbers
