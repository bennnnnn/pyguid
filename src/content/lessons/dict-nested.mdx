## Why this matters

Nested dictionaries shows up throughout Dictionaries and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A contact card can hold **address** details inside the same person. **Nested dicts** model JSON-like records: keys pointing to **more** dicts.

## One new idea: dict inside dict

<PythonExample
  filename="nested.py"
  code={`user = {
    "name": "Ada",
    "address": {
        "city": "London",
        "zip": "SW1A"
    }
}

print(user["name"])
print(user["address"]["city"])`}
/>

**Line by line**

- `user["address"]` — inner dict
- `["city"]` — key inside inner dict

## Real use case: simple catalog

<PythonExample
  filename="catalog.py"
  code={`products = {
    "p1": {"name": "Mouse", "price": 25},
    "p2": {"name": "Keyboard", "price": 80}
}

for pid, info in products.items():
print(pid, info["name"], info["price"])`}
/>

<Callout variant="tip">
  API and JSON data often look like **nested dicts** — practice bracket chaining.
</Callout>

## Recap

- **Outer key** → inner dict
- Chain brackets: **`d["a"]["b"]`**
- Loop with **`.items()`** on outer dict
