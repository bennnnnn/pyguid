  - question: "How is extend() different from append()?"
    answer: "append() adds one object as a single element. extend() unpacks an iterable and adds each value separately."
  - question: "Can I use extend() with a string?"

## Why this matters

extend() is the right tool when you already have a batch of items to merge—reading lines from a file, combining query results, or joining two lists. Using append() on a list by mistake gives [[1, 2]] instead of [1, 2]. Knowing extend saves hours of debugging nested lists.

You already know **`append()`** — one item at the end. **`extend()`** is like pouring a **whole second list** into the first, item by item.

## One new idea: merge another list’s items

<PythonExample
  filename="extend.py"
  code={`first = ["Ada", "Ben"]
second = ["Cara", "Dan"]
first.extend(second)
print(first)`}
/>

**Before → action → after**

| Step             | `first`                         |
| ---------------- | ------------------------------- |
| Start            | `["Ada", "Ben"]`                |
| `extend(second)` | add each item from `second`     |
| After            | `["Ada", "Ben", "Cara", "Dan"]` |

`second` is unchanged; only **`first`** grows.

## append() vs extend() — do not mix them up

<PythonExample
  filename="compare.py"
  code={`a = [1, 2]
b = [3, 4]

a.append(b)
print("append:", a)

c = [1, 2]
d = [3, 4]
c.extend(d)
print("extend:", c)`}
/>

| Method      | Result           | What happened                           |
| ----------- | ---------------- | --------------------------------------- |
| `append(b)` | `[1, 2, [3, 4]]` | **one** new element: the whole list `b` |
| `extend(d)` | `[1, 2, 3, 4]`   | **two** new elements: `3` and `4`       |

## Real use case: combine team rosters

<PythonExample
  filename="teams.py"
  code={`team_a = ["Sam", "Jo"]
team_b = ["Alex", "Riley"]

team_a.extend(team_b)
print("Everyone:", team_a)

/>

## extend() vs `+` (new list)

<PythonExample
  filename="plus_vs_extend.py"
  code={`x = [1, 2]
y = [3, 4]
x.extend(y)
print("extend changed x:", x)

a = [1, 2]
b = [3, 4]
c = a + b
print("a unchanged:", a)
print("c is new:", c)`}
/>

- **`extend()`** — changes the list you call it on; returns **`None`**
- **`a + b`** — builds a **new** list; leaves **`a`** and **`b`** alone

<Callout variant="warning" title="Oops — Python is yelling">
  **`extend()`** returns **`None`**, like **`append()`**. Do not write `result =
  my_list.extend(other)` expecting a new list.
</Callout>

</TryIt>

## Recap

- **`extend(iterable)`** adds **each** item from another collection
- **`append(list)`** adds the **whole** list as **one** element
- Use **`+`** when you need a **new** list without changing the original
