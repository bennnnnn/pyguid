A notebook on your desk holds notes you open and read later. A **file** on disk is the same — **`open()`** reads text so programs can use logs, configs, and data.

## One new idea: open and read

On your machine:

```python
with open("notes.txt", "r") as file:
    content = file.read()
    print(content)
```

**Line by line**

- `"r"` — **read** mode
- **`with`** — automatically closes the file when done
- `.read()` — entire file as one string

<Callout variant="note">
  The browser **Run code** button cannot open real files on your disk. The examples below
  simulate file content so you can practice the ideas.
</Callout>

## Real use case: process each line

<PythonExample
  filename="lines.py"
  code={`content = "apple\\nbanana\\ncherry"
for line in content.splitlines():
    print(line.upper())`}
/>

Read → split into lines → transform each line.

## Check file exists (concept)

On your computer you might use `import os` and `os.path.exists("file.txt")` before opening.

<Callout variant="tip">
  Always use `with open(...) as f:` so files close even if an error occurs.
</Callout>

<Callout variant="danger">
  Never open untrusted paths from user input without validation — path tricks can be a
  security risk.
</Callout>

</TryIt>

## Recap

- **`open(path, "r")`** — read a text file
- **`with`** — safe open/close
- **`.splitlines()`** — one string → list of lines
