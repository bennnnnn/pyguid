## Why this matters

Class methods shows up throughout Object-Oriented Python and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A dog knows its own name and can bark on command. **Methods** are functions **on** an object — they use **`self`** to read and change that object’s data.

## One new idea: methods and self

<PythonExample
  filename="methods.py"
  code={`class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        return f"{self.name} says woof!"

buddy = Dog("Buddy")
print(buddy.bark())`}
/>

**Line by line**

- `def bark(self):` — method; `self` is the dog you called it on
- `self.name` — this object’s name
- `buddy.bark()` — Python passes `buddy` as `self`

## Methods that change state

<PythonExample
  filename="state.py"
  code={`class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

    def reset(self):
        self.count = 0

c = Counter()
c.increment()
c.increment()
print(c.count)
c.reset()
print(c.count)`}
/>

## Real use case: readable print with **str**

<PythonExample
  filename="str.py"
  code={`class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Point({self.x}, {self.y})"

p = Point(3, 4)
print(p)`}
/>

`__str__` controls what `print()` shows.

## Class attribute vs instance attribute

<PythonExample
  filename="class_attr.py"
  code={`class Circle:
    pi = 3.14159

    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return Circle.pi * self.radius ** 2

c = Circle(5)
print(round(c.area(), 2))`}
/>

`pi` on the **class** is shared; `radius` on **`self`** is per circle.

<Callout variant="warning">
  Mutable class attributes (like a shared list) can surprise you — all instances share one
  list. Use `self.list = []` in `__init__` instead.
</Callout>

## Recap

- **Methods** — functions inside a class, first arg is `self`
- **`self.attr`** — read or write instance data
- **`__str__`** — friendly string for `print()`
