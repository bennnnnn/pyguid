Python’s **standard library** includes batteries: **`math`** for precise calculations, **`random`** for games and simulations.

## One new idea: import and use

<PythonExample
  filename="math_demo.py"
  code={`import math

print(math.sqrt(16))
print(math.ceil(4.2))
print(math.floor(4.8))
print(round(math.pi, 2))`}
/>

| Function     | Example result |
| ------------ | -------------- |
| `sqrt(16)`   | `4.0`          |
| `ceil(4.2)`  | `5`            |
| `floor(4.8)` | `4`            |

## random module

<PythonExample
  filename="random_demo.py"
  code={`import random

print(random.randint(1, 6))
print(random.choice(["red", "green", "blue"]))`}
/>

`randint(1, 6)` — dice roll. **`choice`** picks from a list.

<Callout variant="note">
  Skulpt in the browser may not support every **`random`** feature. Test games locally.
</Callout>

## Recap

- **`import math`** / **`import random`**
- Use for games, stats, geometry
- Standard library — no `pip` needed
