A folder of `.py` files becomes a **package** others can install. Modern projects use **`pyproject.toml`** at the root to declare the name, version, and dependencies.

## Minimal layout

```text
mytool/
  pyproject.toml
  src/
    mytool/
      __init__.py
      cli.py
  tests/
    test_cli.py
```

## pyproject.toml teaser

```toml
[project]
name = "mytool"
version = "0.1.0"
description = "My CLI helper"
requires-python = ">=3.10"
dependencies = []

[project.scripts]
mytool = "mytool.cli:main"
```

`[project.scripts]` creates a command **`mytool`** that calls **`main()`** in `cli.py` after install.

## Install locally (editable)

```bash
cd mytool
pip install -e .
mytool --help
```

`-e` means “editable” — code changes apply without reinstalling.

<Callout variant="note">
  Publishing to PyPI is an extra step. Learn layout and **`pip install -e .`** first.
</Callout>
