Raw **sqlite3** SQL works. **SQLAlchemy** maps **classes** to **tables** so you query with Python attributes instead of hand-written SQL everywhere.

## Install

```bash
pip install sqlalchemy
```

## Minimal model (local)

```python
from sqlalchemy import create_engine, String, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session

class Base(DeclarativeBase):
    pass

class Todo(Base):
    __tablename__ = "todos"
    id: Mapped[int] = mapped_column(primary_key=True)
    text: Mapped[str] = mapped_column(String(200))

engine = create_engine("sqlite:///todos.db")
Base.metadata.create_all(engine)

with Session(engine) as session:
    session.add(Todo(text="Learn ORM"))
    session.commit()
    for row in session.scalars(select(Todo)):
        print(row.text)
```

## ORM vs raw SQL

| sqlite3           | SQLAlchemy ORM         |
| ----------------- | ---------------------- |
| SQL strings       | classes + session      |
| manual rows       | objects with attrs     |
| fine for learning | scales for bigger apps |
