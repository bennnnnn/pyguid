## Why this matters

Scope explains why a variable inside a function does not clobber an outer name—and when it accidentally does. Misusing global creates hidden coupling between functions. Understanding LEGB makes closures, defaults, and debugging NameError straightforward.

A name tag at a party works **inside the room** — not on the street. **Scope** is where a variable name is valid: inside one function, or everywhere in the file.

## One new idea: local variables

Variables created inside a function are **local** — they exist only inside that function:

<PythonExample
  filename="local.py"
  code={`def greet():
    message = "Hello"
    print(message)

greet()

# print(message) # would error outside greet`}

/>

**Line by line**

- `message = "Hello"` — created **inside** `greet`
- Works inside the function
- Outside `greet`, `message` does not exist

## Parameters are local too

<PythonExample
  filename="param_local.py"
  code={`def double(n):
    n = n * 2
    return n

x = 5
print(double(x))
print(x)`}
/>

`x` outside the function is unchanged — `n` is a separate local copy.

## Real use case: read a global, pass data in

Functions can **read** global variables:

<PythonExample
  filename="read_global.py"
  code={`tax_rate = 0.08

def price_with_tax(amount):
return amount + amount \* tax_rate

print(price_with_tax(100))`}
/>

Prefer passing values as **parameters** instead of relying on many globals.

## global keyword (use sparingly)

To **change** a global variable inside a function:

<PythonExample
  filename="global_kw.py"
  code={`counter = 0

def increment():
global counter
counter += 1

increment()
increment()
print(counter)`}
/>

<Callout variant="warning">
  Relying on many global variables makes programs hard to debug. Prefer passing values as
  parameters and returning results.
</Callout>

<Callout variant="tip">
  If a function needs many globals, consider passing a dictionary or a small class later.
</Callout>

  }

Change `price`, `qty`, or `TAX_RATE`. Notice each function has its own local names but shares the global rate.

## Recap

- **Local** — created inside a function; gone outside
- **Parameters** — local copies; outside variables stay unchanged
- **Global** — readable everywhere; use `global` to reassign (sparingly)
