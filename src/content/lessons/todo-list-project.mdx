Sticky notes on a fridge — add a task, read them all, cross one off. A **todo list** is your first **data + menu loop** app using only lists.

## In-memory todo (browser-safe)

<PythonExample
  filename="todo.py"
  code={`todos = []

def add_task(text):
todos.append(text)

def show_tasks():
if not todos:
print("Nothing to do!")
return
for i, task in enumerate(todos, start=1):
print(f"{i}. {task}")

def mark_done(index):
if 1 <= index <= len(todos):
removed = todos.pop(index - 1)
print("Done:", removed)

add_task("Learn zip()")
add_task("Finish todo project")
show_tasks()
mark_done(1)
print("---")
show_tasks()`}
/>

**Line by line**

- **`append`** — add to the end
- **`enumerate(..., start=1)`** — human-friendly numbering
- **`pop(index - 1)`** — convert 1-based menu to 0-based list index
