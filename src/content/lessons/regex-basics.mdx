## Why this matters

Regular expressions shows up throughout Python Standard Library and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A search filter: “find anything that looks like an email” instead of matching one exact word. **Regular expressions** (regex) describe **patterns** in text — Python’s **`re`** module finds and replaces them.

## One new idea: re.search

<PythonExample
  filename="search.py"
  code={`import re

text = "My email is ada@example.com"
match = re.search(r"\\w+@\\w+\\.\\w+", text)
if match:
print("Found:", match.group())`}
/>

**Line by line**

- `r"\\w+@..."` — **raw string** pattern (email-like shape)
- `re.search(pattern, text)` — first match anywhere in the text
- `match.group()` — the matched substring

## Common patterns

| Pattern | Meaning        |
| ------- | -------------- |
| `\\d`   | digit          |
| `\\w`   | word character |
| `\\s`   | whitespace     |
| `.`     | any character  |
| `+`     | one or more    |
| `*`     | zero or more   |

## Real use case: find all numbers

<PythonExample
  filename="digits.py"
  code={`import re

text = "Order 42 ships in 3 days"
numbers = re.findall(r"\\d+", text)
print(numbers)`}
/>

## Replace with re.sub

<PythonExample
  filename="replace.py"
  code={`import re

phone = "555-123-4567"
clean = re.sub(r"-", "", phone)
print(clean)`}
/>

## Compile for reuse

<PythonExample
  filename="compile.py"
  code={`import re

pattern = re.compile(r"^\\d{3}-\\d{4}$")
print(bool(pattern.match("555-1234")))`}
/>

<Callout variant="warning">
  Regex can get hard to read quickly. For simple tasks, try `in`, `.startswith()`, or
  `.split()` first.
</Callout>

<Callout variant="tip">
  Raw strings `r"\\d+"` avoid doubling backslashes in patterns.
</Callout>

## Recap

- **`re.search`** — find first match; **`re.findall`** — all matches
- **`re.sub`** — replace by pattern
- Start with **simple string methods**; reach for regex when patterns get complex
