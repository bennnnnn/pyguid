## Why this matters

Mini project: Grade checker shows up throughout Booleans and Conditions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

School apps turn a **number** into a **letter**. Practice **`if`**, **`elif`**, and comparisons with a small grade checker.

## Rules (example)

| Score    | Grade |
| -------- | ----- |
| 90+      | A     |
| 80–89    | B     |
| 70–79    | C     |
| 60–69    | D     |
| below 60 | F     |

<PythonExample
  filename="grades.py"
  code={`scores = [95, 82, 71, 58]

for score in scores:
if score >= 90:
letter = "A"
elif score >= 80:
letter = "B"
elif score >= 70:
letter = "C"
elif score >= 60:
letter = "D"
else:
letter = "F"
print(score, "->", letter)`}
/>

## With input (local Python)

```python
score = int(input("Score: "))
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
# ... continue the chain
```

<Callout variant="warning">
  Check that the score is between 0 and 100 before grading — invalid scores deserve their
  own message.
</Callout>

## Recap

- **`elif`** handles multiple ranges in order
- Test **highest** thresholds first (90 before 80)
- Combine with **`input()`** and **`int()`** for interactive tools
