Before sending an email you glance for **`@`** — is this even an address? The **`in`** operator does that glance for any piece of text inside a string.

## One new idea: substring in string

<PythonExample
  filename="in.py"
  code={`email = "user@example.com"
print("@" in email)
print("password" in email)`}
/>

| Test                  | Result  |
| --------------------- | ------- |
| `"@" in email`        | `True`  |
| `"password" in email` | `False` |

## not in — when it is missing

<PythonExample
  filename="not_in.py"
  code={`word = "Python"
if " " not in word:
    print("One word, no spaces")`}
/>

## Real use case: simple validation

<PythonExample
  filename="validate.py"
  code={`username = "ada42"
has_space = " " in username
print("Has space:", has_space)

if " " not in username:
print("Username OK for this lesson")`}
/>

## in vs find()

| Goal         | Use                   |
| ------------ | --------------------- |
| Is it there? | **`"py" in text`**    |
| Where is it? | **`text.find("py")`** |

<Callout variant="note">
  **`in`** is the Pythonic way to ask “does this string contain that piece?”
</Callout>

## Recap

- **`x in s`** → `True` / `False`
- **`x not in s`** — opposite
- Use with **`if`** for simple checks
