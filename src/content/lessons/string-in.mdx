## Why this matters

in and not in shows up throughout Strings and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Before sending an email you glance for **`@`** — is this even an address? The **`in`** operator does that glance for any piece of text inside a string.

## One new idea: substring in string

<PythonExample
  filename="in.py"
  code={`email = "user@example.com"
print("@" in email)
print("password" in email)`}
/>

| Test                  | Result  |
| --------------------- | ------- |
| `"@" in email`        | `True`  |
| `"password" in email` | `False` |

## in vs find()

| Goal         | Use                   |
| ------------ | --------------------- |
| Is it there? | **`"py" in text`**    |
| Where is it? | **`text.find("py")`** |

<Callout variant="note">
  **`in`** is the Pythonic way to ask “does this string contain that piece?”
</Callout>

## Recap

- **`x in s`** → `True` / `False`
- **`x not in s`** — opposite
- Use with **`if`** for simple checks
