In a cookbook margin you scribble “use less salt” — the oven ignores it, but **you** remember why. **Comments** are those margin notes in code: for **humans**, not the computer.

## One new idea: `#` starts a comment

<PythonExample
  filename="comments.py"
  code={`# This line is a comment — Python skips it
print("This line runs")`}
/>

Only **`print("This line runs")`** executes.

## Comment at the end of a line

<PythonExample filename="inline.py" code={`print(10 + 5)  # adds 10 and 5`} />

Everything after **`#`** on that line is ignored.

## Good comments explain _why_

<PythonExample
  filename="why.py"
  code={`# Example sales tax for the lesson (not real tax advice)
tax_rate = 0.08
price = 50
print(price * tax_rate)`}
/>

<Callout variant="tip">
  Prefer clear names (`tax_rate`, `price`) over comments that repeat the obvious. Comment
  when the **reason** is not clear from the code.
</Callout>

## `#` inside quotes is not a comment

<PythonExample filename="in_string.py" code={`print("Hello # still printed")`} />

The `#` is **part of the text** because it is inside quotes.

## Comment out code to test

<PythonExample
  filename="disable.py"
  code={`print("Version A")
# print("Version B")
print("Done")`}
/>

Only **Version A** and **Done** print — **Version B** is “turned off” without deleting it.

<Callout variant="danger" title="Oops — Python is yelling">
  Do not put `#` in the **middle** of a string without closing quotes — you get a **syntax
  error**. Finish the string first, then comment on the next line.
</Callout>

## Chapter 1 mini project: first program

Combine **print**, **order**, and **comments**:

<PythonExample
  filename="first_program.py"
  code={`# My first PyGuide program
print("=== Welcome ===")

print("Step 1: Learn Python")
print("Step 2: Practice every day")
print("Step 3: Build something fun")

# print("Secret step — uncomment me later!")

print("=== Done ===")`}
/>

Change the three steps to your own goals. Uncomment the secret line and run again.

## Recap

- **`#`** — comment to end of line
- Comments do **not** run
- Use them for **why**, not obvious **what**
