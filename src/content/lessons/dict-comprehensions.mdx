## Why this matters

Dict comprehensions invert lists into lookup tables, tally counts, and transform JSON fields compactly. They mirror list comprehensions, so learning both keeps Python code idiomatic. When logic grows complex, switch back to a regular loop for clarity.

List comprehensions build lists; **dict comprehensions** build **`{key: value}`** dicts in one readable line.

## One new idea: dict comprehension syntax

<PythonExample
  filename="dictcomp.py"
  code={`nums = [1, 2, 3, 4]
squares = {n: n * n for n in nums}
print(squares)`}
/>

| Input `nums` | Result dict             |
| ------------ | ----------------------- |
| `[1,2,3,4]`  | `{1:1, 2:4, 3:9, 4:16}` |

## With a filter

<PythonExample
  filename="filter.py"
  code={`words = ["apple", "pie", "banana"]
long_words = {w: len(w) for w in words if len(w) > 3}
print(long_words)`}
/>

## Swap keys and values (when values are unique)

<PythonExample
  filename="swap.py"
  code={`original = {"a": 1, "b": 2}
flipped = {v: k for k, v in original.items()}
print(flipped)`}
/>

<Callout variant="warning">
  If values repeat, flipping keys **collides** — last one wins. Only swap when values are
  unique.
</Callout>

## Recap

- **`{k: v for item in iterable}`**
- Optional **`if`** filter
- Same spirit as list comprehensions
