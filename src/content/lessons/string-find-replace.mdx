## Why this matters

find() and replace shows up throughout Strings and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

You Ctrl+F in a document: **find** where a word starts, **replace** it with another. Python strings have the same tools built in.

## One new idea: find() returns position or -1

<PythonExample
  filename="find.py"
  code={`text = "Learn Python"
print(text.find("Python"))
print(text.find("Java"))`}
/>

| Search     | Result | Meaning              |
| ---------- | ------ | -------------------- |
| `"Python"` | `6`    | found at index 6     |
| `"Java"`   | `-1`   | not found (no crash) |

## find() vs index()

**`index()`** is like `find()` but **raises ValueError** if missing — use `find()` when “maybe not there” is normal.

## replace() — new string, old unchanged

<PythonExample
  filename="replace.py"
  code={`msg = "I like cats"
new_msg = msg.replace("cats", "dogs")
print(new_msg)
print(msg)`}
/>

**Before → after**

| Variable  | Value           |
| --------- | --------------- |
| `msg`     | `"I like cats"` |
| `new_msg` | `"I like dogs"` |

## Limit how many replacements

<PythonExample
  filename="count_replace.py"
  code={`data = "ha ha ha"
print(data.replace("ha", "ho", 2))`}
/>

Only the **first two** `"ha"` become `"ho"`.

## Real use case: clean a word

<PythonExample
  filename="censor.py"
  code={`tweet = "I love Python programming"
clean = tweet.replace("Python", "Python 🐍")
print(clean)`}
/>

## Recap

- **`find()`** → index or **`-1`**
- **`replace(old, new)`** → new string
- Use **`in`** for yes/no checks (next pages)
