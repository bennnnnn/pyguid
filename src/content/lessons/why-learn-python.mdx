## Why this matters

Time is limited. **Why Python?** is a fair question before you invest weeks of practice.

## Practical reasons

| Reason | What it means for you |
| ------ | --------------------- |
| **Jobs** | Many roles list Python (developer, analyst, QA, ops) |
| **Free** | Download and tools cost nothing to start |
| **Readable** | You learn ideas, not puzzle syntax |
| **Community** | Tutorials, forums, open-source examples |
| **Libraries** | Ready-made code for web, data, PDFs, APIs |

You do not need to be “good at math.” **Logic, patience, and practice** matter more for the first months.

## Skills that transfer

Python teaches:

- Breaking problems into steps
- Debugging when output is wrong
- Reading documentation
- Testing small changes

Those habits help in **any** language or tool you learn later.

## Realistic expectations

- Week 1: read, run, change `print`, fix quotes
- Month 1: variables, `if`, loops, small scripts
- Month 3+: functions, files, bigger mini projects

Progress is **not** linear. Plateaus are normal.

<Callout variant="tip">
  Learn by doing: one lesson, one Run click, one tiny change. That beats watching long videos without typing.
</Callout>

## Recap

- Python is **popular, free, and readable**
- You build **transferable** problem-solving skills
- **Short daily practice** beats rare marathon sessions
