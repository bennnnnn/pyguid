Write to files with **`open(path, mode)`**:

| Mode | Meaning                          |
| ---- | -------------------------------- |
| `"w"` | Write (creates or **overwrites**) |
| `"a"` | Append to the end                 |

## Write text (on your computer)

```python
with open("output.txt", "w") as file:
    file.write("Hello, file!\n")
    file.write("Second line\n")
```

## Append

```python
with open("log.txt", "a") as file:
    file.write("New log entry\n")
```

<Callout variant="warning">
  Mode `"w"` **deletes** existing content. Use `"a"` to add without erasing, or confirm before overwriting.
</Callout>
