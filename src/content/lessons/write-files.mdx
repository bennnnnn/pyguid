## One new idea: write and append modes

| Mode  | Meaning                           |
| ----- | --------------------------------- |
| `"w"` | Write (creates or **overwrites**) |
| `"a"` | Append to the end                 |

On your computer:

```python
with open("output.txt", "w") as file:
    file.write("Hello, file!\n")
    file.write("Second line\n")
```

Append without erasing:

```python
with open("log.txt", "a") as file:
    file.write("New log entry\n")
```

<Callout variant="warning">
  Mode `"w"` **deletes** existing content. Use `"a"` to add without erasing, or confirm

</Callout>

  when files grow large.
</Callout>

- **`"a"`** — append to the end
