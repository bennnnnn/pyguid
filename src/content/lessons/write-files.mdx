A whiteboard you erase and rewrite vs a logbook you add to at the bottom. **Write mode** replaces a file; **append mode** adds without erasing.

## One new idea: write and append modes

| Mode  | Meaning                           |
| ----- | --------------------------------- |
| `"w"` | Write (creates or **overwrites**) |
| `"a"` | Append to the end                 |

On your computer:

```python
with open("output.txt", "w") as file:
    file.write("Hello, file!\n")
    file.write("Second line\n")
```

Append without erasing:

```python
with open("log.txt", "a") as file:
    file.write("New log entry\n")
```

<Callout variant="warning">
  Mode `"w"` **deletes** existing content. Use `"a"` to add without erasing, or confirm
  before overwriting.
</Callout>

<Callout variant="tip">
  For CSV or JSON data, use the `csv` and `json` modules instead of manual string building
  when files grow large.
</Callout>

## Recap

- **`"w"`** — create or overwrite
- **`"a"`** — append to the end
- **`"\\n".join(lines)`** — one string ready to save
