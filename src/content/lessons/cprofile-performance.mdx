## Why this matters

Profiling with cProfile shows up throughout Debugging Python Code and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Your program works but feels slow. **cProfile** counts how often each function runs and how long it spends — a map of hotspots.

## Run from terminal

```bash
python -m cProfile -s cumulative script.py
```

`-s cumulative` sorts by total time including subcalls.

## Programmatic teaser

```python
import cProfile

def slow():
    total = 0
    for i in range(100_000):
        total += i * i
    return total

cProfile.run("slow()")
```

## Read the output

| Column    | Meaning                 |
| --------- | ----------------------- |
| `ncalls`  | how many calls          |
| `tottime` | time in function only   |
| `cumtime` | time including children |

<Callout variant="tip">
  Optimize only after profiling — guessing the slow line is often wrong.
</Callout>
