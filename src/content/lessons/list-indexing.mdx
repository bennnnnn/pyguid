A parking garage labels spots **0, 1, 2** from the entrance — not 1, 2, 3. Python lists count positions from **`0`** the same way.

## One new idea: index with `[ ]`

<PythonExample
  filename="access.py"
  code={`colors = ["red", "green", "blue"]
print(colors[0])
print(colors[1])
print(colors[2])`}
/>

| Index | Item      |
| ----- | --------- |
| `0`   | `"red"`   |
| `1`   | `"green"` |
| `2`   | `"blue"`  |

**Line by line**

- `colors[0]` — first item
- `colors[1]` — second item
- `colors[2]` — third item

## Change one item (lists are mutable)

<PythonExample
  filename="change.py"
  code={`colors = ["red", "green", "blue"]
colors[1] = "yellow"
print(colors)`}
/>

**Before → after**

| Before index `1` | After      |
| ---------------- | ---------- |
| `"green"`        | `"yellow"` |

Full list: `["red", "yellow", "blue"]`

## Negative indexes: count from the end

<PythonExample
  filename="negative.py"
  code={`items = [10, 20, 30, 40, 50]
print(items[-1])
print(items[-2])`}
/>

| Index | Item                   |
| ----- | ---------------------- |
| `-1`  | last (`50`)            |
| `-2`  | second from end (`40`) |

## Slicing: a piece of the list

`[start:end]` — **`end` is not included**

<PythonExample
  filename="slice.py"
  code={`nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])
print(nums[:3])
print(nums[2:])`}
/>

| Slice   | Result         | Meaning              |
| ------- | -------------- | -------------------- |
| `[1:4]` | `[1, 2, 3]`    | index 1 up to, not 4 |
| `[:3]`  | `[0, 1, 2]`    | from start           |
| `[2:]`  | `[2, 3, 4, 5]` | from index 2 to end  |

## Common mistakes

<Callout variant="danger" title="Oops — Python is yelling">
  **`colors[99]`** when the list is shorter → **IndexError**. Valid indexes: `0` through
  **`len(colors) - 1`** (or negative shortcuts).
</Callout>

<Callout variant="warning">
  **`colors[3] = "pink"`** does **not** grow a list with only 3 items (indexes `0`–`2`).
  Use **`append()`** or **`insert()`** to add new slots.
</Callout>

<TryIt title="Try it yourself" answer="banana">
  With `fruits = ["apple", "banana", "cherry"]`, print the item at index `1`.
</TryIt>

## Recap

- Indexes start at **`0`**
- **`list[i] = new`** changes one item
- **`list[start:end]`** copies a slice; **`end`** is excluded
- **`-1`** is the last item

Next: **`append()`** — add one item to the end.
