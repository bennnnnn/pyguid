## Why this matters

String slicing powers prefixes, extensions, and parsing fixed-width fields without regex. Because strings are immutable, slices always produce new text. Mastering slice notation transfers directly to lists and bytes.

A word on a strip of paper: you can read the **whole** word or highlight **letters 2–4**. **Slicing** `text[start:end]` highlights a piece — **`end` is not included**.

## One new idea: [start:end]

<PythonExample
  filename="slice.py"
  code={`text = "Python"
print(text[0:3])
print(text[2:])
print(text[:4])`}
/>

| Slice   | Result   | Meaning         |
| ------- | -------- | --------------- |
| `[0:3]` | `"Pyt"`  | index 0,1,2     |
| `[2:]`  | `"thon"` | from index 2 on |
| `[:4]`  | `"Pyth"` | up to, not 4    |

Same rules as list slicing (you will use these everywhere).

## Negative indexes

<PythonExample
  filename="neg_slice.py"
  code={`text = "Programming"
print(text[-3:])
print(text[:-1])`}
/>

| Slice   | Result       |
| ------- | ------------ |
| `[-3:]` | last 3 chars |
| `[:-1]` | all but last |

## Step: every second letter, reverse

<PythonExample
  filename="step.py"
  code={`text = "abcdef"
print(text[::2])
print(text[::-1])`}
/>

| Slice    | Effect              |
| -------- | ------------------- |
| `[::2]`  | every 2nd character |
| `[::-1]` | reversed copy       |

## Real use case: hide part of an email

<PythonExample
  filename="mask.py"
  code={`email = "ada@example.com"
name = email[:3]
domain = email[email.find("@"):]
print(name + "***" + domain)`}
/>

## Recap

- **`[start:end]`** — `end` excluded
- **`[:]`** — whole copy
- **`[::-1]`** — reversed copy
