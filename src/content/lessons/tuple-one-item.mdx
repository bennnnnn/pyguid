## Why this matters

One-item tuples shows up throughout Tuples and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Parentheses alone do not always make a tuple. **`(42)`** is just the number 42. **`(42,)`** — comma included — is a **one-item tuple**.

## One new idea: the trailing comma

| Expression | Type    |
| ---------- | ------- |
| `(42)`     | `int`   |
| `(42,)`    | `tuple` |

## Real use case: single return value

Functions often return tuples. One value still uses a comma for consistency:

```python
def only_x():
    return (100,)
```

## Recap

- **One-item tuple** needs a **comma**: `(x,)`
- **`(x)`** is not a tuple — just grouped math
