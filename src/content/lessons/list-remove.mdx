You cross **one** line off a shopping list — the first line that says “milk,” not every “milk” in the notebook. **`remove(value)`** deletes the **first** item that matches that value.

## One new idea: delete by value

<PythonExample
  filename="remove.py"
  code={`pets = ["cat", "dog", "bird", "dog"]
pets.remove("dog")
print(pets)`}
/>

**Before → action → after**

| Before                          | After `remove("dog")`    |
| ------------------------------- | ------------------------ |
| `["cat", "dog", "bird", "dog"]` | `["cat", "bird", "dog"]` |

Only the **first** `"dog"` is gone. The second `"dog"` stays.

## Real use case: unsubscribe one email

<PythonExample
  filename="unsub.py"
  code={`subscribers = ["ada@x.com", "ben@x.com", "cara@x.com"]
to_remove = "ben@x.com"

subscribers.remove(to_remove)
print("Still subscribed:", subscribers)`}
/>

## Safe remove: check first

If the value is **not** in the list, **`remove()`** raises **ValueError**.

<PythonExample
  filename="remove_safe.py"
  code={`items = ["a", "b", "c"]
target = "z"

if target in items:
items.remove(target)
print("Removed")
else:
print("Not found")

print(items)`}
/>

## remove() vs pop()

| Method          | You know…     | Returns          |
| --------------- | ------------- | ---------------- |
| `remove(value)` | the **value** | `None`           |
| `pop(index)`    | the **index** | the removed item |

<PythonExample
  filename="vs_pop.py"
  code={`nums = [10, 20, 30]
nums.remove(20)
print("after remove:", nums)

letters = ["a", "b", "c"]
gone = letters.pop(1)
print("pop returned:", gone)
print("after pop:", letters)`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  **`items.remove("z")`** when `"z"` is missing → **ValueError**. Use **`if "z" in
  items`** first, or handle the error later with `try/except`.
</Callout>

<TryIt title="Try it yourself" answer='["red", "blue"]'>
  With `colors = ["red", "green", "blue"]`, `remove("green")`. Print `colors`.
</TryIt>

## Recap

- **`remove(x)`** deletes the **first** match of **`x`**
- Returns **`None`**; the list changes in place
- Use **`pop()`** when you care about **position** or want the removed value back
