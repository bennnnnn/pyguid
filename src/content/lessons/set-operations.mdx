## Why this matters

Set operations shows up throughout Sets and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.


Two friend groups on a diagram: some people overlap, some are only in one circle. **Set operations** answer those questions in code — who is in **both**, **either**, or **only one** group.

## One new idea: union — everything from both sets

<PythonExample
  filename="union.py"
  code={`a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)
print(a.union(b))`}
/>

**Line by line**

- `a | b` — all items from **a** or **b** (duplicates merged)
- `a.union(b)` — same result, reads clearly in longer code
- Result: `{1, 2, 3, 4, 5}`

| Operation      | Symbol | Method                    | Meaning                      |
| -------------- | ------ | ------------------------- | ---------------------------- | --------------------------- |
| Union          | `      | `                         | `.union()`                   | in **a** or **b** (or both) |
| Intersection   | `&`    | `.intersection()`         | in **a** **and** **b**       |
| Difference     | `-`    | `.difference()`           | in **a** but **not** **b**   |
| Symmetric diff | `^`    | `.symmetric_difference()` | in **one** set, **not both** |

## Intersection — items in both

<PythonExample
  filename="intersection.py"
  code={`a = {1, 2, 3}
b = {3, 4, 5}
print(a & b)
print(a.intersection(b))`}
/>

Only **`3`** appears in both sets.

## Difference — in first but not second

<PythonExample
  filename="difference.py"
  code={`a = {1, 2, 3}
b = {3, 4, 5}
print(a - b)
print(b - a)`}
/>

- `a - b` → `{1, 2}` (in `a` only)
- `b - a` → `{4, 5}` (in `b` only)

## Real use case: shared tags between articles

shared = article_a & article_b
only_a = article_a - article_b

print("Both articles:", shared)

/>

## Subset and superset

<PythonExample
  filename="subset.py"
  code={`small = {1, 2}
big = {1, 2, 3, 4}
print(small.issubset(big))
print(big.issuperset(small))`}
/>

Both return **`True`** — every item in `small` is also in `big`.

<Callout variant="note" title="Oops — easy to mix up">
  **`a - b`** and **`b - a`** are **not** the same. Order matters for difference.
</Callout>

## Recap

- **Union** `|` — combine both sets
- **Intersection** `&` — keep only shared items
- **Difference** `-` — items in the first set but not the second
