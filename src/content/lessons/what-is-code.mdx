## Why this matters

**Code** is the word for those instructions when they are written for a machine. Once you recognize code, tutorials and error messages feel less mysterious.

Computers store and read **text files**. A file full of instructions in a language like Python is called **source code** (or just **code**).

## Code is not magic symbols

Beginners sometimes think code is random punctuation. Most of it is **English-like words** plus a few rules about spacing and punctuation.

<PythonExample filename="hello.py" code={`print("Hello!")`} />

**What you are looking at**

- `print` — a built-in action: show text on the screen
- `("Hello!")` — the text to show, in quotes
- The whole line is one **statement** — one instruction

That is real code. You can run it on this page.

## Source code vs running the program

| Term | Meaning |
| ---- | ------- |
| **Source code** | The text you write and save |
| **Run / execute** | The computer reads the file and follows each line |
| **Output** | What you see after running (here, `Hello!`) |

You will write code in the editor, press **Run**, and read the **output** — again and again.

## Files and languages

Python code often lives in a file ending in `.py` (for example `hello.py`). Other languages use other endings (`.js`, `.java`). PyGuide runs Python in your browser so you do not install anything first.

<Callout variant="tip">
  Read code out loud: “print Hello.” That habit helps you see one instruction at a time.
</Callout>

## Recap

- **Code** = instructions written in a programming language
- **`print(...)`** = a simple instruction you will use constantly
- **Run** every example — reading alone is not enough
