Consistent style helps readers focus on logic. **black** formats layout; **ruff** lints mistakes and can format too — many projects use **ruff** for both.

## Install in your venv

```bash
pip install ruff black
```

## Format with black

```bash
black src tests
```

Opinionated — few options, less bike-shedding.

## Lint with ruff

```bash
ruff check src tests
ruff check --fix src tests
```

Catches unused imports, undefined names, and style issues.

## pyproject.toml config teaser

```toml
[tool.black]
line-length = 88

[tool.ruff]
line-length = 88
target-version = "py312"
```

Run in **CI** so main stays clean.

<Callout variant="note">
  Pre-commit hooks can run ruff/black before each `git commit` — optional power-up.
</Callout>
