## Why this matters

Code quality: ruff and black shows up throughout Writing Clean Python and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.


Consistent style helps readers focus on logic. **black** formats layout; **ruff** lints mistakes and can format too — many projects use **ruff** for both.

## Install in your venv

```bash
pip install ruff black
```

## Format with black

```bash
black src tests
```

Opinionated — few options, less bike-shedding.

## Lint with ruff

```bash
ruff check src tests
ruff check --fix src tests
```

Catches unused imports, undefined names, and style issues.

## pyproject.toml config teaser

```toml
[tool.black]
line-length = 88

[tool.ruff]
line-length = 88
target-version = "py312"
```

Run in **CI** so main stays clean.

<Callout variant="note">
  Pre-commit hooks can run ruff/black before each `git commit` — optional power-up.
</Callout>

## Recap

- **black** / **ruff** — automate style
- Configure in **pyproject.toml**
- Run the same tools in CI when you automate tests later
