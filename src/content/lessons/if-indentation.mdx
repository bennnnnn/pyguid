## Why this matters

if is how programs make decisions—login checks, discounts, error handling. Python's indentation rules force readable structure but punish mixed tabs and spaces. Solid if skills underpin elif, loops, and try/except later.

A vending machine only drops a snack when you pick a valid button and pay enough. An **`if`** statement works the same way — it runs code **only when** a condition is `True`.

## One new idea: `if`, a colon, and an indented block

1. Write `if` followed by a condition
2. End the line with a **colon** `:`
3. Indent the block below with **4 spaces**

<PythonExample
  filename="if_basic.py"
  code={`age = 18

if age >= 18:
print("You are an adult")
print("Welcome")`}
/>

**Line by line**

- `if age >= 18:` — test the condition; the colon starts the block
- Indented lines run **only** when the condition is `True`
- Lines at the normal indent level always run

<PythonExample
  filename="flow.py"
  code={`score = 50
print("Checking score...")

if score >= 60:
print("Pass")

print("Done")`}
/>

When `score` is 50, you only see “Checking score…” and “Done” — the indented block is skipped.

## Real use case: login check

<PythonExample
  filename="login.py"
  code={`logged_in = True

if logged_in:
print("Hello")
print("Dashboard ready")
else:
print("Please sign in")`}
/>

## Nested if

You can put an `if` inside another `if` — each level adds 4 more spaces:

<PythonExample
  filename="nested.py"
  code={`age = 20
has_license = True

if age >= 18:
if has_license:
print("You may drive")
else:
print("You need a license")
else:
print("Too young to drive")`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  Mixing tabs and spaces, or using 2 spaces on one line and 4 on the next, causes
  **`IndentationError`**. All lines in the same block must use the **same** indentation.
</Callout>

<Callout variant="warning">
  Deep nesting gets hard to read. Consider combining conditions: `if age >= 18 and has_license:`.
</Callout>

## Recap

- **`if condition:`** runs the indented block only when the condition is `True`
- Every block line needs **4 spaces** (or one consistent indent)
- Lines outside the block always run
- Nested `if` adds another indent level
