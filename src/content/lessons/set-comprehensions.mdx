## Why this matters

Set comprehensions shows up throughout Comprehensions and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

List comprehensions build lists; **set comprehensions** build **sets** — duplicates disappear automatically.

## One new idea: unique squares

<PythonExample
  filename="setcomp.py"
  code={`nums = [1, 2, 2, 3, 3, 3]
unique_squares = {n * n for n in nums}
print(unique_squares)`}
/>

Curly braces with a **`for`** inside mean “set comprehension” (not a dict — no colon between key and value).

## Filter with if

<PythonExample
  filename="setcomp_if.py"
  code={`words = ["hi", "hello", "hey", "hi"]
long_starts = {w for w in words if len(w) >= 3}
print(long_starts)`}
/>

## Compare to list comprehension

| Syntax              | Result type | Duplicates |
| ------------------- | ----------- | ---------- |
| `[x for x in nums]` | list        | kept       |
| `{x for x in nums}` | set         | removed    |

## Recap

- **`{expr for item in iterable}`** — set comprehension
- Add **`if`** to filter
- Order is not guaranteed (sets are unordered)
