String paths get messy with slashes. **`pathlib`** (standard library) treats paths as objects — cleaner joins and checks.

## One new idea: Path objects

On your computer:

```python
from pathlib import Path

folder = Path("data")
file = folder / "notes.txt"
print(file)
print(file.name)
print(file.suffix)
```

| Property / op            | Example result |
| ------------------------ | -------------- |
| `Path("data") / "a.txt"` | `data/a.txt`   |
| `.name`                  | `notes.txt`    |
| `.suffix`                | `.txt`         |

## Why pathlib?

- **`/` operator** joins paths (OS-aware on real `Path`)
- **`.exists()`**, **`.read_text()`** — readable methods (local Python 3)

<Callout variant="tip">
  New projects often prefer **`pathlib`** over manual string paths with **`os.path`**.
</Callout>
