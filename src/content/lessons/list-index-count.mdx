You search a spreadsheet: **how many** times does “banana” appear, and **where is the first** “banana”? **`count()`** answers “how many”; **`index()`** answers “where first.”

## One new idea: count()

<PythonExample
  filename="count.py"
  code={`letters = ["a", "b", "a", "c", "a"]
print(letters.count("a"))
print(letters.count("z"))`}
/>

| Call         | Result | Meaning              |
| ------------ | ------ | -------------------- |
| `count("a")` | `3`    | three `"a"` items    |
| `count("z")` | `0`    | not found — no error |

## index() — first position of a value

<PythonExample
  filename="index.py"
  code={`fruits = ["apple", "banana", "cherry", "banana"]
print(fruits.index("banana"))
print(fruits.index("cherry"))`}
/>

| Value      | `index()` returns | Why              |
| ---------- | ----------------- | ---------------- |
| `"banana"` | `1`               | first at index 1 |
| `"cherry"` | `2`               | only one         |

Only the **first** match — not every `"banana"`.

## Safe search before you act

<PythonExample
  filename="index_safe.py"
  code={`items = [10, 20, 30]
target = 25

if target in items:
print(items.index(target))
else:
print("25 not in list")`}
/>

<Callout variant="danger" title="Oops — Python is yelling">
  **`items.index(25)`** when `25` is missing → **ValueError**. Use **`in`** first, like
  with **`remove()`**.
</Callout>

## Start searching later in the list

<PythonExample
  filename="index_start.py"
  code={`nums = [1, 2, 3, 2, 1]
print(nums.index(2))
print(nums.index(2, 2))`}
/>

Second call: find **`2`** starting at index **`2`** → finds the `2` at index `3`.

## Real use case: count before removing duplicates

<PythonExample
  filename="tally.py"
  code={`votes = ["yes", "no", "yes", "yes", "no"]
print("yes:", votes.count("yes"))
print("no:", votes.count("no"))`}
/>

<TryIt title="Try it yourself" answer="1">
  With `colors = ["red", "green", "blue"]`, print `colors.index("green")`.
</TryIt>

## Recap

- **`count(x)`** — how many times **`x`** appears (0 if none)
- **`index(x)`** — index of **first** **`x`** (error if missing)
- Check **`x in list`** before **`index`** or **`remove`**
