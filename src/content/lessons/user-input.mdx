A waiter asks “What would you like?” and waits for your answer. **`input()`** pauses your program, reads a line from the keyboard, and returns it as a **string**.

## One new idea: input()

On your computer:

```python
name = input("What is your name? ")
print(f"Hello, {name}")
```

**Line by line**

- `input("...")` — show a prompt, wait for Enter
- Always returns **text** — even if the user types digits
- Use the result like any other string

<Callout variant="note">
  **`input()` does not work in PyGuide’s browser runner** — it would wait forever for
  keyboard input. Practice the pattern below with preset values, then try `input()` in a
  local `.py` file.
</Callout>

## Real use case: validate with try/except

<PythonExample
  filename="validate.py"
  code={`raw = "42"
try:
    value = int(raw)
    print("Valid number:", value)
except ValueError:
    print("Please enter digits only")`}
/>

Wrap risky parsing so bad input does not crash the program.

## Recap

- **`input()`** — read a line of text from the user
- **Convert** with `int()` / `float()` before math
- **Validate** with try/except for friendly errors
