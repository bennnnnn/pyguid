Imagine a very literal friend who only does what you write down, line by line. **Python** is how you write those instructions so a computer can follow them.

Computers do not understand English. They follow **code** — text in a **programming language**. Python is one of the friendliest languages to start with.

## One new idea: code is instructions

<PythonExample filename="demo.py" code={`print("Hello, Python!")`} />

**Line by line**

- `print(...)` — “show this on the screen”
- `"Hello, Python!"` — text in quotes
- Run it — you should see exactly that message

That one line is a real program. You are already “coding.”

## Why learn Python?

| Reason                | What it means for you                            |
| --------------------- | ------------------------------------------------ |
| **Beginner-friendly** | Less clutter; you learn ideas, not magic symbols |
| **Powerful**          | Used by beginners and big companies              |
| **Versatile**         | Web, data, automation, games, hobbies            |
| **In demand**         | Many jobs list Python                            |
| **Free help**         | Huge community and tutorials                     |

You do not need to be “good at math.” **Patience and practice** beat prior experience.

## What is Python used for?

| Area           | Examples                                       |
| -------------- | ---------------------------------------------- |
| **Websites**   | APIs, backends (Instagram, Dropbox use Python) |
| **Data & AI**  | Spreadsheets, charts, research                 |
| **Automation** | Rename files, send emails, boring office tasks |
| **Education**  | Schools and universities teach with it         |
| **Hobbies**    | Small games, personal tools                    |

This course teaches **core Python** that works in all of those areas.
