## Why this matters

You have seen **programming**, **code**, and **how computers follow steps**. This lesson names the tool you will learn: **Python**.

## One new idea: Python is a language

A **programming language** is a set of rules for writing instructions. **Python** is one language—like English vs Spanish, but for computers.

<PythonExample filename="demo.py" code={`print("Hello, Python!")`} />

That line is valid Python. The computer (via PyGuide’s runner) follows the rules of Python to show the message.

## Who created Python?

**Guido van Rossum** started Python in the late 1980s and released it publicly in **1991**. He wanted a language that was **pleasant to read** and **fast to write**. The community grew from there; today thousands of people maintain libraries and tools.

## High-level vs low-level

| Level | You write | Example |
| ----- | --------- | ------- |
| **Low-level** | Details close to the CPU | Machine code, assembly |
| **High-level** | Steps closer to human logic | **Python** |

High-level does not mean “weak.” Huge systems run on Python. It means you worry less about hardware on day one.

## Interpreter vs compiler (simple version)

Python is usually run by an **interpreter**: it reads your file and executes it step by step. You press **Run** on PyGuide and see output without a separate compile step. (Other languages compile first; you can learn that distinction later.)

## How PyGuide runs Python

Lessons use **Skulpt** in the browser—real Python-style syntax for beginners, no install. A few advanced features differ from Python on your laptop; we stick to beginner-safe examples.
