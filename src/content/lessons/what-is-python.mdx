Computers do not understand English. They follow **instructions** written in a **programming language**. **Python** is one of the most popular languages in the world — and one of the best places to start learning to code.

## What is Python?

**Python** is a language for telling a computer what to do. You write **code** (text instructions), and a program called the **Python interpreter** runs that code step by step.

Python is known for code that reads almost like plain English:

<PythonExample
  filename="demo.py"
  code={`print("Hello, Python!")`}
/>

That one line is a real program. It tells Python to show the text `Hello, Python!` on the screen.

## Why learn Python?

People choose Python because it is:

- **Beginner-friendly** — less clutter than many languages; you focus on ideas, not tricky syntax  
- **Powerful** — used by beginners and by large companies for serious work  
- **Versatile** — one language for websites, data, automation, games, and more  
- **In demand** — many jobs list Python as a skill  
- **Well supported** — huge community, free tutorials, and libraries for almost any task  

You do not need to be “good at math” or have built a computer before. Patience and practice matter more than prior experience.

## What is Python used for?

| Area | What people build |
| ---- | ----------------- |
| **Websites & apps** | Backends for sites, APIs, tools like Instagram and Dropbox use Python |
| **Data & AI** | Analyzing spreadsheets, charts, machine learning, scientific research |
| **Automation** | Renaming thousands of files, sending emails, scraping data, repetitive office tasks |
| **Scripting** | Small programs that glue other software together |
| **Education** | Teaching programming in schools and universities |
| **Games & hobbies** | Prototypes, indie games, personal projects |

You do not pick one path on day one. This course teaches **core Python** that applies everywhere.

## Who is this course for?

- Understand what code is and how Python runs it
