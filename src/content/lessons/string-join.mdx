**`split()`** cuts a string apart. **`join()`** is the glue: you pick the separator, pass a list of strings, and get one combined string back.

## One new idea: separator.join(list)

<PythonExample
  filename="join.py"
  code={`words = ["Python", "is", "great"]
sentence = " ".join(words)
print(sentence)`}
/>

**Line by line**

- `" "` — the **glue** (space between words)
- `.join(words)` — stick `words` together
- Result: `"Python is great"`

Read it as: **“space-join these words.”**

## Different separators

<PythonExample
  filename="separators.py"
  code={`items = ["2024", "05", "23"]
print("-".join(items))
print(", ".join(["a", "b", "c"]))`}
/>

## Round trip with split()

<PythonExample
  filename="roundtrip.py"
  code={`original = "one,two,three"
parts = original.split(",")
restored = ",".join(parts)
print(restored)`}
/>

## Common mistake: numbers in the list

<Callout variant="danger" title="Oops — Python is yelling">
  **`"-".join([1, 2, 3])`** → **TypeError**. Every item must be a **string**. Convert
  first: **`"-".join(str(n) for n in nums)`** (pattern shown below).
</Callout>

<PythonExample
  filename="str_first.py"
  code={`nums = [1, 2, 3]
text = "-".join(str(n) for n in nums)
print(text)`}
/>

<TryIt title="Try it yourself" answer="a-b-c">
  With `parts = ["a", "b", "c"]`, print `"-".join(parts)`.
</TryIt>

## Recap

- Call **`join`** on the **separator** string
- All items must be **`str`**
- Pairs naturally with **`split()`**
