A stack of plates: you take the **top** one off and **hold it in your hand**. **`pop()`** removes an item from the list and **hands it back to you** in code.

## One new idea: pop the last item

<PythonExample
  filename="pop_last.py"
  code={`stack = [1, 2, 3]
last = stack.pop()
print("Got:", last)
print("Left:", stack)`}
/>

**Before → action → after**

| `stack` before | `last` | `stack` after |
| -------------- | ------ | ------------- |
| `[1, 2, 3]`    | `3`    | `[1, 2]`      |

**Line by line**

- `stack.pop()` — remove and return the **last** item
- `last` stores what was removed
- `stack` is shorter now

## pop(index) — pick a position

<PythonExample
  filename="pop_index.py"
  code={`colors = ["red", "green", "blue"]
middle = colors.pop(1)
print("Removed:", middle)
print("List now:", colors)`}
/>

`pop(1)` removes `"green"` (index 1).

## Real use case: process a queue (front first)

<PythonExample
  filename="queue.py"
  code={`queue = ["first", "second", "third"]
current = queue.pop(0)
print("Processing:", current)
print("Remaining:", queue)`}
/>

`pop(0)` takes from the **front**. Fine for small lists; for huge queues, later you may use `collections.deque`.

## Common mistake: pop from empty list

<PythonExample
  filename="pop_empty.py"
  code={`items = []
if items:
    items.pop()
else:
    print("Nothing to pop")`}
/>

<Callout variant="warning" title="Oops — Python is yelling">
  **`pop()`** on an **empty** list → **IndexError**. Check **`if items:`** first.
</Callout>

<Callout variant="tip">
  **Stack pattern:** **`append(x)`** to push, **`pop()`** to pop — last in, first out.
</Callout>

<TryIt title="Try it yourself" answer="30">
  With `nums = [10, 20, 30]`, assign `n = nums.pop()`. Print `n` (not the whole list).
</TryIt>

## Recap

- **`pop()`** — remove **last**, return it
- **`pop(i)`** — remove at index **`i`**, return it
- Unlike **`remove()`**, you get the **value back**

Next: **`clear()`** — empty the whole list.
