## Why this matters

Python sets shows up throughout Sets and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

A **list** keeps every item, even duplicates, in order. A **set** is like a **jar of unique marbles** — drop in `"python"` twice, you still only have **one** `"python"`. No guaranteed order.

## One new idea: a set in curly braces

<PythonExample
  filename="set.py"
  code={`tags = {"python", "code", "learn", "python"}
print(tags)
print(len(tags))`}
/>

**Line by line**

- `{"python", "code", "learn", "python"}` — curly braces `{ }`, items separated by commas
- Duplicate `"python"` is stored **once**
- `len(tags)` → **`3`**, not `4`

Sets are:

- **Unordered** — printing may show items in any order
- **Unique** — duplicates are ignored automatically
- **Mutable** — you can add and remove items (but not change items in place)

## Remove duplicates from a list

<PythonExample
  filename="from_list.py"
  code={`numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(unique)
print(list(unique))`}
/>

`set(list)` drops duplicates. Wrap with `list(...)` if you need a list again.

## Real use case: fast membership checks

<PythonExample
  filename="in_set.py"
  code={`allowed = {"admin", "editor", "viewer"}
role = "admin"

if role in allowed:
print("Access granted")
else:
print("Access denied")`}
/>

Sets are optimized for **`in`** checks — great for allowed roles, seen IDs, or tag lookups.

## Add and remove

<PythonExample
  filename="add_remove.py"
  code={`colors = {"red", "blue"}
colors.add("green")
colors.remove("red")
print(colors)`}
/>

| Method       | If item missing                      |
| ------------ | ------------------------------------ |
| `remove(x)`  | **KeyError**                         |
| `discard(x)` | **no error** — silently does nothing |

<Callout variant="warning" title="Oops — Python is yelling">
  Set items must be **immutable** — numbers, strings, and tuples work. **Lists** inside a
  set → **TypeError**.
</Callout>

## Recap

- **`{a, b, c}`** stores **unique** items with **no fixed order**
- **`set(my_list)`** removes duplicates
- **`add()`**, **`remove()`**, **`discard()`** change the set
