Family traits pass from parent to child — eye color, height. **Inheritance** lets a **child class** reuse a **parent class** and add or override behavior.

## One new idea: parent and child

<PythonExample
  filename="inherit.py"
  code={`class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
def speak(self):
return f"{self.name} says woof!"

class Cat(Animal):
def speak(self):
return f"{self.name} says meow!"

pets = [Dog("Buddy"), Cat("Luna")]
for pet in pets:
print(pet.speak())`}
/>

**Line by line**

- `class Dog(Animal):` — `Dog` **inherits** from `Animal`
- Child gets `__init__` and can **override** methods like `speak`
- Same loop, different sounds — **polymorphism**

## super() — call the parent

<PythonExample
  filename="super.py"
  code={`class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
def **init**(self, name, student_id):
super().**init**(name)
self.student_id = student_id

s = Student("Ada", "A123")
print(s.name, s.student_id)`}
/>

`super().__init__(name)` runs the parent setup before adding `student_id`.

## Real use case: isinstance()

<PythonExample
  filename="isinstance.py"
  code={`class Animal:
    pass

class Dog(Animal):
pass

d = Dog()
print(isinstance(d, Dog))
print(isinstance(d, Animal))`}
/>

A `Dog` **is a** `Animal` — `isinstance` checks the family tree.

<Callout variant="tip">
  Inheritance models “is-a” relationships: a `Dog` **is an** `Animal`. If the relationship
  is only “has-a” (a car **has an** engine), composition (attributes) is often better.
</Callout>

<Callout variant="note">
  Python supports multiple inheritance, but beginners should master single inheritance
  first.
</Callout>

<TryIt title="Try it yourself" answer="True">
  With `Dog(Animal)` as above, create `d = Dog()` and print `isinstance(d, Animal)`.
</TryIt>

## Recap

- **Inheritance** — child reuses parent behavior
- **Override** — replace a method in the child
- **`super()`** — call the parent’s `__init__` or methods
