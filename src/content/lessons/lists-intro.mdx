## Why this matters

Lists are the default container for sequences in beginner Python—scores, names, file lines, and API data often arrive as lists first. Indexing and slicing show up in every loop and comprehension later. A solid lists foundation makes dictionaries, functions, and projects much less confusing.

Your phone’s playlist is **one** thing called “Road trip” — but inside it are **many songs in order**. A Python **list** is that: **one variable**, **many values**, **in order**.

## One new idea: a list in square brackets

<PythonExample
  filename="lists.py"
  code={`fruits = ["apple", "banana", "cherry"]
print(fruits)
print(len(fruits))`}
/>

**Line by line**

- `["apple", "banana", "cherry"]` — three strings inside `[ ]`, separated by commas
- `fruits = ...` — one name for the whole collection
- `len(fruits)` — how many items? Here, `3`

Lists are:

- **Ordered** — first item stays first unless you change it
- **Mutable** — you can add, remove, and edit items
- **Indexed** — each position has a number starting at **`0`**

## What is in this chapter?

You will learn lists in this order:

1. **What a list is** (this page)
2. **Access items** — `[0]`, slicing, negative indexes
3. **Add items** — `append()`, `extend()`, `insert()`
4. **Remove items** — `remove()`, `pop()`, `clear()`
5. **Reorder** — `sort()`, `reverse()`
6. **Search and copy** — `index()`, `count()`, `.copy()`
7. **Loop** through every item

## Numbers and text in one list

<PythonExample
  filename="mixed.py"
  code={`item = ["book", 12.99, 3]
print(item[0])
print(item[1])`}
/>

| Index | Value    |
| ----- | -------- |
| `0`   | `"book"` |
| `1`   | `12.99`  |
| `2`   | `3`      |

One list _can_ mix types; in real projects, keeping one type per list is often clearer.

## Start empty, grow later

<PythonExample
  filename="empty.py"
  code={`tasks = []

/>

An empty list `[]` is useful when you will add items one at a time (shopping cart, todo app).

## Recap

- **`[a, b, c]`** creates an ordered, changeable collection
- **`len(my_list)`** counts items
- **`"x" in my_list`** checks membership
