Real tools split code across files: CLI in one module, storage in another, tests in a folder. This capstone ties **argparse**, **JSON or SQLite**, and **pytest** into one small project you can put on GitHub.

## Suggested layout

```text
taskcli/
  pyproject.toml
  src/taskcli/
    __init__.py
    cli.py       # argparse + main()
    storage.py   # load/save todos
  tests/
    test_storage.py
```

## cli.py sketch

```python
import argparse
from taskcli.storage import load_tasks, save_tasks, add_task

def main():
    parser = argparse.ArgumentParser(description="Task CLI")
    sub = parser.add_subparsers(dest="command", required=True)

    add_p = sub.add_parser("add")
    add_p.add_argument("text")

    list_p = sub.add_parser("list")

    args = parser.parse_args()
    tasks = load_tasks()

    if args.command == "add":
        add_task(tasks, args.text)
        save_tasks(tasks)
    elif args.command == "list":
        for i, t in enumerate(tasks, start=1):
            print(f"{i}. {t['text']}")

if __name__ == "__main__":
    main()
```

## storage.py with JSON

```python
import json
from pathlib import Path

PATH = Path.home() / ".taskcli.json"

def load_tasks():
    if not PATH.exists():
        return []
    return json.loads(PATH.read_text(encoding="utf-8"))

def save_tasks(tasks):
    PATH.write_text(json.dumps(tasks, indent=2), encoding="utf-8")

def add_task(tasks, text):
    tasks.append({"text": text, "done": False})
```

## Test storage.py

```python
def test_add_task():
    tasks = []
    add_task(tasks, "Write tests")
    assert len(tasks) == 1
    assert tasks[0]["text"] == "Write tests"
```
