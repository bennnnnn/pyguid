## Why this matters

Static checking with mypy shows up throughout Type Hints and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Type hints are labels. **mypy** reads those labels and reports mismatches **before** runtime — like spell-check for types.

## One new idea: run mypy locally

```python
# greet.py
def greet(name: str) -> str:
    return f"Hello, {name}"

greet(42)  # mypy flags this
```

```bash
pip install mypy
mypy greet.py
```

mypy reports: expected `str`, got `int`.
