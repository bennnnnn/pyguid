## Why this matters

Real messages combine labels and numbers: `Age: 25`, `Score: 10`. Commas in **`print()`** are the simple way to show several values on one line.

## Commas add spaces

<PythonExample
  filename="multiple.py"
  code={`print("Age:", 25)
print("Python", "is", "fun")`}
/>

**Output**

```text
Age: 25
Python is fun
```

Each comma is another argument. **`print()`** puts a **space** between them by default.

## Mix text and numbers

<PythonExample
  filename="label.py"
  code={`print("The answer is", 42)
print("Score", 10)`}
/>

## Custom separator with `sep`

<PythonExample
  filename="sep.py"
  code={`print("A", "B", "C", sep="-")`}
/>

**Output:** `A-B-C`

| Option | Default | Example |
| ------ | ------- | ------- |
| `sep` | space `" "` | `sep=", "` → commas |
| `sep` | | `sep="-"` → dashes |

## Blank line with empty print()

<PythonExample
  filename="blank.py"
  code={`print("Line 1")
print()
print("Line 3")`}
/>

`print()` with nothing inside prints an empty line.

## Same line with `end` (preview)

<PythonExample
  filename="end.py"
  code={`print("Loading", end="...")
print(" done")`}
/>

**Output:** `Loading... done` (default `end` is a newline).

## Recap

- **Commas** → several values, spaces between
- **`sep="-"`** → control what goes between items
- **`print()`** alone → blank line
