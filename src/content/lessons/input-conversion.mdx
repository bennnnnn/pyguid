## Why this matters

Programs that add, compare, or loop by count need numeric types, not strings—'5' + '3' is not 8. Conversion errors are normal with real users, so learning try/except or validation early prevents crashes. This bridges input() to arithmetic and conditions.

You ask for someone’s age and they type `25`. Python still stores **`"25"`** (text), not the number **25**. That is why this line crashes:

```python
age = "25"
print(age + 1)  # TypeError
```

## One new idea: wrap input with int() or float()

<PythonExample
  filename="convert.py"
  code={`# age_text = input("Age: ")
age_text = "25"
age = int(age_text)
print(age + 1)`}
/>

**Before → after**

| Step       | `age` means   |
| ---------- | ------------- |
| `age_text` | `"25"` string |
| `int(...)` | `25` number   |
| `age + 1`  | `26`          |

## Shorthand: convert in one line

<PythonExample
  filename="one_line.py"
  code={`# age = int(input("Age: "))
age = int("25")
print("Next year:", age + 1)`}
/>

## Common mistake: forget int()

<Callout variant="danger" title="Oops — Python is yelling">
  **`"5" + "5"`** → **`"55"`** (text glued together). **`5 + 5`** → **`10`**. After
  `input()`, use **`int()`** or **`float()`** before math.
</Callout>

<TryIt title="Try it yourself" answer="30">
  Set `text = "12"`, then `n = int(text)`, then `print(n + 18)`.
</TryIt>

## Recap

- **`input()`** → always **str**
- **`int(text)`** / **`float(text)`** → numbers for math
- Convert **before** adding or comparing numbers
