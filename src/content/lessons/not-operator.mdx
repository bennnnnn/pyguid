## Why this matters

not expresses absence and invalid states—if not found:, if not user.is_active:. Double negatives get confusing, so pairing not with clear names matters. It works with and and or to build compact guards without extra variables.

A light switch labeled **not on** flips the meaning. **`not`** reverses a boolean — `True` becomes `False` and back.

## One new idea: not

<PythonExample
  filename="not_demo.py"
  code={`is_raining = False
print(not is_raining)

is_closed = True
print(not is_closed)`}
/>

| Expression  | Result  |
| ----------- | ------- |
| `not False` | `True`  |
| `not True`  | `False` |

## With comparisons

<PythonExample
  filename="not_compare.py"
  code={`age = 15
print(not age >= 18)`}
/>

Same as “not an adult” for this simple check.

## Real use case: while a flag is false

<PythonExample
  filename="flag.py"
  code={`done = False
if not done:
    print("Keep going")`}
/>

<Callout variant="tip">
  **`not x`** is clearer than **`x == False`** when `x` is already a boolean.
</Callout>

## Recap

- **`not`** flips booleans
- Works on comparison results too
