## Why this matters

reverse shows up throughout Lists and later chapters. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

You flip a row of dominoes so the first becomes last. **`reverse()`** mirrors the **current** order — it does **not** sort by size.

## One new idea: flip the list in place

<PythonExample
  filename="reverse.py"
  code={`nums = [1, 2, 3, 4, 5]
nums.reverse()
print(nums)`}
/>

**Before → after**

| Before            | After `reverse()` |
| ----------------- | ----------------- |
| `[1, 2, 3, 4, 5]` | `[5, 4, 3, 2, 1]` |

## reverse() vs sort(reverse=True)

<PythonExample
  filename="compare.py"
  code={`a = [3, 1, 4, 2]
a.reverse()
print("reverse:", a)

b = [3, 1, 4, 2]
b.sort(reverse=True)
print("sort reverse:", b)`}
/>

| Method               | What it does                     |
| -------------------- | -------------------------------- |
| `reverse()`          | flip whatever order you have now |
| `sort(reverse=True)` | sort largest-first by value      |

Example: `[3, 1, 4, 2]` → `reverse` → `[2, 4, 1, 3]`; `sort(reverse=True)` → `[4, 3, 2, 1]`.

## Keep the original: slice copy

<PythonExample
  filename="slice_reverse.py"
  code={`letters = ["a", "b", "c", "d"]
backward = letters[::-1]
print("original:", letters)
print("backward:", backward)`}
/>

`[::-1]` builds a **new** reversed list; **`letters`** stays the same.

## Loop with reversed()

<PythonExample
  filename="reversed_func.py"
  code={`nums = [1, 2, 3]
for n in reversed(nums):
    print(n)
print("list unchanged:", nums)`}
/>

<Callout variant="note">
  **`reverse()`** returns **`None`**. Use **`[::-1]`** or **`reversed()`** when you must
  keep the original order intact.
</Callout>

## Recap

- **`reverse()`** — mirror order in place
- Not the same as **`sort(reverse=True)`**
- **`[::-1]`** — reversed **copy**
