The **`for`** loop walks through each item in a **sequence** (list, string, tuple, dict keys, etc.):

<PythonExample
  filename="for_string.py"
  code={`word = "Python"
for letter in word:
    print(letter)`}
/>

## Loop a list

<PythonExample
  filename="for_list.py"
  code={`colors = ["red", "green", "blue"]
for color in colors:
    print(color)`}
/>

## Loop with a counter variable

<PythonExample
  filename="sum.py"
  code={`numbers = [4, 8, 15, 16]
total = 0
for n in numbers:
    total += n
print(total)`}
/>

## Nested loops

<PythonExample
  filename="nested.py"
  code={`for row in range(1, 4):
    for col in range(1, 3):
        print(row, col)`}
/>

<Callout variant="warning">
  Nested loops can run many times (3 × 2 = 6 here). Deep nesting on huge lists can be slow
  — there is often a better approach later.
</Callout>

<Callout variant="tip">
  `for` does not need a manual index when you only need values. You already practiced
  lists and strings — `for` ties them together.
</Callout>
