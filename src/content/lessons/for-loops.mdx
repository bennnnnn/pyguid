## Why this matters

for loops are how Python repeats work over data—printing tables, summing numbers, processing files. Almost every script beyond hello world uses them. Getting indentation and the loop variable right unlocks lists, strings, and dictionaries in practice.

Reading a word letter by letter is natural — you do not need to know the length first. A **`for`** loop walks through each item in a sequence the same way.

## One new idea: `for item in sequence`

<PythonExample
  filename="for_string.py"
  code={`word = "Python"
for letter in word:
    print(letter)`}
/>

**Line by line**

- `for letter in word:` — take each character from `word`, one at a time
- `letter` is a variable that changes each round
- The indented block runs once per item

<PythonExample
  filename="for_list.py"
  code={`colors = ["red", "green", "blue"]
for color in colors:
    print(color)`}
/>

## Real use case: total a list of numbers

<PythonExample
  filename="sum.py"
  code={`numbers = [4, 8, 15, 16]
total = 0
for n in numbers:
    total += n
print(total)`}
/>

| Loop type | Best when                            |
| --------- | ------------------------------------ |
| `for`     | You have a sequence to walk through  |
| `while`   | You repeat until a condition changes |

Nested loops run an inner loop for **each** outer step:

<PythonExample
  filename="nested.py"
  code={`for row in range(1, 4):
    for col in range(1, 3):
        print(row, col)`}
/>

<Callout variant="warning">
  Nested loops multiply work (3 × 2 = 6 prints here). Deep nesting on huge lists can be
  slow.
</Callout>

## Recap

- **`for item in sequence:`** visits every item once
- Works on strings, lists, and other sequences
- Use **`while`** when you do not have a sequence to walk
