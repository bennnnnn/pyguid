<h2 id="creating-variables">Creating variables</h2>

A **variable** is a name that refers to a value. You create one with `=`.

<PythonExample
  filename="variables.py"
  code={`age = 25
name = "Ada"
print(name)
print(age)`}
/>

<h2 id="naming-rules">Naming rules</h2>

Names can use letters, numbers, and underscores. They cannot start with a number. Use `snake_case` for multiple words.

<PythonExample
  filename="naming.py"
  code={`user_name = "Sam"
print(user_name)`}
/>

<h2 id="updating-values">Updating values</h2>

You can assign again to change what a variable holds.

<PythonExample
  filename="update.py"
  code={`score = 10
print(score)
score = 20
print(score)`}
/>

<h2 id="variables-in-print">Variables in print</h2>

Pass variables to `print()` or use an f-string.

<PythonExample
  filename="fstring.py"
  code={`name = "Ada"
print(f"Hello, {name}")`}
/>
