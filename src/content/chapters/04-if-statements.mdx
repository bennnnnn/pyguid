<h2 id="if-indentation">if and indentation</h2>

Use `if` with a condition. The block below must be indented.

<PythonExample
  filename="if_basic.py"
  code={`age = 18
if age >= 18:
    print("Adult")`}
/>

<h2 id="elif-else">elif and else</h2>

Add `elif` for extra conditions and `else` as a fallback.

<PythonExample
  filename="if_else.py"
  code={`score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")`}
/>

<h2 id="comparisons">Comparison operators</h2>

Compare values with `==`, `!=`, `<`, `>`, `<=`, `>=`.

<PythonExample
  filename="compare.py"
  code={`x = 5
print(x == 5)
print(x != 3)`}
/>

<h2 id="and-or">and / or</h2>

Combine conditions with `and` and `or`.

<PythonExample
  filename="logic.py"
  code={`age = 25
has_id = True
if age >= 18 and has_id:
    print("OK")`}
/>
