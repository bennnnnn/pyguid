## Why this matters

Real programs rarely ask just one question. A sign-up form asks for name, email, and password. A quiz asks question after question. Chaining `input()` calls is how you collect multiple answers.

## One question after another

Each `input()` pauses the program, waits, and moves on to the next line:

<PythonExample
  filename="three_questions.py"
  code={`# On your PC, each line would pause and wait:
# name = input("Name: ")
# city = input("City: ")
# food = input("Favorite food: ")

name = "Bini"
city = "Portland"
food = "tacos"

print(name, "lives in", city, "and likes", food)`}
/>

The program runs top to bottom, pausing at each `input()`.

## Each answer gets its own variable

<PythonExample
  filename="profile.py"
  code={`# Simulate four inputs
name = "Sam"
age = "22"
city = "London"
hobby = "reading"

print("=== Your Profile ===")
print("Name:", name)
print("Age:", age)
print("City:", city)
print("Hobby:", hobby)`}
/>

Each piece of information lives in its own named variable. You can use them in any order later.

## Why separate variables matter

If you reuse the same variable, you lose the earlier answer:

```python
answer = input("Name: ")
answer = input("City: ")  # Oops — overwrote the name!

print(answer)  # Only the city is left
```

Each question deserves its own variable:

```python
name = input("Name: ")
city = input("City: ")

print(name, "—", city)  # Both answers are safe
```

<Callout variant="warning" title="Don't reuse the same variable">
  The second `=` **overwrites** the first value. Use a new variable name for each question unless you genuinely want to replace the old answer.
</Callout>

## Recap

- Call `input()` once per question
- Use a **different variable** for each answer
- The program pauses at each `input()` in order, top to bottom
- Reusing the same variable **overwrites** the previous answer
