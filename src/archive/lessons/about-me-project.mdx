## Why this matters

This mini project ties together **print()** and what you learned in **Running Python code**. Understanding it here makes the next lessons easier and helps you read real Python code with confidence. PyGuide keeps each page focused on one idea so you can practice without getting lost.

Time to build something small but **yours** — a program that introduces you. You will use only **`print`**, **comments**, and order of lines (everything from Chapter 1).

## What you are building

A script that prints:

```text
=== About Me ===
Name: ...
Age: ...
Hobby: ...
=== Thanks for reading ===
```

## Starter code — customize it

<PythonExample
  filename="about_me.py"
  code={`# About Me — Chapter 1 mini project
print("=== About Me ===")

print("Name: Ada")
print("Age: 20")
print("Hobby: learning Python")

print("=== Thanks for reading ===")`}
/>

**Line by line**

- Comments explain the file to humans
- Each `print` runs **in order**, top to bottom
- Change the text inside quotes to your real info (or fun fake info)

## Stretch goals

- Add a blank line with `print()`
- Print one line with **commas**: `print("City:", "London")`
- Add one more fact (favorite food, pet, game)

<Callout variant="tip">
  If you get **SyntaxError**, check every opening `(` and `"` has a closing partner.
</Callout>

## Recap

- You can already make a **small real program**
- **Order** of lines = order of output
- Errors are fixable — re-run after each fix
