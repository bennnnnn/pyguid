## Why this matters

You are not learning a fad from last year. Programming has decades of history. Python sits in a sweet spot: **modern**, **widely used**, and **readable**.

## Before high-level languages

Early programmers wired circuits or wrote **machine code** — numbers the CPU understands directly. Every task was slow to write and hard to fix.

**Assembly** used short mnemonics (`MOV`, `ADD`) but still tracked hardware details. Powerful, but heavy for beginners.

## High-level languages

In the 1950s–70s, languages like Fortran, Lisp, C, and Pascal let people write closer to human logic. A **compiler** or **interpreter** translated that text into machine instructions.

Goals shifted: **less typing**, **fewer errors**, **faster development**.

## Python enters the story

**Python** was created by **Guido van Rossum** and first released in **1991**. Goals included:

- **Readable** syntax (often described as “executable pseudocode”)
- **One clear way** to do many tasks (the Zen of Python encourages simplicity)
- **Batteries included** — a large standard library out of the box

Python grew with the web, data science, automation, and education. Today it powers startups, research labs, and intro courses worldwide.

## Why history matters to you

| Era | What changed for learners |
| --- | ------------------------- |
| Machine code | Experts only |
| C / Java | Powerful but more setup and syntax |
| Python | Gentle start, still used in serious products |

You learn Python **on purpose**: it is a mainstream tool, not a toy language.

## Recap

- Languages became **more human-friendly** over time
- **Python (1991+)** prioritizes readability and practical libraries
- You are learning a language with a long, active future
