A **web framework** maps URLs to Python functions. **Flask** is minimal — great for learning HTTP, HTML, and JSON APIs.

## Install and hello

```bash
pip install flask
```

```python
from flask import Flask

app = Flask(__name__)

@app.get("/")
def home():
    return "Hello from Flask"

if __name__ == "__main__":
    app.run(debug=True)
```

Visit `http://127.0.0.1:5000/` locally.

## JSON route

```python
from flask import jsonify

@app.get("/api/health")
def health():
    return jsonify({"ok": True})
```
