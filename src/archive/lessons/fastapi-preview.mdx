**FastAPI** builds on type hints — it validates request bodies and serves interactive docs at `/docs` automatically.

## Install and run

```bash
pip install "fastapi[standard]"
```

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"ok": True}

@app.get("/greet/{name}")
def greet(name: str):
    return {"message": f"Hello, {name}"}
```

```bash
fastapi dev main.py
```

Open `http://127.0.0.1:8000/docs` for Swagger UI.

## Flask vs FastAPI (beginner view)

| Flask           | FastAPI                 |
| --------------- | ----------------------- |
| flexible, tiny  | APIs + validation focus |
| sync by default | async-friendly          |
| huge ecosystem  | auto OpenAPI docs       |
