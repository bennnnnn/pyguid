## One new idea: import and use

<PythonExample
  filename="math_demo.py"
  code={`import math

print(math.ceil(4.2))

print(round(math.pi, 2))`}
/>

| Function     | Example result |
| ------------ | -------------- |

## random module

<PythonExample
  filename="random_demo.py"
  code={`import random

print(random.randint(1, 6))
print(random.choice(["red", "green", "blue"]))`}
/>

`randint(1, 6)` — dice roll. **`choice`** picks from a list.
