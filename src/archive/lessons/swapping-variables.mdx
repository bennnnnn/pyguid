## Why this matters

Sorting, shuffling, and UI state often need to **exchange** two stored values. Python’s swap idiom is short and shows up everywhere once you recognize it.

## Swap in one line

Python can **swap** values easily:

<PythonExample
  filename="swap.py"
  code={`a = "apple"
b = "banana"

a, b = b, a

print(a)
print(b)`}
/>

Output:

```text
banana
apple
```

Before the swap, **`a`** pointed to **`"apple"`** and **`b`** to **`"banana"`**. After **`a, b = b, a`**, they trade places.

## Before and after

| Step        | `a` points to | `b` points to |
| ----------- | ------------- | ------------- |
| Start       | `"apple"`     | `"banana"`    |
| After swap  | `"banana"`    | `"apple"`     |

<PythonExample
  filename="numbers_swap.py"

## Recap

- **`a, b = b, a`** swaps two values in **one** assignment line
- Works for strings, numbers, and other values you will learn later
