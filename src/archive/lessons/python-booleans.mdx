## Why this matters

Programs constantly ask yes/no questions: logged in? over 18? file found? Python stores those answers as **booleans** — **`True`** or **`False`**. You will use them heavily in **Conditions** later.

## True and False

A **boolean** (`bool`) is either:

- **`True`** — yes
- **`False`** — no

<PythonExample
  filename="flags.py"
  code={`is_student = True
is_admin = False

print(is_student)
print(is_admin)
print(type(is_student))`}
/>

Output:

```text
True
False
<class 'bool'>
```

## Capital T and F matter

Python only accepts the **capitalized** spellings **`True`** and **`False`**.

<Callout variant="danger" title="Invalid">
  **`true`**, **`false`**, **`TRUE`**, and **`FALSE`** are **not** valid booleans — Python will
  raise a **NameError** or treat them as unknown names.
</Callout>

## Used for logic later

You do not need **`if`** yet. Just know booleans **store decisions**:

<PythonExample
  filename="preview.py"
  code={`has_ticket = True
door_open = False

print("Ticket:", has_ticket)
print("Door open:", door_open)`}
/>

## Recap

- **`bool`** values are **`True`** and **`False`** only
- **Capital letters** are required
- Booleans power **conditions** and comparisons in later chapters
- **`type(x)`** shows **`<class 'bool'>`**
