## Why this matters

Error messages and tutorials mention **statements** and **expressions**. The difference is small but helps you read code and REPL output.

## Expression = produces a value

These are **expressions** — they **evaluate** to a value:

```python
2 + 2
3 * 5
"Hello"
len("hi")   # later
```

An expression can sit **inside** something bigger:

<PythonExample filename="expr.py" code={`print(2 + 2)`} />

Here `2 + 2` is an expression (value **4**). **`print(...)`** is the statement that uses it.

## Statement = do something

A **statement** is a full line of instruction Python executes:

```python
print("Hi")
name = "Bini"   # later, in Variables
```

<PythonExample
  filename="statements.py"
  code={`print("Start")
print(3 + 4)
print("End")`}
/>

Each line is a statement. Some contain expressions inside them.

## Same value, different roles

| Code | Kind | What happens in a script |
| ---- | ---- | ------------------------ |
| `2 + 2` | expression only | computes 4; may not show (see next lesson) |
| `print(2 + 2)` | statement | computes 4 **and shows** 4 |

<PythonExample filename="both.py" code={`print(2 + 2)
print(10 - 3)`} />

## Keep it simple for now

You do not need to classify every line perfectly. Remember:

- **Expression** → “what is the value?”
- **Statement** → “what should Python **do**?”

## Recap

- **Expressions** produce values (`2 + 2`, `"Hi"`)
- **Statements** perform actions (`print(...)`, assignments later)
- **`print(2 + 2)`** combines both: expression inside a statement
