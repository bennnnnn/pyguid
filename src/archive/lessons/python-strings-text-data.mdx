## Why this matters

Names, messages, file paths, and labels are **text**. In Python, text values are called **strings** (`str`). If you forget quotes, Python thinks a word is a variable name instead of text.

## Strings are text

A **string** is a sequence of characters — letters, digits, spaces, symbols — wrapped in **quotes**.

<PythonExample
  filename="hello_str.py"
  code={`name = "Bini"
print(name)
print(type(name))`}
/>

Output:

```text
Bini
<class 'str'>
```

## Single quotes or double quotes

Both work for plain text:

<PythonExample
  filename="quotes.py"
  code={`city = 'San Francisco'
country = "USA"

print(city)
print(country)`}
/>

Pick one style and stay consistent. PyGuide often uses **double quotes** `"..."`.

## Numbers inside quotes are still text

If digits are in **quotes**, they are **strings**, not math numbers:

<PythonExample
  filename="text_digits.py"
  code={`name = "Bini"
age = "25"

print(type(name))
print(type(age))`}
/>

Output:

```text
<class 'str'>
<class 'str'>
```

You cannot do **`"25" + 1`** — that mixes text and a number (TypeError).

## Recap

- **`str`** = text; create with **`"..."`** or **`'...'`**
- **`"25"`** is text; **`25`** is an int
- **`type(value)`** shows **`<class 'str'>`** for strings
- Full string tools (slice, split, etc.) come in the **Strings** chapter later
